---
name: cubegame-models
description: Validate CubeGame character geometry, rig, sockets, skinning, Blender export or Unity import.
---

- Start with [character tooling](../../../tools/character-assets/README.md). Record input provenance, dependencies and any local-only references.
- Rebuild in a separate output directory. Validate scale, rest pose, topology, weights, clips, sockets and module coverage after re-import.
- For a game-ready candidate, import and play a clip in Unity, check scale and module movement in an actual scene and obtain the owner's visual decision.
- Separate measured file checks, runtime verification and artistic review in the result.
