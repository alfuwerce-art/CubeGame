Reconcile prior owner remarks and later superseding decisions; never reset, switch or recreate another person's work. Save reversible baseline, actual UE assets and restore recipe before changes.
2. Convert ordinary request into individual requirement IDs, owner wording, target clip/phase/model, protected scope, observable acceptance checks; keep every unresolved prior remark in checkpoint. Select CREATE, ADAPT, EDIT or REVIEW per operation. Do not silently drop requirements, expand scope or declare prior owner-rejected work fixed.
3. Verify callable UE/MCP/UI/Python tools and installed versions; prefer native UE Control Rig/FK, Sequencer, Curve Editor, IK Rig/Retargeter and Animation Sequence editor as suitable. Use verified scripts/Blender only for scoped tasks where justified. No invented API or tool-use claims. Preserve rigid voxel forms, intended gaps, approved geometry, rest pose, sockets, unrelated clips and movement policy.
4. Quaternius is visual-reference-only: normal viewer playback, analyze poses/tempo, author original keys directly on own mannequin in UE; never download/extract/import/retarget its data, including related packs, cache or network. Other sources: explicit permission and verified license for import; otherwise visual only. Cube World is visual inspiration only.
5. Diagnose first; select smallest correct layer. For edit preserve unaffected tracks and verify after bake/reload. For transitions test actual input, contact phases, root/capsule and interruption. Two unsuccessful attempts: change method after diagnosis or BLOCKED. Never smooth away expressive motion or hide defects with camera/blend changes.
6. Required: run existing task-gate with animation contract and result; use real baseline and candidate exports, track-level comparison, per-requirement evidence and five independent verdicts (technical, motion, visual, gameplay, regression). Inspect full playback and actual PIE when applicable; matched cameras, normal/slow, key moments and hands close-up when relevant. If cannot visually inspect, NOT_RUN/BLOCKED, never PASS. Follow [review lab](../../../docs/agents/animation/REVIEW_LAB.md).
7. Update local checkpoint with current candidate, active assets, exact owner comments, status and evidence; report each requirement, changed tracks, tool calls, limitations, rollback and branch/SHA. READY_FOR_OWNER_REVIEW only after all required checks pass; owner alone ACCEPTED. Do not publish private refs/raw packs/recordings. Pilot is [RUN-02 checkpoint](../../../docs/agents/animation/RUN02_CHECKPOINT.md); verify local state before use.
