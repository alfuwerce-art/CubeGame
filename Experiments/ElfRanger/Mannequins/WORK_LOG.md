# Запись по чату о манекенах

25 ноября 2026 года владелец подтвердил, что крупноблочная форма женской головы соответствует его референсу. Он поручил сохранить результат в GitHub и перенести эту же голову на мужской манекен. Ниже указаны SHA локальных ревизий экспериментальной рабочей копии.

| Ревизия | Результат |
| --- | --- |
| `17d7ba6` | Локальная правка груди, живота и таза женского манекена, сверка пяти ракурсов. |
| `34425f5` | Увеличение груди и коррекция уступа над ягодицами по отметке владельца. |
| `6398447` | Перевод торса на воксельную сетку двух размеров и небольшая правка углов головы. |
| `bc1cfb5` | Правка участка под грудью и проба головы с пиксельным лицом. |
| `ff88e3c` | Возврат однотонной лицевой плоскости, коррекция лба и подбородка, ступени к затылку. |
| `ab6c162d3df6a82baef7deabc6f38313aa860295` | Крупноблочная голова по четырём ракурсам. Передняя грань челюсти вровень с лицевой плоскостью. Эту форму подтвердил владелец. |
| Сохранение пары | Исходная женская модель сверена побайтно, общая голова применена к мужскому манекену. Мужской торс и уши совпали с его предыдущим экспортом. Обе модели сохранены в эксперименте UE 5.9 и в переносимом glTF. |

Полный чат хранится в истории Codex. Эта запись содержит рабочие решения и результаты проверки.

## Использованный скилл

**`cubegame-voxel-asset`** из [локальной копии проектного скилла в репозитории](../../../.dsh/skills/cubegame-voxel-asset/SKILL.md). Он задавал границы работы с оригинальным воксельным ассетом, сверку ракурсов, экспорт и проверку меша. Назначение сверялось с [индексом навыков](../../../docs/agents/SKILLS_INDEX.md). GitHub использовался для сверки HEAD и PR и для публикации пакета.
