# D39 — DeepSeek Harness как основной локальный исполнитель

**Дата:** 2026-11-02  
**Статус:** ACCEPTED — назначение исполнителя и стратегия сравнения инструментов.

1. DeepSeek Harness (локальная установка на ПК продюсера) — основной AI-агент CubeGame для исследования Alpha, работы с Unity/C#, Git/GitHub и последующего переноса игровых механик.
2. Codex может быть испытан отдельно на этапах моделей/графики/анимаций, после чего сравнивается качество результатов. Не утверждать заранее, что конкретный агент обязательно лучше.
3. ChatGPT остаётся архитектором/ревьюером, продюсер утверждает игровой результат. Применяется ADR-0001 (модульный монолит).
4. Для CubeGame создать изолированный workspace и пользовательский пресет `cubegame-dev`. Прежние настройки и проекты DSH не изменять.
5. Перенос Alpha в Unity — целевая задача агенту на этапах S01–S04, **но текущий S00-G0 не пропускать**. Версия Unity, рендер, остальные архитектурные решения и начало Unity-кодирования ещё должны быть отдельно утверждены.
6. Серверы, мультиплеер и массовый графический контент — более поздние стадии; сейчас расходы на них запрещены.
7. Настройка/запуск DSH на локальном ПК из ChatGPT не выполнялись. Наличие конкретного пресета, Unity Hub/Editor и инструментов проверять отдельно.
