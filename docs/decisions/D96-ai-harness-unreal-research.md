# D96 — единая архитектура ИИ-разработки и изолированное исследование Unreal

**Дата решения владельца:** 2026-11-21  
**Статус решения:** `APPROVED_FOR_DOCUMENTATION_AND_REVIEW`; технический монтаж плагинов и запуск Unreal/Blender — `NOT_AUTHORIZED_YET`.  
**Опора:** D93 (собственная Unity-игра), D95 (единственный CubeGame, закрытие старой фабрики), три предоставленных владельцем транскрипта.

## Утверждено направление

1. Сохранить ранее подготовленные AGENTS, Project Memory, Active Stage, Data-Driven/Modular подходы, task handoff, приёмку владельца, ограничения Git/лицензий и закрытие Factoria. Короткий постоянный контекст дополняется skills/scripts/hooks, но не заменяется автоматическим саморедактированием правил.
2. Оформить единый набор проектных документов: Concept, GDD, Art Direction, ADR, Roadmap, Quality Attributes, решения и refs. Отдельные текстовые заметки не могут конкурировать с утверждёнными решениями.
3. Разработать отдельные **skills для DeepSeek Harness** под безопасную Unity-разработку, скрипты, диагностику, единичный voxel-ассет, риг, анимацию, арт-аудит и исследования. Техническая возможность skills/хуков должна быть **проверена в установленной версии DSH**.
4. Изучить кандидатов плагинов DSH по официальному каталогу (skill-filesystem, PowerShell/sandbox, LSP, subagents, hooks, MCP по необходимости). **Установка, включение и изменение глобальных профилей не разрешены** этим решением.
5. Зафиксировать **отдельный эксперимент Unreal 5.8**: Editor Python + C++ + Geometry Scripting + Control Rig/IK в изолированной среде, с сопоставлением результатов с Unity. Unreal не становится движком игры без отдельного решения.
6. Словарь имён и карта зависимостей должны опираться на **реальный код**, а не на придуманные автором/агентом примеры; Obsidian — необязательный viewer поверх единого Git-репозитория.
7. Не создавать второй meta-репозиторий и не перезапускать отменённую Factory под именем «ассетный skill». Массовая автоматизация моделей остаётся запрещённой; речь только об оценке и создании одного оригинального игрового объекта по отдельной задаче.

## Разграничение полномочий

- **Владелец** задаёт вид игры, утверждает технологии, художественные эталоны, приёмку и merge.
- **ChatGPT** — системная архитектура, синтез требований, независимое ревью.
- **DeepSeek Harness / Codex** — локальная реализация по определённому TASK, реальный код и инструменты, тесты, воспроизводимый отчёт.
- Самостоятельный rewrite AGENTS/GDD/decision registry, расширение scope, подключение оплачиваемых сервисов и открытый доступ к чужим каталогам запрещены.
