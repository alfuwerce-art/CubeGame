# D96 — архитектура AI-разработки
**Статус:** направление утверждено; новые внешние инструменты требуют предметной проверки.

Документы разделены на Concept, GDD, Art, Decisions, ADR, Roadmap, Quality, Active Stage и короткую Memory. AGENTS содержит минимальные общие инструкции. Профильные навыки — в `.dsh/skills/`, повторяемые проверки — в `tools/harness/`, технические ограничения — в разрешениях и CI. Изменения проверяются измеримыми тестами.

DeepSeek Harness и Codex выполняют отдельные задачи; владелец утверждает продукт и merge. При отсутствии проверенной возможности инструмента отмечать `NOT_INSTALLED/NOT_VERIFIED`. Для Unreal разрешён отдельный игровой пилот U0–U4 с C++-first, Python/MCP автоматизацией редактора. Существующая Unity-база сохраняется. Окончательный движок релиза выбирает владелец после проверки игрового результата.
