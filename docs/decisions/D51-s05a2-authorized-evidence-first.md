# D51 — авторизация ограниченного S05A-2: восстановление пропорций, креплений и tint

**Дата:** 2026-11-04. **Автор решения:** продюсер. **Основание:** [D50](D50-s05a1-accepted-s05a2-planning.md), [план S05A-2](../stages/S05A2_PROPORTIONS_TINT_PLAN.md), [матрица пробелов](../research/alpha2013/CHARACTER_VISUAL_GAPS_MATRIX.md), ревью ChatGPT `PASS WITH PLAN FIXES`.

**Статус:** `ACCEPTED` **как разрешение исполнения только S05A-2**, а не как приёмка результата этапа. `S05A-2 — AUTHORIZED / IN_PROGRESS` после начала исполнителем. `S05A-1` остаётся `ACCEPTED`. `S05B` и массовая конвертация — `NOT_AUTHORIZED`.

## 1. Утверждённые решения продюсера

1. **Не оставлять неизвестные параметры без исследования.** Сначала пытаться восстановить оригинальные per-part scale, offsets, pivots, гнездо оружия, назначение RGB-маркеров, hair tint и связанный путь матриц/рига по статическому коду, данным, измерениям и контролируемым запускам Alpha. Отчёт обязан перечислить фактические попытки, найденные свидетельства и причины, если значения остаются `UNKNOWN`. Не требовать невозможного доказательства полного оригинального рига для завершения ограниченного этапа.
2. **Технические приближения `PROXY_NOT_ALPHA` допустимы только после документированного исследования**; не выдавать их за оригинальные числа. Они требуют личного визуального решения продюсера, не получают автоматически `VERIFIED_ALPHA`.
3. **Контролируемый локальный запуск Cube World Alpha разрешён, если он поможет** установить пропорции, цвета, точки крепления и поведение. Использовать отдельную копию в локальной `.scratch/`, сохранять оригинальную установку и базы неизменными; предварительно проверить файл/источник на очевидные риски, избегать сети и изменения существующих сохранений; не запускать `Server.exe` и не менять бинарник, не ставить новое ПО без разрешения. Документировать время/цель/режим запуска и полученные доказательства. Это право действует **только для S05A-2**.
4. **Масштаб C+**: общий масштаб и индивидуальные коррекции групп только по необходимости; **голова и волосы — единая логическая группа масштаба** с общим authored frame. Не изменять отдельно масштаб головы без корректного сопряжённого изменения волос; не допускать двойного масштабирования вложенного узла. Масштаб оружия может корректироваться отдельно, но сохраняется гнездо в координатах кисти. Изменения должны быть детерминированны и конфигурируемы.
5. **Tint T3** как приоритетный технический эксперимент, если статические доказательства не укажут иной механизм: маска в шейдере, исходная палитра неизменна. Если обнаружен подтверждённый механизм Alpha — предпочесть точное воспроизведение и отдельно обосновать отступление от T3. Чистые RGB-маркеры автоматически не удалять; обычный красный декор должен сохраняться.
6. Внешний вид (front, side, three-quarter, до/после, одинаковая камера/свет/масштаб) **лично утверждает продюсер**. Технический PASS не означает художественного ACCEPTED. Не объявлять любые наблюдаемые пропорции текущего пилота ошибкой Alpha без доказательств.

## 2. Порядок исполнения и границы

- **Сначала доказательства, потом изменение конфигурации и Unity-пилот**. Продюсер разрешает контролируемые экспериментальные запуска Alpha, анализ существующих локальных источников и ограниченную реализацию для **того же одного гуманоида** в изолированной Unity 6000.3.27f2.
- Разрешено дополнить собственные инструменты метаданными, масками tint, тестами и документами; использовать один проверенный baseline S05A-1. Изменение производственного S04/Unity-проекта не разрешено.
- Категории достоверности: `VERIFIED_ALPHA` / `PARTIAL` / `UNKNOWN` / `PROXY_NOT_ALPHA`, при узких отрицательных находках использовать `NOT_FOUND_IN_INSPECTED_SET` как характеристику поиска, не как доказательство отсутствия в движке.
- `S05B`, пакетная конвертация (2857 моделей), создание других персонажей, новая художественная анимация, установка ПО без согласования, платные API, публикация оригинальных/конвертированных ассетов Alpha, merge в `main` и force push — **запрещены**.
- Альфа-скриншоты, игровые ресурсы и их визуальные производные — локально; в GitHub допустимы только собственный код, обезличенные метрики и текстовые описания. Для будущей распространяемой игры — собственные или лицензированные ресурсы.

## 3. Проверки и приёмка

- Не терять accepted baseline: Python `62/62`, Unity S05A-1 `69/69`, S05A-0 `19/19`; характерная сборка, 40 кадров PlayMode и успешная последовательность завершения Unity/exit 0.
- Для C+: world-space transform/mesh-проверки (не требовать изменения исходных координат Mesh при `localScale`), положения суставов, визуальной целостности, skin-alignment головы/волос ≥ 99%, крепления оружия drift ≤ 1e-3, отсутствие зеркалирования.
- Для T3: проверять цвета **по воксельным координатам** внутри и вне маски, не только по суммарной гистограмме; тест на декоративный красный вне маски.
- Локальные одинаково поставленные виды до/после; продюсер оценивает **каждый** предложенный художественный результат. `READY_FOR_REVIEW` — конечный статус исполнителя, `ACCEPTED` только после отдельного решения продюсера.
