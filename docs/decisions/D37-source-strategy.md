# D37 — источники исследования CubeGame

Статус: ACCEPTED — решение продюсера, 2026-11-02.
Рабочее название проекта: CubeGame; финальное название игры не утверждено.

1. Установленного экземпляра Cube World Alpha 2013 нет; его наличие больше не является блокером S00.
2. Механики Alpha 2013 изучаются через архивные видео, руководства, датированные материалы и технические исследования с обязательным указанием достоверности.
3. Cube World 2019 устанавливается через официальный Steam и исследуется агентом непосредственно на ПК.
4. Каждое предлагаемое для CubeGame правило Alpha утверждается отдельно. Ранее принятые D01–D36 сохраняются.
5. Наблюдения версии 2019 не выдаются за факты Alpha 2013 и наоборот.
6. Собственная игра остаётся Unity-проектом; версия 2019 является исследуемым экземпляром, не исходным Unity-проектом.
7. Цель S00 — сравнение систем и утверждение целевого набора механик, без разработки кода игры, платного хостинга и серверов.
