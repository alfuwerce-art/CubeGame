# D50 — приёмка S05A-1 и подготовка ограниченного плана следующего пилота

**Дата:** 2026-11-04. **Решение продюсера:** после финального архитектурного ревью ChatGPT `REVIEW PASS` утвердил закрытие `S05A-1` и **подготовку** следующего ограниченного этапа.  
**Статус решения:** `ACCEPTED` для **S05A-1**. Подготовка плана **S05A-2 (рабочий номер)** разрешена; **исполнение S05A-2 не авторизовано**. `S05B` и массовая конвертация по-прежнему `NOT_AUTHORIZED`.  
**Основание:** [D46](D46-asset-conversion-first.md), [D48](D48-s05a0-accepted-s05a1-draft.md), [D49](D49-s05a1-authorized.md), [отчёт S05A-1](../research/alpha2013/CHARACTER_ASSEMBLY_ANIMATION_PILOT.md) и финальный код-коммит [`b72f615`](https://github.com/alfuwerce-art/CubeGame/commit/b72f615f8079c8ebb62e8d438cbb3551a42c99c9).

## 1. Что принято

- `S05A-1 — ACCEPTED` **как ограниченный технический пилот**, а не как восстановленный оригинальный игровой персонаж.
- На локальных оригинальных ресурсах Alpha в **изолированном** Unity 6000.3.27f2 технически собран один гуманоид из **8 узлов** (торс, голова, волосы, 2 кисти, 2 стопы, меч). Работают иерархия, крепление меча и один **собственный** технический цикл `technical_walk_NOT_ALPHA`.
- Приняты исправления `S05A-1-REVIEW-FIX-01/02/03`: корректные координаты мешей (два прохода, сохранение исходного grid frame), совпадение 284/286 кожных вокселей головы/волос, реальная проверка Unity Transform-иерархии, запрет ложного PASS при сломанной сборке, безопасный жизненный цикл PlayMode, полный контракт аниматора на 8 частей.
- **По отчёту локального агента DeepSeek**, а не независимому запуску ChatGPT: Python `62/62 PASS`, Unity self-tests S05A-1 `69/69 PASS`, регресс S05A-0 `19/19 PASS`, конверсия 4 образцов PASS, сборка PASS, PlayMode 3× по 40/40 кадров, Unity exit 0 без `0xC0000005`; девять негативных сценариев ожидаемо дают FAIL/exit 1.
- ChatGPT выполнил финальное **ревью исходного кода и документации GitHub** (`REVIEW PASS`). Локальные Unity-тесты не запускал; локальную финальную демонстрацию независимо не принимал.

## 2. Открытые границы и риски

- `PROXY_NOT_ALPHA`: относительные масштабы модели и оружия, offsets, pivot и гнездо меча — пока технические приближения, **не восстановленные точные параметры Alpha**. 
- `PARTIAL / UNKNOWN`: семантика зелёных/синих RGB-маркеров и механизм подкрашивания волос. Успех skin-alignment (284/286) относится к конкретной проверенной паре.
- `UNKNOWN / NOT_REPRODUCED`: структура исходного рига и анимационный цикл оригинала не перенесены. Техническая ходьба не является оригинальной анимацией.
- Оригинальные и конвертированные ассеты Alpha **не разрешено публиковать** в открытом репозитории/использовать для распространяемого продукта без необходимых прав. Все такие ресурсы — только локально в `.scratch/`; для релиза нужны собственные или надлежаще лицензированные материалы.
- Остаются возможности укрепить проверку полного состава журнала событий и аварийного выхода; эти улучшения **не блокировали ограниченную приёмку** и не означают разрешение на новый производственный код.

## 3. Следующее направление — только подготовка

**Разрешено подготовить, но не исполнять** отдельное ТЗ / план с рабочим обозначением `S05A-2 — CHARACTER PROPORTIONS / ATTACHMENTS / TINT RESEARCH`:

1. Один прежний технический гуманоид, **никаких новых массовых моделей**.
2. Статическое исследование имеющихся доказательств Alpha о масштабах, offsets, pivot, взаимных пропорциях тела, оружия и гнезда; отделять подтверждённое от художественного приближения.
3. Отдельная карта неизвестного назначения RGB-маркеров и механизма tint/палитры волос, требования к безопасной экспериментальной проверке.
4. План **одного** ограниченного Unity-пилота визуального выравнивания на той же локальной технической модели с наглядными видами (front/side/3⁄4), сравнением до/после и критериями ручного утверждения продюсером по D35.
5. Таблица `VERIFIED_ALPHA / PARTIAL / UNKNOWN / PROXY_NOT_ALPHA`, список необходимых доказательств, рисков, тестов, запретов, входных и выходных критериев.

В рамках этой авторизации **можно читать репозиторий, составлять документацию и исследовательский план, но нельзя проводить новые Unity-опыты, менять модели/код, запускать Alpha, делать batch conversion, устанавливать ПО или начинать S05A-2**. Исполнение — только после отдельного решения продюсера. `S05B — NOT_AUTHORIZED`.
