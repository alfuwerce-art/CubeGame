# D54 — режим внутреннего исследовательского прототипа Alpha → Unity

**Дата:** 2026-11-05. **Автор уточнения:** продюсер. **Статус:** `ACCEPTED` как уточнение рабочего режима исследовательских задач D46/D51–D53; не означает приёмку `S05A-2` и не даёт дополнительных разрешений на `S05B`.

## 1. Цель и текущая стадия

Сейчас CubeGame — **локальный некоммерческий исследовательский прототип переноса архитектуры и содержимого Cube World Alpha 2013 в Unity**. Проект будет существенно перерабатываться; для выпускаемой игры предполагается использовать другие, собственные или надлежаще лицензированные анимации.

**Практический приоритет сейчас — научиться получать и воспроизводить существующие анимационные данные оригинала**, а не вручную придумывать замену, пока конвейер переноса не отлажен.

## 2. Что разрешено DeepSeek в рамках уже авторизованного исследовательского пилота

- Изучать локальную копию оригинальной игры, её допустимо полученные данные, статические структуры, матрицы, state/keyframe таблицы и функции анимации.
- Извлекать и сохранять **локально** временные исследовательские копии поз, кривых, костных матриц, ключевых кадров и других данных, если это необходимо для технической проверки переноса и доступно с учётом применимого права и условий использования.
- Использовать эти данные **в локальном изолированном Unity-пилоте**, создавая инструмент захвата/конвертации/воспроизведения/сравнения; не заставлять агента заменять их самодельными анимациями исключительно потому, что данные происходят из Alpha.
- Выполнять для одного выбранного гуманоида разрешённые D53 эксперименты с одной атакой, затем оформлять план воспроизводимого переноса других анимаций. Работы ограничены уже утверждённым этапом; S05B не разрешён.
- Хранить исследовательские бинарные/анимационные данные в `.scratch/` или ином закрытом локальном каталоге, а в **публичный** GitHub публиковать только собственные инструменты, отчёты, обезличенные метрики и код без заимствованных защищённых данных.

## 3. В чём сохраняется правовая граница

- `Некоммерчески` **не означает автоматически** `всё разрешено по авторскому праву`. Допустимость конкретных копий и действий зависит от законности экземпляра, применимой юрисдикции, условий использования и предусмотренных законом исключений.
- Чужая публикация материалов на GitHub **не доказывает наличие лицензии** или прав на их дальнейшее использование. Проверять лицензию и происхождение каждого внешнего репозитория по мере использования.
- Удалять из технического задания безусловные формулировки «нельзя извлекать/использовать оригинальные анимации в локальном прототипе». Вместо них: `исследовать и использовать локально для проверки технического переноса в пределах применимых прав; не распространять оригинальные защищённые материалы`.
- Перед **публичным распространением/продажей** CubeGame отдельно провести проверку лицензионного статуса и заменить/очистить оригинальные анимации и другие защищённые ресурсы, на которые нет прав. **Пользователь заявил намерение переработать игру и анимации до релиза; замена ещё не выполнена и не проверена.**

Не изменять оригинальный `Cube.exe`, оригинальную установку или существующие сохранения; не запускать `Server.exe`; не устанавливать новые инструменты без отдельного согласования, не менять production Unity/S04, не выполнять merge в `main` или force push.
