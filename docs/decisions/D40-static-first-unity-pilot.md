# D40 — исследование Alpha и Unity-пилот параллельно

**Дата:** 2026-11-02
**Статус:** ACCEPTED (прямое решение продюсера)
**Название:** CubeGame — рабочее название проекта, не утверждённое название игры.

## Решение
1. Главный исполнитель — DeepSeek Harness. Проводит статический разбор локальных файлов Alpha 2013 и использует исследовательский проект [CubeWorld-Reversal](https://github.com/qad3n/CubeWorld-Reversal) как справочную информацию. При спорных случаях проверяет поведение игры выборочно, не заменяет полный анализ игровым прохождением.
2. Разрешён **ограниченный пилот Unity** параллельно с исследованием Alpha. Не ждать полной инвентаризации всех подсистем.
3. Первый пилот: небольшой процедурный регион, задаваемый seed, временный персонаж, третьеличная вращаемая камера, ходьба и простое отображение координат/seed. Это **не** полный перенос игры и не финальное качество моделей.
4. Unity Hub и Unity Editor **не установлены** по последнему отчёту локального агента. Разрешено подготовить план установки официальной Unity 6.3 LTS + URP; фактическую загрузку/установку, лицензирование и повышение прав согласовать с продюсером в локальной сессии. Выбранная версия/URP — рабочая гипотеза, производственное утверждение после проверки пилота.
5. **Blender не установлен**. В первом пилоте он не нужен; использовать собственные простые геометрические примитивы. Blender готовить к S05A, где будет пилот модели и анимации, с отдельным выбором версии.
6. Модульный монолит ADR-0001 уже утверждён. Конкретные размеры чанков, интерфейсы, частота симуляции, формат сохранений и визуальные стандарты решаются после измерений.
7. Исходная Alpha: `D:\Games\Cube world`, не изменять оригинальные файлы. Не публиковать её бинарники/ассеты и не переносить декомпилированные C++-тела напрямую в Unity: писать собственные спецификации и реализацию. Старый G0 имеет ограничения: неофициальное происхождение образца и неполная независимая проверка.
8. Два трека обязаны иметь **разные ветки и отчёты**, проверки и статус READY_FOR_REVIEW. Никаких самостоятельных merge в main; другие проекты DSH не изменять. Сессия только `workspace-write/ask`.
9. Не запускать мультиплеер, сервисы за деньги, LLM NPC, массовый моделинг и графику сверх минимального пилота.
