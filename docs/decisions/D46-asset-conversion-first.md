# D46 — Приоритет конвертации моделей и анимаций Alpha → Unity

**Дата:** 2026-11-03  
**Решение:** ACCEPTED — утверждён принцип работы, но **не запуск следующего этапа**.  
**Дополняет:** D31, D32 и D35.

## Утверждено продюсером

Перед массовым изготовлением собственных моделей CubeGame сначала исследовать возможность конвертации существующих 3D-ресурсов Cube World Alpha 2013 в Unity 6.3. Исходные модели и анимации рассматриваются **отдельно**: успешный перенос геометрии не доказывает перенос рига/анимаций.

Последовательность: изучение ресурсов и форматов → проверка уже существующих инструментов → эксперимент с тремя моделями (персонаж, монстр, оружие) → импорт и осмотр в Unity → отдельное исследование ригов и анимаций → решение продюсера о дальнейшей конвертации или создании собственных ассетов.

**Не утверждено:** что конвертация реально работает, что она применима ко всем моделям, что анимации можно извлечь, что конвертированные модели пригодны для распространения в собственной игре.

## Ограничения

- Оригинальные ресурсы Alpha только для локальной технической проверки; **нельзя публиковать их или конвертированные копии** в публичном GitHub без соответствующих прав.
- Для будущего релиза — права на ресурсы должны быть подтверждены; иначе заменить моделями и анимациями собственного производства.
- Никакой массовой конвертации или ручного моделирования пачками до оценки пилота.
- Прежде чем создавать новый конвертер, исследовать существующие совместимые инструменты.
- D32 действует: после проверки переноса — один пилот собственной/переработанной модели, тест старой анимации (если переносима), одна новая анимация, запуск в Unity.
- D35 действует: каждую переработанную модель лично принимает продюсер.
- Стиль voxel/cube сохраняется, но окончательная графика заранее не утверждается.
- S04-EQUIPMENT-COMBAT не изменяется этим решением и остаётся READY_FOR_REVIEW; запуск S05 требует отдельного разрешения.
