# D66 — магическое дерево, практика боя, свитки, летописи и камни снаряжения

**Дата:** 2026-11-06  
**Статус:** ACCEPTED на уровне направления геймдизайна по прямому решению продюсера; подробные правила, списки и баланс DRAFT/OPEN.  
**Приоритет:** D66 **заменяет** часть D65 про два главных дерева и гибрид боевого дерева. Остальные положения D65 о реальных физических попаданиях, перекатах, промахах и выборе потери инвентаря **сохраняются**.  
**GDD:** [§3.20](../game-design/GDD_DRAFT.md).

## Утверждено продюсером

1. **Единственное дерево развития — магическое.** Боевое дерево **отменено**. Боевая компетентность персонажа растёт самостоятельно от практики, по принципу *learning by doing* (ориентир — Kenshi).
2. **Комбинации и специальные боевые техники** открываются через **летописи** и другие знания, а не через боевое дерево. Боевая тренировка помогает лучше применять оружие и полученные приёмы.
3. **Новые умения** изучаются через **свитки**. Разделение между свитком, летописью, их получением и конкретными категориями техник нуждается в разработке; нельзя автоматически превращать одни в другие.
4. **Повышение общего уровня** даёт возможность улучшить часть магии через дерево. Уровень сохраняется, несмотря на аналогию с Kenshi, где общего уровня нет. Утверждённый D30: без максимального уровня, дерево конечно.
5. **Шесть основных магических направлений:** огонь, чистая энергия, молния, земля, **некромантия**, **чёрная энергия**. Конкретные способности и семантика каждой школы пока не приняты.
6. **Магические направления можно сочетать через узлы/связи дерева** по принципу гибридных билдов PoE 2. Конкретные рецепты, связи, ограничения и стоимость сочетаний OPEN.
7. **Камни/руны для экипировки** с модификаторами, вдохновлённые PoE 2. Примеры самого продюсера: дополнительный **урон молнией** на оружии и усиление **кровотечения меча**. Система должна быть совместима с ростом умений от практики и физическим контактом оружия.
8. Уже принятые **D65**: фактические контакты меча с телом (сильный/неполный/касательный), реальные промахи и перекаты; выбор при создании героя «сохранять весь инвентарь / терять весь инвентарь»; D61: сон и возрождение.

## Проверенный референс — разделение механик PoE 2 (источники изучены 2026-11-06)

- **Skill Gems** предоставляют активные умения, **Support Gems** изменяют конкретные умения и размещаются в интерфейсе умений, **не являются камнями экипировки**. Источники: https://pathofexile2.com/ (официальное описание), https://www.poe2wiki.net/wiki/Guide:PoE2_overview_for_PoE1_players.
- В **гнёзда оружия и брони** устанавливаются отдельные **руны**, которые дают модификаторы снаряжения (например, добавочный урон молнией, сопротивления, HP/ману). https://poe2db.tw/Rune ; https://www.poe2wiki.net/wiki/Version_0.5.0 (патч Run es of Aldur, дополнения системы рун).
- **Kenshi:** независимый рост умений через действия, а не через общий пул XP/дерево. https://kenshi.fandom.com/wiki/Statistics ; https://kenshi.zone/en/skills-stats. **CubeGame сохраняет общий уровень по D30.**
- **Нельзя переносить буквально** числа, дерево, списки камней/заклинаний PoE 2 или формулы Kenshi; брать принципы и проектировать собственные правила и контент.

## Предложенный контракт для следующего обсуждения — DRAFT

| Слой | Источник прогресса | Результат |
|---|---|---|
| Практический боевой навык | Осмысленное применение оружия, блока, уклонения в бою | Контроль оружия, эффективность применения, владение стилем |
| Летопись | Находка/обучение особому боевому знанию | Доступ к боевой комбинации или приёму; эффективность — от практики |
| Свиток | Исследование мира/торговля/награда/учитель | Новое активное умение; фактический список OPEN |
| Общий уровень | Опыт персонажа, по рамке D30 | Очки магического дерева |
| Магическое дерево | Вложение очков | Специализация школы и связи между направлениями |
| Руны снаряжения | Найденный/изготовленный/купленный камень, подходящий предмет с гнездом | Модификатор оружия или доспеха; может сочетаться с магией, но не заменяет обучение |

**Предлагаемый принцип формулы (не утверждён):** физическое касание оружия должно определять возможность нанесения как основного, так и добавочного элементального урона. Руна молнии **не должна превращать промах в попадание**. Касательный удар наносит меньший контактный урон; точное масштабирование элементального эффекта и кровотечения остаётся открытым.

**Пример гибридов (НЕ УТВЕРЖДЕНЫ):** земля + молния → проводящие каменные конструкции; некромантия + чёрная энергия → усиленные призывы; чистая энергия + молния → энергетический разряд. Не объявлять конкретные заклинания каноном без визуальных/геймплейных эталонов.

**Ограничения/риски для будущего прототипа:** слоты рун и совместимость типов оружия, возможность извлечения/замены камней, наложение эффектов, сочетания со свитками и пассивами, антиэксплойт практики, предотвращение множителей взрывного урона и спама статусов, реальные контакты оружия в Unity без пропуска быстрых ударов, баланс экономики редких рун. Все точные параметры OPEN.
