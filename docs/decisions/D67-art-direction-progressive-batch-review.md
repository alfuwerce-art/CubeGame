# D67 — M1 Art Direction и прогрессивная пакетная приёмка

**Дата:** 2026-11-06  
**Статус:** **ACCEPTED** прямым решением продюсера.  
**Относится к:** [Art Direction](../art/ART_DIRECTION_DRAFT.md), [Production Pipeline](../production/PRODUCTION_PIPELINE_DRAFT.md), [D31–D36](../planning/DECISIONS_001-036.md).

**Приоритет:** D67 заменяет в D35 **только требование личного утверждения каждой отдельной переработанной модели**. Требования начать с эталонов и сохранять художественное решение продюсера сохраняются; D32 о связи модели и анимации действует.

## Решение

1. **M1 — целевой визуальный стиль**: качественная визуальная эволюция Alpha при сохранении кубической пластики и узнаваемости. M0 → M1 как технический порядок остаётся.
2. **Растительность:** многослойные, объёмные, просматриваемые кроны с просветами; базовая текстура травы вместе с густыми объёмными травяными пучками и 3D/voxel моделями растений разных размеров. Свет, вода, тени и окружение более проработаны, игровая читаемость сохраняется.
3. **UI:** новая оригинальная компоновка и размещение элементов для удобства, с сохранением духа исходного интерфейса без его буквального копирования.
4. **Художественная приёмка:** сначала согласовать эталоны каждого семейства моделей и анимаций, а также окружения, воды и света; затем за проход оценивать **несколько моделей вместе с анимациями**; после каждого успешного прохода масштабировать партии **мультипликативно/в сторону экспоненциального роста** с поправками по фактическому качеству и затратам. Продюсер утверждает **эталоны и каждую партию**, а не каждую отдельную модель.
5. При несоответствии исправить и повторно показать партию; не наращивать объём, если упало качество или выявлена регрессия. Технические проверки каждого ассета сохраняются.
6. **Каталог локальных референсов** `D:\Projects\референсы для CudeGame` — оставить без перемещений/переименований/копирования, включить в список рабочих каталогов только для изучения. Агенты с доступом изучают нужные референсы сами. Это ориентиры желаемого качества и направления, а не целевые изображения для прямого копирования. Содержимое папки через GitHub не просматривалось.
7. **Art Direction принят целиком как регламент.** Конкретные эталоны, параметры и игровые ассеты утверждаются по фактическим прототипам, без выдумывания RGB/размеров/форматов до измерений.

## Границы

- Принятие художественного руководства не означает, что визуальные эталоны уже изготовлены, проверены или что права на сторонние материалы получены.
- Новый игровой этап этим решением не открыт: `S05A-2 IN_PROGRESS / REVIEW OPEN`, `S05B NOT_AUTHORIZED`.
- Историческое D35 остаётся в реестре; при споре о поштучной приёмке действует более позднее D67.
