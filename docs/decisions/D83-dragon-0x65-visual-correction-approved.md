# D83 — Dragon 0x65: визуальная коррекция `dragon_0x65_v1` утверждена для игры

**Дата:** 2026-11-09  
**Источник:** прямое решение продюсера в сессии Claude Code по issue #7 («Принять коррекцию»).  
**Статус:** APPROVED. Это **не** `ACCEPTED` S05B-2 и **не** запуск M0-01+.  
**Основание:** [S05B2_DRAGON_0X65_VISUAL_REVIEW_FIX](../reports/S05B2_DRAGON_0X65_VISUAL_REVIEW_FIX.md),
ветка `review/s05b2-dragon-visual-fix` @ `91d7e96`.

**Номер:** D70–D82 уже заняты решениями продюсера в других ветках (`docs/gdd-first-draft-20261106`), поэтому D83.

## Решение
1. Предложение `dragon_0x65_v1` принимается как облик дракона **в игре**: передние лапы `offset_hand z 1 → −7.5`,
   задние `offset_foot z 1 → −9`, корень хвоста `offset_tail y −16 → −11`. Голова, корпус, модели, масштабы,
   якоря и формулы анимаций — без изменений.
2. Статус всего, что сделано с коррекцией: `VISUAL_CORRECTION_APPROVED_NOT_ALPHA` — утверждённое отклонение от
   Alpha, **не** перенесённый результат Alpha и не Alpha-паритет.
3. Игровые задания вида 0x65 получают коррекцию по умолчанию (`visual_correction.GAME_DEFAULTS`,
   `transfer_planner.job_for`) и принимают только библиотеку действий, испечённую с этой коррекцией
   (риг `alpha_creature/95251fe7e5`). Библиотека, испечённая для Alpha, для игры отклоняется.
4. Alpha-паритет сохраняется как эталон: оракул `drawModel`, тесты дефекта и проверка D69 по-прежнему идут без
   коррекции и доказывают, что исходные данные Alpha не изменились.

## Не решено этим решением
- Хитбокс дракона (в Alpha — человеческий, 0.96×0.96×2.16) — игровое правило M0.
- Крылья (`dragon-wing.cub` в Alpha не рисуется) — отдельный вопрос, коррекция их не добавляет.
- Пересборка продюсерского проекта `FullCatalogReview` с новым драконом — по запросу.

## Границы
S05B-2 остаётся `READY_FOR_REVIEW`; `main`, S04, ветка и папка DeepSeek не затрагиваются; ассеты Alpha — только
в `.scratch`.
