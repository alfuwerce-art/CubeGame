## 2. Git-поток (обязательный)
1. Каждый агент фиксирует базовый SHA, читает `PROJECT_MEMORY.md`, `docs/ACTIVE_STAGE.md`, `AGENTS.md`, `docs/agents/MULTI_AGENT_WORKFLOW.md`, этот D71.
2. **Сохранить прежде всего untracked черновики DeepSeek #5**: два `M0_00B_*.md` из основного дерева **копированием** в новый worktree после его создания, убедиться в размерах/содержимом; не удалять из основной папки до подтверждённого push. Не коммитить чужие изменения `ReviewSceneBuilder.cs` и файлы #4/#7 в ветке DeepSeek.
3. Каждый агент делает отдельные логические коммиты **в собственной ветке**, пушит по готовности пакетов (не только в самом конце), прикладывает SHA, честные PASS/FAIL/SKIP и open blockers к своей issue.
4. **Последний завершивший работу НЕ имеет права автоматически коммитить всё дерево или push чужих изменений**. После двух завершений нужен отдельный интеграционный прогон: compare/diff, ручное разрешение конфликтов, полные тесты, личное одобрение продюсера и только после этого merge/cherry-pick/PR. Пока нет такого поручения — публикация только своих веток.
5. Перед Git-командами проверить `git status --short`, `git branch --show-current`, `git worktree list`; никакого `git add .` без проверки списка файлов.
6. Сбои, неоднозначная локальная чистота, одновременная запись в одну директорию, конкурирующие изменения контракта — **STOP_AND_REPORT**, не автоматический force-reset/overwrite.
