# D38 — Alpha 2013 снова основной источник S00

**Проект:** CubeGame (рабочее имя; название игры не выбрано)  
**Статус:** ACCEPTED — на основании сообщения продюсера 2026-11-02  
**Источник:** продюсер сообщил о скачанной игре 2013 года в `D:\Games\Cube world`. Наличие папки, точный билд и возможность запуска локальным агентом **ещё не проверялись**.

## Решение

1. **Прямое исследование Alpha 2013** вновь первично для S00; использовать сообщённую папку как кандидат на локальный источник.
2. Сначала проводить **S00-G0 — проверку версии, файлов, безопасности и запуска**. Только после подтверждения реально запускаемой Alpha выполнять игровые тесты и ставить статус `ALPHA_DIRECT_VERIFIED`.
3. Архивные источники остаются дополнением для редких механик и проверки расхождений.
4. Cube World 2019 **не требуется для старта или завершения базового исследования Alpha**. Её возможное исследование/сравнение — дополнительная дорожка, только при наличии клиента и отдельной необходимости.
5. **D37 сохраняется как историческая запись** решения, принятого когда Alpha считалась недоступной. D38 заменяет в D37 допущения «Alpha недоступна» и «Steam 2019 требуется обязательно», не изменяя правило разделения версий.
6. D01–D36 и ADR-0001 сохраняются, 12 кандидатов сравнительной матрицы **не утверждаются автоматически**.
7. S00 исследует и документирует, но не начинает Unity-кодирование, платные сервисы и массовую переработку моделей.

## Проверка S00-G0

- `Test-Path -LiteralPath 'D:\Games\Cube world'`.
- Перечисление файлов (включая исполняемые, конфиги, ресурсные архивы), версия и SHA-256 найденных EXE/DLL.
- Никаких модов, патчей и посторонних исполняемых установщиков. Для копии неизвестного происхождения — локальная проверка безопасности перед запуском; не выполнять подозрительные скрипты и не запрашивать повышение прав без явного согласования.
- Запуск игры после проверки, запись наблюдаемого меню/версии, создание тестового героя/мира, выход и перезапуск без изменения исходного каталога.
- Если запуск невозможен — `BLOCKED_CLIENT_VERIFICATION`, а не сообщение о якобы изученной Alpha.
