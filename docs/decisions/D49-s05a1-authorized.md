# D49 — авторизовано исполнение S05A-1 (сборка одного персонажа и анимационный пилот)

**Дата решения:** 2026-11-04. **Автор решения:** продюсер. **Зафиксировал:** DeepSeek Harness (исполнитель), без самоприёмки.
**Статус:** `ACCEPTED` (разрешение на исполнение `S05A-1`).
**Основание:** [D46](D46-asset-conversion-first.md) (conversion-first), [D47](D47-s04-accepted-s05a0-authorized.md), [D48](D48-s05a0-accepted-s05a1-draft.md) (S05A-0 `ACCEPTED`, разрешена подготовка ТЗ), [черновик ТЗ S05A-1](../stages/S05A1_CHARACTER_ASSEMBLY_ANIMATION_DRAFT.md), [отчёт S05A-0](../research/alpha2013/MODEL_CONVERSION_PILOT.md).

## 1. Что решено

1. `S05A-0` остаётся **`ACCEPTED`** (D48); не переоткрывается.
2. Продюсер передал исполнителю ТЗ `S05A1-CHARACTER-ASSEMBLY-ANIMATION-01` — это **отдельное разрешение** выполнить **только `S05A-1`**.
3. `S05A-1` — пилот сборки **одного** технического персонажа-человека из отдельных `.cub`-частей, исследование маркеров/тинтов/масштабов/pivot, статическое исследование системы анимаций Alpha и одна проверяемая анимация на собранной модели в изолированной Unity 6000.3.27f2.
4. `S05B` (пакетное производство), массовая конвертация 2857 моделей и любые новые этапы **не разрешены**.

## 2. Границы исполнения

**Разрешено:** чтение `D:\Games\Cube world` (`mode=ro&immutable=1`); статический анализ `Cube.exe` и реконструкции; расширение собственных инструментов `tools/alpha_models/` (маркеры, метаданные частей); изолированный Unity-проект; один персонаж, одна-две технические анимации; локальные изображения и отчёты.

**Запрещено:** запуск `Cube.exe`/`Server.exe`; изменение исходных баз; публикация оригинальных и конвертированных ассетов (`.cub`, `.cubdec`, `.obj`, `.mtl`, PNG с моделями) в GitHub; массовая конвертация; десятки персонажей/анимаций; изменение production-проекта Unity, сцен S04, боевых формул; установка ПО (Blender и др.); платные сервисы; merge в `main`, force push, переписывание принятой истории.

## 3. Достоверность и статусы

1. Каждый восстановленный параметр (часть, offset, pivot, scale, анкор, тинт, анимация) получает статус `VERIFIED_ALPHA` / `PARTIAL` / `UNKNOWN` с указанием источника (код `Cube.exe`, данные `.cub`, исследование S00-R01/R02).
2. Если оригинальные offsets/pivots/иерархия не восстановлены, допускается **явно маркированная** техническая сборка `PROXY_NOT_ALPHA`; она не выдаётся за поведение Alpha.
3. Один собственный тестовый анимационный цикл допустим как техническая проверка конвейера (D32), но не как художественная анимация.
4. По D35 любая **переработанная** художественная модель требует личного утверждения продюсера; технический пилот не означает художественную приёмку.
