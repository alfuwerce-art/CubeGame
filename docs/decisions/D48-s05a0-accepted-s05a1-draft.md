**Основание:** [D46](D46-asset-conversion-first.md), [D47](D47-s04-accepted-s05a0-authorized.md), [отчёт S05A-0](../research/alpha2013/MODEL_CONVERSION_PILOT.md).

## 1. Принято

- `S05A-0 — ACCEPTED`: подтверждён технический пилот декодирования/конвертации `.cub` и отображения **3 выбранных образцов + 1 части персонажа** в **изолированной** Unity 6000.3.27f2 через прямой Mesh с vertex colors и OBJ/MTL.
- Финальные исправления `S05A-0-REVIEW-FIX-01` приняты по ревью ChatGPT (`PASS`): строгий вердикт Unity по всем ошибкам, проверка комплектности, пофасетное сравнение OBJ с исходной воксельной сеткой, отрицательные сценарии.
- По **отчёту локальных прогонов DeepSeek**: Python **42/42 PASS**, Unity validator self-tests **19/19 PASS**, четыре негативных Unity сценария распознаются как FAIL; четыре модели импортированы, пофасетные отклонения = 0. GitHub-код и тесты проверены ChatGPT; ChatGPT **не запускал Unity независимо и не осматривал локальные PNG**.
- В Unity OBJ ModelImporter обнаружено и документировано **зеркалирование по X**; прямой Unity Mesh сохраняет ориентацию выбранных образцов. Сохранение количества граней/формы не значит готовность рига или полноценной модели.

## 2. Не принято и не доказано

- Не доказано, что **все 2857** моделей конвертируются и корректно собираются в Unity как игровые сущности; пакетная конвертация не запускалась.
- Маркерные RGB-воксели пока выводятся как видимая геометрия; семантика анкоров и тинта не восстановлена.
- Масштаб/смещения/иерархия составных моделей и pivot не восстановлены.
- Перенос исходных анимаций/ригов, state→clip/pose mapping и крепление оружия не доказаны. Отсутствие отдельных файлов анимаций в исследованном наборе — **предварительный результат**, не доказательство отсутствия всех анимационных данных в логике/ресурсах.
- **Право на распространение** моделей/экспортов Alpha не установлено. Оригинальные и конвертированные защищённые ассеты остаются только для локальных технических исследований; для релиза — собственные ресурсы либо необходимое разрешение правообладателя.
