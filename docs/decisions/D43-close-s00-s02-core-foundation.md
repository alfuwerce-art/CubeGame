# D43 — закрытие S00-R02 (`ACCEPTED`) и авторизация этапа S02-CORE-FOUNDATION

**Дата:** 2026-11-03. **Автор решения:** продюсер. **Зафиксировал:** DeepSeek Harness (исполнитель), без самоприёмки.
**Статус:** `ACCEPTED` (решение продюсера, переданное в задаче `S00-CLOSE-AND-S02-CORE-FOUNDATION`).
**Связанные решения:** [D41](D41-research-before-port.md) (research-first), [D42](D42-alpha-numbers-as-references.md) (`ACCEPTED`, числа Alpha как референсы), [ADR-0001](../architecture/ADR-0001-modular-monolith.md) (модульный монолит).

## 1. Что решено

1. Исследовательский этап **S00-R02 закрывается со статусом `ACCEPTED`** с явно зафиксированными ограничениями.
2. Закрытие этапа **не** является доказательством полного соответствия Cube World Alpha 2013.
3. Все открытые вопросы сохраняют статусы: `UNKNOWN`, `PARTIAL`, `BLOCKED` (в частности OQ-22 `PARTIAL`, OQ-23 `OPEN/BLOCKED`, OQ-24 `PARTIAL`).
4. Новые запуски Alpha 2013 **не проводятся** без отдельного разрешения продюсера (лимит 4/4 исчерпан).
5. Авторизуется следующий ограниченный этап разработки Unity: **`S02-CORE-FOUNDATION`**.
6. D42 остаётся в силе без изменений.

## 2. Границы приёмки S00-R02

| Что принято | Что НЕ принято этим решением |
|---|---|
| Объём, структура и проверяемость исследования (пакеты A…L рассмотрены, есть реестр источников, матрица проверок, эталонные скрипты) | Полное восстановление всех механик Alpha 2013 |
| Достаточность данных для реализации прогрессии, статов персонажа, статов предметов и сохранений | Полные боевые формулы, лут-таблицы, AI, подземелья, ассеты |
| Эталонные числовые значения, воспроизводимые скриптами (`alpha_curves_reference.py`, `alpha_item_stats_reference.py`) | Масштаб единиц движения (OQ-23) и позиция в сейве (OQ-22) |

Пакеты A…L остаются `PARTIAL` (кроме явно `DIRECT`/`STRONGLY_SUPPORTED` фрагментов); статусы `PARTIAL`/`OPEN` не повышаются при закрытии этапа.

## 3. Границы S02-CORE-FOUNDATION

**Разрешено (первая партия, только это):**

- Модуль A — Progression: уровень, XP, стоимость уровня, `levelFactor`, `starFactor`.
- Модуль B — Character Stats: базовые характеристики, `calcMaxHealth`, подтверждённая часть `calcWeaponDamage`, класс/специализация, подтверждённые бонусы экипировки.
- Модуль C — Items Foundation: тип/подтип/уровень/редкость/seed/модификаторы, базовые вычисляемые статы.
- Модуль D — Persistence Foundation: версия формата, состояние персонажа и тестовых предметов, save/load в `Application.persistentDataPath`, защита от повреждённых данных и проверка версий.

**Запрещено:** переделывать генерацию мира; полноценная боевая система; AI/NPC; питомцы; подземелья; квесты; модели и анимации; URP; управление Alpha через DSH; выдавать неизвестные числа Alpha за восстановленные; merge в `main`.

**Архитектура:** ADR-0001 — чистая логика отделена от данных, сохранений и Unity-представления; без громоздкой инфраструктуры ради четырёх модулей; сначала штатные возможности Unity.

## 4. Следствия

1. Активный этап — `S02-CORE-FOUNDATION`, ветка `stage/s02-core-foundation` от проверенного `stage/s01-unity-pilot` @ `a884278`.
2. Статус S02 по завершении партии — **`READY_FOR_REVIEW`**, не `ACCEPTED`.
3. `PLACEHOLDER_NOT_ALPHA` (D42) применяется к любым будущим скоростным/движенческим параметрам; прогрессия и статы предметов опираются на воспроизводимые референсы.
4. S01 Pilot остаётся `READY_FOR_REVIEW`: использование его кода как технической основы не является приёмкой пилота.
5. OQ-23 (масштаб движения) не блокирует S02 и остаётся открытым.
