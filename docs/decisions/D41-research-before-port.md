# D41 — исследовательский контур перед дальнейшим переносом CubeGame

**Дата:** 2026-11-03
**Статус:** ACCEPTED — решение продюсера.
**Контекст:** [D40](D40-static-first-unity-pilot.md) разрешал исследование Alpha и ограниченный Unity-пилот параллельно. Пилот теперь, по отчёту агента, выполняется в Unity 6.3 LTS, но последний коммит пилота ещё локальный.

## Утверждённый порядок
1. Приоритет DeepSeek: **максимально предметное исследование устройства Cube World Alpha 2013** по локальным файлам, восстановленной архитектуре и документированному поведению, а не догадки при написании Unity-кода.
2. Обязателен повторяемый цикл для КАЖДОЙ системы: инвентаризация файлов и функций → структурная карта зависимостей → гипотезы/алгоритмы → проверка данными и точечным запуском Alpha → собственная спецификация CubeGame → архитектурное решение и согласование → самостоятельная реализация C# в Unity → тесты сопоставления с Alpha.
3. Источники с иерархией достоверности: локальные измерения оригинальной игры и файлов; декомпиляция/RTTI/структуры с оценкой уверенности; современные игре **документы и видео 2013 года**; поздние wiki с точным указанием версий; Unity 6.3 official documentation. Информация из релиза 2019 не автоматически относится к Alpha.
4. Для непонятных участков агент сначала ищет уточнение внутри файла/структуры/вызывающих функций; затем независимое наблюдение в игре; далее архивные материалы и документацию, при необходимости обращается к ChatGPT с точным набором гипотез и доказательств. При отсутствии ответа сохраняет `UNKNOWN`, а не выдумывает механики.
5. **Не переписывать в Unity движок Plasma:** D3D9-рендер, окна/ввод, шрифты, физическое представление, анимационные автоматы, ресурсы и Editor/тесты по возможности обеспечивать штатными возможностями Unity; собственный код — для специфической RPG-логики, мира, генерации, предметов/квестов и сохранений. Unity-пакеты выбирать после проверки совместимости/профилирования, а не ставить все подряд.
6. Не переносить защищённый декомпилированный C++ текст и закрытые ассеты в публичный CubeGame; анализ технических идей/поведения не равен лицензии. Фиксировать источник и границу использования, новую реализацию писать собственным кодом.
7. Уже созданный **S01-PILOT сохраняется**; не начинать массовую реализацию новых подсистем до исследовательской приёмки. Локальный коммит `a884278` агент может запушить в существующую `stage/s01-unity-pilot` после проверки diff; **слияние в main НЕ разрешено автоматически**.
8. URP — **APPROVED_FOR_SEPARATE_MIGRATION_TRIAL** на выделенной ветке после фиксации рабочего пилота; обратимость и регрессии обязательны. Экспериментальный `com.unity.pipeline` — **DEFERRED / OPTIONAL**: не устанавливать автоматически, сначала доказать выгоду относительно работающего CLI/Editor batchmode и предложить отдельный эксперимент. Версия Editor закреплена `6000.3.27f2`; 6.6 не использовать.
9. Художественное направление всё ещё утверждается по будущим образцам на S05/S06; Blender пока не обязателен. Отдельная модель/анимация — отдельное утверждение продюсера.
10. Все документы — версия в GitHub; каждый исследовательский факт имеет адрес источника/условия воспроизведения, уверенность и уровень полноты; тесты подтверждают PASS только после запуска.

## Роли
DeepSeek — исполнение исследований, Unity и отчётов; ChatGPT — техническая архитектура, поиск недостающих источников и ревью; продюсер утверждает игровые решения и арт.
