## 2. Доказательность, проверки и публикация

- Получение кадра из Alpha, работающего `SendInput` или графической трассы **не равны** переносу данных анимации; фиксировать, что реально удалось извлечь. `TRANSFERRED_FROM_ALPHA` — только для поз/формул с подтверждённым исходным происхождением, а не одних таймингов. Неудачи конкретных анимаций отметить `BLOCKED`, продолжать другие доступные методы и движения, не заявлять ложный PASS.
- Работы должны быть воспроизводимы, с кодом/документацией/тестами, отдельными результатами по каждому клипу и пакетным сравнением кадров на личное визуальное утверждение продюсера. Итоговая художественная приёмка — за продюсером; **не нужно его предварительное разрешение для каждого технического движения**.
- Исследовательские файлы/матрицы/кадры оригинала остаются локально; в публичный GitHub публиковать только собственный код и текстовые результаты, без защищённых ассетов. Для релиза затем используются собственные или надлежаще лицензированные анимации.
- Не менять production S04, не начинать S05B, не выполнять массовую конвертацию персонажей, не делать force push/merge в main; не менять исходный `Cube.exe` и оригинальные сохранения.
- Если реально упёрся в недоступное GUI/системное ограничение, документировать проверенные способы, результаты и минимальное необходимое действие продюсера. **Это основание для честного `BLOCKED`, а не для создания следующего фиктивного этапа с тем же запросом.**
