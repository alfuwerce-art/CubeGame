# S00-R02 — SUBSYSTEM_TO_UNITY_MAP: Alpha → модули CubeGame → тесты

**Проект:** CubeGame. **Этап:** S00-R02 (D41). **Назначение:** выполнить пункт gate «составлена таблица Alpha subsystem → Unity builtin/own module → tests» и дать архитектору единый обзор решений.
**Ограничение:** это **предложения** (`PROPOSED`), а не утверждённое ТЗ. Числа и геймплей утверждает продюсер, архитектуру — ChatGPT.

## 2. Правила (из D41 п. 5)

1. Сначала проверяем, умеет ли Unity это сама; собственный код — только для правил игры и специфических данных.
2. Не воссоздаём Plasma (D3D9, окна, шрифты, анимационные автоматы, `.plx`).
3. Пакеты не ставим «всем набором»: каждый — после проверки совместимости и профилирования, с согласия продюсера.
4. Все числа из Alpha — **референс**, а не утверждённый баланс.

## 3. Что уже можно специфицировать (не блокировано)

- Прогрессия: XP-кривая, множители уровня/редкости, power-фактор (проверено скриптами).
- Статы предметов: одна формула + множители (проверено скриптом).
- Модель предмета и слотов; модель целей/«миссий»; модель сохранения (v11-аналог с версией).
- Камера/движение — константы собраны, кроме масштаба единиц (один замер).

## 4. Что блокировано (и чем снимается)

| Блокер | Чем снимается |
|---|---|
| Масштаб единиц скорости | один игровой замер (прыжок/бег) |
| Полная таблица id способностей/анимаций | де-обфускация словаря + лог `+0x68` |
| Формат `reg`/`tile` карты | читатель ключей в коде сохранения |
| Точные размеры подземелья | дизасм аргументов `Dungeon::ctor_0` |
| Источник очков прокачки | trace UI навыков + прогон |

Ни один из блокеров **не мешает** начать спецификации и тесты по §3.
