**2026-11-05—06. S05A-2, Codex; продолжение Claude `43a1ba6` через стабилизацию `3d4a2fb`. READY_FOR_REVIEW, не ACCEPTED.**
Итоги запусков: [отчёт продолжения](../../reports/S05A2_CLAUDE_CONTINUATION_REPORT.md).
Воспроизведение: [ANIMATION_SYSTEM_PLAYBOOK](../../agents/ANIMATION_SYSTEM_PLAYBOOK.md).

## Что уже существовало и сохранено

`drawmodel_emu.Emulator` исполняет `Creature_drawModel` (`0x4128F0`) строгим интерпретатором x86; математика и чистые функции выполняются, внешние draw/upload-вызовы записываются. Неизвестная инструкция/память — ошибка. `alpha_oracle.Oracle` строит вход из прежней appearance-системы и реестра размеров. `anim_states.resolve_state` исполняет исходный renderer-блок `0x4B4EF6…0x4B532F`; это action/equipment/flag→state, а не назначение state по названию клипа.

Входной `formula_all.json` содержит 156 видов; два survey — по 101 action. Это **готовые результаты Claude**, не новая массовая обработка Codex. Текущий исполнитель вычисляет только одного прежнего гуманоида.

## Что дополнено

`action_baker` связывает существующие resolver, timing-функции, `bake_action` и `baked_clip` в повторяемый автоматический путь. Ключи включают точные границы action/duration; вся динамика родного smoothing остаётся в oracle. Исходные позы не заменяются нарисованными вручную кривыми. Хвост state 0 проверяется относительно независимо сохранённого settled idle. Проверяются конечность/TRS, полный неизменный набор частей, движение и остаток восстановления ≤0.001 вокселя / 0.05°.

Прежние дефекты закрыты: fallback 1000 мс, молчаливый пропуск ключа с отсутствующей частью, импорт только `TRANSFERRED_FROM_ALPHA`, отсутствие обязательного списка action-клипов, два автономных Update-источника часов и непроверенный контроллер. Проверка движения учитывает active window отдельно от стыка с idle: action 51 честно `BLOCKED`, несмотря на отличающуюся удерживаемую позу.

Итог: из 101 ID — **93 поддержаны (60 states), 8 BLOCKED**. Полный контроллер — 93/93 PASS при 30/60/120 Гц; Python 178, EditMode 29. Числа и логи — в отчёте.

### Оружие — отдельный слой

Тело использует установленное ядро `param_walk` / `AlphaParamWalk.Joint`, которое не изменялось. Добавлен отдельный back-weapon evaluator, проверенный против итогового oracle. У оружия на спине собственный поворот от walk swing; простой постоянный parent offset к телу неверен (проба выявила расхождение до ~0.52 в матрице).

Репрезентация action-клипов использует **один fixed back anchor**. Вычисление `J = T(anchor_back) M P⁻¹` точно сохраняет Alpha-модельную матрицу даже когда Alpha фактически держит предмет в руке. Поэтому `weaponOnBack=true` в таком клипе — соглашение хранения; оно не утверждает, что во время удара меч остаётся на спине. Хват нужно измерять в модельной сетке, а не по этому якорю.

Между ключами перевод к точке хвата перед TRS-интерполяцией и обратно устраняет искусственный отрыв, возникающий при обычной интерполяции центра модели. Исходные ключи сохраняются. Размер оружия fixed-back клипа проверяется при импорте; перенос на другой размер без адаптера не объявляется готовым. Сечения текущего меча подтверждают рукоять Z=[0,7]; проверяются основная кисть, радиальное отклонение второй кисти и попадание в этот конечный отрезок, включая реальные промежуточные кадры PlayMode.

### Переходы

Alpha резко меняет ветвь позиционирования кистей/оружия при смене action 0↔attack. Первая проба выявила перенос оружия примерно на 25 вокселей при возврате в state 0; прежний контроллер также начинал сразу с уже изменённого первого ключа. Это свойство сырого renderer-выхода нельзя скрывать статусом «Alpha transition transferred».

Контроллер хранит сырые клипы и добавляет ограниченные Unity-crossfades (entry 0.15 с, первый recovery 0.18 с, exit 0.12 с). Для этих интервалов статус **`UNITY_TRANSITION`**. Вне них runtime-поза должна точно соответствовать активному исходному evaluator. Полный контроллер имеет один clock и проверяемый жизненный цикл действия. Линейная остановка амплитуды — явная политика исследовательского пилота, не восстановленная динамика игрового update.

## Граница доказательств

Новый clip `EMULATED_ALPHA_CODE` — позы родного кода на явно заданных входах. Сверка эмулятора с живыми захватами подтверждает точность на наблюдавшихся состояниях, но не делает все ненаблюдавшиеся действия `TRANSFERRED_FROM_ALPHA`.

Полный replay 3115 кадров совпал до `max_abs=0`, порог 0.0001 сохранён. Первоначальный FAIL дальних NPC локализован к **входу камеры**: центрирование XY в ноль меняло округления upload-матриц. Опциональный `camera_xy_fixed` восстанавливает исходную систему отсчёта из captured placement и координат существа; placement дополнительно сверяется. Это не подстановка поз; default-путь бейкинга не изменён.

`combat_getAttackTiming` даёт нативное окно исследования; сам по себе не доказывает игровую доступность действия с данным оружием, условия удержания/отмены, root motion, ресурсы способностей, VFX или фактическую длительность действия в полном игровом update. Контроллер — проверенная система воспроизведения поз одного гуманоида, не законченная боевая система Alpha.

При изменении набора частей (например, спрятанное оружие) действие отклоняется текущим восьмичастным контрактом; это `BLOCKED`, а не автоматически поддержанная анимация. S05B/другие существа не выполнялись. Все защищённые входы, кривые, матрицы, PNG и Unity Data остаются в `.scratch`.
