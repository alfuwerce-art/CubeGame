# Alpha 2013 — startup presentation: font, geometry, colours

**Дата:** 2026-11-11 · **Этап:** M0 P0 (review fix) · **Ветка:** `deepseek/m0-full-port-p0`
**Источник:** `D:\Games\Cube world\Cube.exe` (read-only, 32-bit MSVC 2012) + `start.plx`, `gui.plx`,
`resource1.dat`, `resource2.dat`, `data1.db` установки; декомпиляция `.scratch/CubeWorld-Reversal` (Ghidra,
адреса = VA) как указатель, поведение сверено с телами функций.
**Метки:** `ALPHA_CODE_STATIC` — прочитано в декомпиляции; `ALPHA_DATA` — проверено на файлах установки;
`ALPHA_CAPTURE` — измерено на снимке запущенного оригинала (используется только как validation);
`UNKNOWN` — не установлено.

## 1. Шрифт (`ALPHA_CODE_STATIC` + `ALPHA_DATA`)

* Единственный шрифт интерфейса — файл `resource1.dat` в каталоге игры. Его загружает
  `FontCache_find_or_create_scalable(L"resource1.dat")` в каждом UI-виджете: `StartMenuWidget::vfunc_1` 0x583320
  (`cube/ui/StartMenuWidget.cpp:109`), `SystemWidget` 0x587710 (`:109`), `OptionsWidget`, `Interface`, `World`,
  `ChatWidget`, `SpeechWidget`, все подсказки. Второй файл `resource2.dat` загружается рядом
  (`GameController.cpp:20744`) — это начертание для крупных/особых надписей; в стартовых экранах он не участвует.
* `resource1.dat` — валидный TrueType (sfnt 1.0, 13 таблиц, `glyf` 13548 Б, `unitsPerEm` 1000). Строчные глифы
  нарисованы как **капитель**, поэтому любой текст Alpha читается заглавными, хотя строки в таблице `Cube.exe`
  смешанного регистра (`Start Game`, `Create Character`). Проверено рендером файла: `Start Game` → `START GAME`,
  ширина строки на 18 px = 155 px при измеренных на снимке 153 px.
* Размеры (`ALPHA_CODE_STATIC`): стартовое меню 0x41900000 = **18.0f**; `SystemWidget` 0x41600000 = **14.0f**;
  строки `OptionsWidget` и её кнопки 0x41400000 = **12.0f**; строки списков 14 / 12 / 10.
* Тень: каждый текстовый прогон рисуется **дважды** — первый проход с offset 3.0 (меню 4.0) и чёрным цветом тени,
  второй без тени. Выравнивание задаётся флагами `Font_measureTextLine`: `bit1` — горизонтальный центр, `bit4` —
  вертикальный центр (`game_misc.cpp:64347`).
* Цвета (`ALPHA_CODE_STATIC`): обычный текст `(1,1,1,1)`; hover стартового и системного меню `(0.2,1,1,1)`;
  имя персонажа/мира `(0.25,1,1,1)`; строка специализации/seed `(0.5,0.5,1,1)`; строка уровня/`Explored` `(1,1,1,1)`.

## 2. Стартовое меню (`StartMenuWidget` 0x583320)

`ALPHA_CODE_STATIC`: три пункта, текст-вызовы `y = 30 / 80 / 130` (шаг 50), `size = 18`, `x = 0.5 × ширина экрана`,
флаги центра по X; hit-зоны по локальной оси `[10,40) [60,90) [110,140)`, `+0x160` = индекс под курсором (−1 по
умолчанию). Фон/рамку виджет не рисует — только текст.
`ALPHA_CAPTURE` (окно 1936×1048, клиент 1:1): верх глифов `START GAME / OPTIONS / EXIT` = 604 / 654 / 704 px,
ширины 153 / 99 / 51 px, центр по X совпадает с центром экрана. Отсюда якорь первого пункта = 0.576 высоты окна,
шаг 50 px, шрифт 18 px — масштабирования UI нет.

## 3. Списки персонажей и миров (`ALPHA_CODE_STATIC` + `ALPHA_CAPTURE`)

* Строки: `count + 1` (последняя — «новый»), шаг `0xE6 = 230` px, первая строка `y = 0x32 = 50` от начала списка;
  размер строки `Widget_measureContentEntry(600.0, 220.0, 1)` — **600×220** (`GameController.cpp:41756-41821`,
  `:42483-42584`). `ALPHA_CAPTURE`: строка 600×220, зазор 10 px, блок центрирован по X (x = 668 при ширине 1936),
  белая рамка 2 px, полупрозрачная тёмная заливка (≈ rgba(26,26,26,0.62)).
* Текст строки персонажа рисует `CharacterPreviewWidget` → `Interface::drawCharacterCreation` 0x425450: имя
  `(200,30)` size 14, `"LVL <n> <race> <class>"` `(200,55)` size 12, `"Specialization: <x>"` `(200,75)` size 10;
  строка уровня собирается из `L"LVL "` + level + раса + класс.
* Строка мира рисует `WorldPreviewWidget` → `GameController::drawWorldSelectEntry` 0x605AE0: имя `(200,30)` size 14,
  `"Explored: <WorldInfo+0x24>"` `(200,55)` size 10, `"Seed: <WorldInfo+0x20>"` `(200,80)` size 10.
* Превью в строке — **живой 3D-объект**, а не картинка: `CharacterPreviewWidget` рисует модель существа
  (`Creature_drawModel`) камерой с переносом 17.0, поворотом X −95°, Y 45°, полем зрения 45° (`1/tan(22.5°)`) и
  экранным смещением `(x+100−W/2)/W·2`; область ≈ левые 200×220 строки. `WorldPreviewWidget` рисует воксельную
  карту мира из `worlds.db` (распакованный zlib-блоб → `VoxelModel`), камера: масштаб базиса 0.05, дистанция 17,
  поворот X −120°, Y = yaw+45°, yaw вращается ~1°/кадр при наведении.
* «Новая» строка: вместо превью — центрированный текст `New character` / `New world` (size 14, y = 30).
* Кнопки `Select` / `Create` внутри строки в коде строк **не найдены**: в UI-бутстрапе клонируются отдельные узлы
  `Select` / `Delete Character` / `Delete World` (600×30 и 20×20) с низкой достоверностью; правило видимости —
  `UNKNOWN`. На снимках кнопка `SELECT` (198×66) видна у строки под курсором, `X` — в правом верхнем углу строки.

## 4. Options (`OptionsWidget` 0x4CF3C0, раскладка `vfunc_10` 0x4D46D0)

`ALPHA_CODE_STATIC`: 11 строк, шаг **30.0**, первый узел строки `y = 12`, текст `y = 27 + 30i`, `x = 15`, size 12;
значение центрируется флагами. Кнопки `Apply` / `OK` / `Cancel`: measure content 110×15, `Apply` x = 20,
`OK` по центру, `Cancel` прижат вправо, `y` = низ слота. Размер виджета 450×440 (`GameController.cpp:23313-23316`).
Цвет текста строк не меняется при hover — подсвечиваются только узлы-стрелки (`setVec4(0,1,1,1)`), механизм
`UNKNOWN`. Фон панели приходит из `.plx`-шаблона — `UNKNOWN`.

## 5. SystemWidget 0x587660 / vfunc_1 0x587710

`ALPHA_CODE_STATIC`: три пункта (`Options`, `Start Menu`, `Exit Game`), `y = 30 / 60 / 90` (шаг 30), size 14, тень 3,
центр по X внутри виджета 350×285; hit-зоны `[10,40) [40,70) [70,100)`. Виджет не рисует фон — только текст.
`Start Menu` в Alpha сохраняет персонажа и мир (`saveEntityBlob` + `saveStructureBlob`), затем показывает стартовый
экран; `Exit Game` выходит без сохранения.

## 6. Фон стартовых экранов и логотип

* `ALPHA_CODE_STATIC`: во время отрисовки мира (`GameController.cpp:46415-46450`) при видимом стартовом экране
  временно скрываются пять стартовых узлов и корень `gui.plx`, вызывается `Widget_render_pass()`, затем видимость
  восстанавливается. То есть **мир рендерится за стартовыми экранами**, а не однотонный backdrop.
* `ALPHA_CAPTURE`: за меню виден живой мир (холмы, деревья, облака, туман), в списках — тот же мир и модель
  персонажа в сцене. Логотип `CUBE WORLD` + `α` — плоское изображение с чёрной обводкой, `PICROMA ©2013` — в правом
  нижнем углу. Оба приходят из текстур `start.plx` (узлы `cubeworld`, `picroma`, `star1..4`, `blackwidget`).
* `UNKNOWN`: какой мир показан при холодном старте (в сессии P1 мир уже был загружен) и как извлекаются текстуры
  `.plx` — формат чанков не расшифрован; PNG-сигнатур внутри `start.plx`/`gui.plx` нет (текстуры упакованы
  в собственном чанке). `logo.cub` в `data1.db` — воксельная модель, кодом клиента по имени не загружается.

## 7. Что это меняет в порте

Реализовано по этим фактам (`AlphaStartupPresentation`, `GameBootstrap.AlphaMenus`, `GameInterface.uss`):
шрифт `resource1.dat` через локальный staging, размеры 18 / 14 / 12 / 10, шаги 50 / 30 / 230, цвета из §1, плоские
кнопки 198×66 и 298×66 в позициях снимка, строки 600×220 с текстом в x = 200, hover-кнопка строки, `New character`
/ `New world`, три пункта системного меню (14 px, шаг 30).

Осталось `PARTIAL`/`UNKNOWN`: логотип и `picroma` (текстуры `.plx`), фон-мир при холодном старте, воксельное
превью мира в строке (нужен блоб `worlds.db`), строка специализации (нет поля в записи персонажа), точное
правило видимости кнопки строки.
