# S00-R02 — VALIDATION_CASES: воспроизводимые проверки механик Alpha ↔ CubeGame

**Проект:** CubeGame. **Этап:** S00-R02 (D41). **Обновлено:** 2026-11-03 (партия 1).
**Смысл:** каждый случай — конкретный вход, действие и ожидаемый результат, который можно **фактически** выполнить. Статус `PASS` ставится только после реального прогона с записанным результатом; иначе `NOT_RUN`.

## Легенда

| Поле | Значение |
|---|---|
| `SRC` | откуда взято ожидание (`SRC-01/02/03/04`) |
| `MODE` | `STATIC` (расчёт/данные), `ALPHA_RUNTIME` (запуск оригинала), `UNITY` (тест CubeGame) |
| `STATUS` | `NOT_RUN` / `PASS` / `FAIL` / `BLOCKED` |
| `CONF` | уверенность ожидания (`VERIFIED_DIRECT`, `STRONGLY_SUPPORTED`, `PARTIAL`, `UNKNOWN`) |

## Правила

- `PASS` — только с командой/датой/выводом. Скриншот без параметров (seed, уровень, экипировка) не считается доказательством.
- `ALPHA_RUNTIME`-случаи нельзя выполнять без разрешения продюсера; игра запускается только из `D:\Games\Cube world` и только в сессии, где продюсер разрешил запуск.
- Результаты прогонов писать в `R02_REPORT.md` (партия) и обновлять `STATUS` здесь.
