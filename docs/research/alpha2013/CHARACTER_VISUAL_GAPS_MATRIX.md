# Матрица визуальных пробелов персонажа (S05A-1 → S05A-2)

**Проект:** CubeGame. **Основание:** [D51](../../decisions/D51-s05a2-authorized-evidence-first.md) (разрешено исполнение, evidence-first, контролируемый Alpha run), [D50](../../decisions/D50-s05a1-accepted-s05a2-planning.md), [отчёт S05A-1](CHARACTER_ASSEMBLY_ANIMATION_PILOT.md), [план S05A-2](../../stages/S05A2_PROPORTIONS_TINT_PLAN.md).
**Назначение:** свести в одну таблицу, что у собранного технического персонажа **доказано**, что **приближение**, а что **неизвестно**; какие нужны доказательства и что предлагается делать.
**Статусы:** `VERIFIED_ALPHA` (подтверждено данными/кодом Alpha), `PARTIAL` (частично, есть конкурирующие объяснения), `UNKNOWN` (нет данных), `PROXY_NOT_ALPHA` (техническое приближение пилота, к Alpha отношения не имеет).
**Правовая граница:** измерения выполняются по локальным ресурсам, включая разрешённые D51 контролируемые запуски оригинала из отдельной копии; изображения и конвертированные ассеты не публикуются.

## 5. Сводка «что известно / что нет»

**Известно (данные и код):**
- состав частей гуманоида и габариты каждой модели; число граней;
- общая сетка головы и волос (99.3% совпадения кожных вокселей);
- движок собирает три списка координат чистых R/G/B и не удаляет их из геометрии;
- в поставке нет файлов анимаций; в коде есть матрицы костей и слой keyframes;
- отсутствие отдельных `.cub` моделей рук/ног гуманоида в наборе.

**Неизвестно:**
- per-part масштабы, offsets и pivots оригинала;
- масштаб оружия и точка его крепления;
- назначение зелёных/синих маркеров;
- механизм tint волос (какой цвет заменяется, применяется ли множитель);
- таблица «состояние → поза/клип» и параметры исходной ходьбы;
- точные пропорции по кадрам игры (нужен контролируемый протокол съёмки).

## 6. Рекомендуемые решения (черновик, требует утверждения)

| Проблема | Решение | Статус после решения |
|---|---|---|
| P1, P2, P3, P4 | приоритет выявления оригинальных параметров (код + контрольные кадры); затем C+ (согласованный масштаб головы/волос, коррекция оружия), пересчёт offsets и инварианты креплений | `PROXY_NOT_ALPHA` → `PARTIAL`, если появятся измерения по кадрам |
| P5, P7, P8, P9 | статический разбор `Creature_drawModel`; при неудаче — оставить `PROXY_NOT_ALPHA` и зафиксировать | `UNKNOWN` → `PARTIAL` или остаётся `PROXY_NOT_ALPHA` |
| P11–P13 | не удалять маркеры автоматически; маска в метаданных; скрытие только по конфигурации | `PARTIAL` (без изменений) |
| P12, P14, P15 | установить настоящий механизм Alpha, если возможно; при отсутствии доказательств опыт T3 с адресной маской, сравнением цвета **по координатам** и контрольной гистограммой | `PARTIAL` (эксперимент, не заявка на поведение Alpha) |
| P16–P18 | не переносить анимацию; технический цикл остаётся | `UNKNOWN / NOT_REPRODUCED` (без изменений) |

## 7. Что нельзя делать при проверках

1. Удалять все чистые R/G/B-воксели «потому что маркеры».
2. Считать `1 voxel = 1 Unity unit` моделью масштаба Alpha.
3. Выдавать измерения по одному кадру за точные параметры — только `PARTIAL`; по D51 разрешены дополнительные контролируемые съёмки для кросс-проверки.
4. Публиковать кадры с оригинальными моделями.
5. Менять модели/код вне ограниченного S05A-2 по D51. Внутри этапа допустим только один персонаж в изолированной Unity; не запускать S05B.

## 8. Решение D51 и приоритет устранения неизвестности

**По D51 авторизовано исполнение S05A-2:** сначала активно исследовать неизвестные scale/offset/pivot/weapon socket/tint/RGB markers статически и по контролируемым кадрам оригинальной Alpha (только локальная копия без изменения исходных файлов). Вести журнал попыток и источников для каждого P1–P18. При отсутствии доказательств разрешено только помеченное `PROXY_NOT_ALPHA` с личным визуальным утверждением продюсера. Вариант масштаба **C+**: голова и волосы масштабируются совместно в исходной общей сетке; не допускать двойного наследования scale. Шейдерный вариант **T3** — технический запасной эксперимент, но если обнаружен механизм Alpha, приоритет подтверждённому механизму. Проверять адреса/цвета вокселей вне tint-маски, а не одну гистограмму. Работы по S05B не разрешены.
