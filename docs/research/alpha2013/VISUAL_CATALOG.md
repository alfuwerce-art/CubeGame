# S00-R02 — VISUAL_CATALOG: что визуально сверять с Alpha 2013

**Проект:** CubeGame. **Этап:** S00-R02 (D41), review-fix R02 (FIX-05).
**Статус:** `CATALOG_READY / CAPTURE_DEFERRED`. Это **перечень проверок и требований к кадрам**, а не утверждённый художественный стиль и не перенос ассетов.
**Граница:** оригинальные `.cub`, `.png`, `.wav`, `.plx`, сейвы и скриншоты с приватными данными **не** коммитятся в CubeGame. Каталог фиксирует только собственные метаданные/описания; кадры хранятся локально и публикуются только по отдельному решению продюсера.

## 1. Зачем каталог

`S00_DEEP_RESEARCH.md` требует для пакета K «каталог наблюдаемых силуэтов, ракурсов, расположения UI, анимационных состояний и объектов»; `K_assets.md` §K5 перечисляет группы. Каталог нужен, чтобы на S05/S06 проверять **наблюдаемое поведение и композицию**, а не копировать закрытый контент. Формат/структура моделей уже известны отдельно (`K_assets.md` §K1): воксель 1 блок, RGB, без материала/прозрачности.

## 4. Требования к доказательствам кадра

1. Каждый кадр сопровождается: версия/хеш клиента, seed мира, имя мира (можно заменить на нейтральное), персонаж (класс/уровень/спека/экипировка), координаты/регион, время мира, разрешение, язык, настройки графики, FOV/зум.
2. Для анимаций — серия кадров или короткое видео с указанием id состояния/атаки; одного кадра недостаточно.
3. Для UI — кадр без обрезки HUD, с читаемым тултипом; указывать UI-масштаб.
4. Кадры хранятся в локальном evidence-каталоге (`.scratch/visual/`), **не** в git; в docs попадают только метаданные и собственные описания.
5. Запрещено выгружать/публиковать оригинальные модели, текстуры, иконки, звуки и `.plx`; сравнение — только «как выглядит/как устроено», не копирование.

## 5. Почему сбор отложен (`DEFERRED`)

| Причина | Следствие | Когда вернуться |
|---|---|---|
| Новые запуски Alpha требуют отдельного разрешения продюсера; в review-fix их не было | нельзя снять свои кадры | после разрешения, до S05 |
| Связь `state id → клип` не восстановлена (K-U3), таблица `+0x68` неполная (OQ-03) | нельзя подписать анимационные кадры | после статического разбора/лога `+0x68` |
| Художественное направление утверждается на S05/S06, не сейчас | каталог не является ТЗ на стиль | S05/S06 |
| Оригинальные ассеты закрыты | нельзя использовать их в CubeGame | всегда |

## 6. Что нужно от продюсера

1. Разрешение на контролируемые запуски Alpha из копии для съёмки кадров (или съёмка продюсером).
2. Решение, можно ли хранить локальные кадры и в каком объёме; публиковать — только по отдельному решению.
3. Подтверждение, что визуальный каталог — вход в S05/S06, а не утверждённый арт-дирекшн.
