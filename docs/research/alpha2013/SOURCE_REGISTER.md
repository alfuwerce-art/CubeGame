# S00-R02 — SOURCE_REGISTER: реестр источников Cube World Alpha 2013

**Проект:** CubeGame (рабочее название). **Этап:** S00-R02 (D41).
**Дата сверки:** 2026-11-03, MSK. **Исполнитель:** DeepSeek Harness.
**Назначение:** единый список источников с провенансом, хешами, датой проверки и **границей использования**. Любой факт в `BEHAVIOR_SPECS/` обязан ссылаться на ID источника из этого файла (`SRC-*`).

## 0. Лестница достоверности (из D41 п. 3)

| Ранг | Тип | Что означает |
|---|---|---|
| 1 | Локальные измерения Alpha (файлы, сейвы, запуск) | фактическое поведение конкретной сборки |
| 2 | Реконструкция (декомпиляция/RTTI/структуры) | гипотеза с оценкой уверенности, не первоисточник |
| 3 | Документы и видео 2013 года | независимое свидетельство, но не техника |
| 4 | Поздние wiki с указанием версии | индекс вопросов, часто смешаны Alpha/2019 |
| 5 | Unity 6000.3 official docs | техническая возможность движка, не поведение Alpha |

`RECONSTRUCTED_SOURCE` — **тип доказательства**, а не статус `VERIFIED`. Статус `VERIFIED_DIRECT` ставится только при воспроизводимом подтверждении (данные сейва, точная константа, собственный запуск с записанным результатом).

## SRC-02 — CubeWorld-Reversal (реконструкция)

- URL: `https://github.com/qad3n/CubeWorld-Reversal`
- **Зафиксированный коммит:** `e6e906e4b2644806ef19c2e1f12ebc636c347f7c` («Add reverse-engineered game struct field offsets», 2026-07-21).
- Клон для анализа: локальный `C:\Users\bow\Desktop\CubeGame\.scratch\CubeWorld-Reversal` (**не** входит в git CubeGame, `_scratch` исключён из индекса).
- Инструмент авторов: Ghidra 12.1.2 headless. Клиент: 12 983 функции, 1 370 игровых; сервер 6 152 / 288. Классов `cube::` — 55 (клиент) / 25 (сервер), 23 общих.
- Вспомогательные индексы: `cube/attribution.tsv` (адрес → имя → класс), `cube/RENAMES.tsv` (адрес → предложенное осмысленное имя), `cube/GAP_ANALYSIS.md` (уверенность по `FUN_*`), `cube/include/cube_types.h` (экспорт структур + **подтверждённые смещения полей**).
- **Ограничения:** это декомпилированный псевдокод, а не исходники; MSVC-оптимизация теряет параметры, часть выражений деградирована (в телах встречаются неинициализированные `self`, `world`, `column`). Имена `FUN_*` и комментарии `[AUDIT] proposed: ... (confidence: ...)` — **предложения**, не истина. Копирование тел функций в CubeGame запрещено; используем собственные описания алгоритмов и константы.
- Сверка с локальным бинарём: 48 RTTI-классов `cube::` в `Cube.exe` (R01 §5) согласуются с деревом Reversal; классы `Region/Chunk/ChunkBuffer/WorldInfo/LandscapeTile/Spawn` не имеют RTTI (вероятно, не полиморфны) — их наличие подтверждается только реконструкцией, помечаем `RECONSTRUCTED_SOURCE`.

## Правила ведения реестра

1. Новый источник добавляется строкой с ID, URL/хешем, датой проверки и **границей использования**.
2. Если источник противоречит другому — фиксируется `CONTRADICTIONS` в спецификации, а не «выбирается удобный».
3. Никакие бинарники, ассеты, сейвы, декомпилированные тела не попадают в git; в отчётах только метаданные, константы и собственные описания поведения.
4. При обновлении Reversal фиксируется новый SHA; старые ссылки в спецификациях сохраняют свой SHA, чтобы факт оставался проверяемым.
