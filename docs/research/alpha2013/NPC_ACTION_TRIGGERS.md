# Запуск действий NPC в Alpha — исполнение байтов ИИ (S05B-A, П1)

**Статус:** `IN_PROGRESS` (шаг A1, Cat 0x1e: П1, П2, Unity — PASS; П3 — `NOT_CAPTURED`). **Решение:** [D60](../../decisions/D60-s05ba-npc-actions-authorization.md). **План:** [S05B_NPC_ACTIONS_PLAN_DRAFT](../../stages/S05B_NPC_ACTIONS_PLAN_DRAFT.md).
**Инструмент:** [ai_trigger.py](../../../tools/alpha_models/universal/ai_trigger.py). **Тесты:** [test_npc_actions.py](../../../tools/alpha_models/tests/test_npc_actions.py).

Обозначения: **ИСПОЛНЕНО** — результат получен выполнением байтов `Cube.exe` эмулятором; **ПРОЧИТАНО** — по дизассемблеру/декомпиляции, не исполнено; **ВХОД** — значение мира, которое перебирается как условие.

## 1. Где Alpha выбирает действие NPC

Тик боевого ИИ `cube::CombatBehavior::vfunc_0` (VA `0x42CB20`) после выбора цели пишет код действия в `creature+0x68` (таймер `+0x6c` обнуляется). Каждое существо мира получает `Sequential[CombatBehavior, LookAtPlayerBehavior, …]` при спавне (`GameController.cpp` 96726, ПРОЧИТАНО). Коты и бегуны в живых захватах — фракция `+0x60 = 1` (враждебный монстр).

Участок выбора действия: от диспетчера по виду `0x42D87F` (`mov eax, [edi+0x64]`) до общих выходов `0x42EAEF / 0x42EB01 / 0x42EAEA`. Ветвление (ИСПОЛНЕНО, адреса — места решения):

| Условие | Адрес | Итог |
|---|---|---|
| вид 0x74 / 0x76 / 0x2f,0x6f,0x70,0x71 / 0x77 | `0x42D882`… | собственные списки действий (вне A1) |
| водное существо (`creature_hasWaterAffinity` `0x444610`) | `0x42DD6C` | своя ветка |
| вид 0x65 (Dragon) | `0x42DEC3` | своя ветка |
| флаги внешности `+0x7e`: бит 2 и бит 0x10 | `0x42E109` | действие 51 (`0x33`) — полёт |
| вид ≠ 0x68, оружие не 6/7/8, **бит 0x10** | `0x42E288` | вид 0x19 → 72 при доступной способности; иначе **75** (`0x42E2BF`) |
| **бит 0x08** | `0x42E2CF` | `combat_advanceAttackTimer` `0x445410` |
| иначе — ближний бой | `0x42E2DF` | оружие / вторая рука / способность 0x36 / `CombatBehavior_chooseAttack` `0x4456A0` |

Флаги `+0x7e` — это поле внешности `+0x06`, его заполняет `creature_generateAppearance` (эмулятор внешности), поэтому набор действий вида выводится **из байтов Alpha без запуска игры**.

## 2. Метод

`run_region` исполняет участок `0x42D87F…` эмулятором `drawmodel_emu.EmuCPU` на структуре существа, собранной исполнением `creature_generateAppearance(kind, seed)`. Вызовы из участка (`combat_getAttackTiming`, `CombatBehavior_chooseAttack`, `combat_advanceAttackTimer`, `combat_selectAttackVariant`, `creature_isBossType` и др.) **исполняются**. Заменены только:

* `rand` (IAT `0x6FC468`) — сценарий значений (ВХОД);
* `ability_isUsable` `0x43E5A0` — ответ «да/нет» (ВХОД: зависит от навыков существа);
* `libm` — точная математика.

Перебор входов: дистанция (ближняя/дальняя), ресурс `+0x170` (0 / 0.5 / 0.79 / 0.81 / 1.0), 4 сценария `rand`, доступность способности, счётчик серии `+0x70` (0/1), предыдущее действие (замыкание по полученным действиям). Удерживаются: внешний приказ `[esp+0x3c] = 0` (не решение ИИ), оглушение `+0x128 = 0`, таймер `+0x6c` больше любого `combat_getAttackTiming`, фракция 1, «на земле». Любая неисполнимая инструкция или вызов останавливает прогон с причиной — ни одной догадки.

## 3. Результат для 15 видов S05B-1 (ИСПОЛНЕНО, seed 0,0)

| Виды | Флаги `+0x7e` | Действия, которые запускает ИИ | Адрес записи |
|---|---|---|---|
| Cat 0x1e, BrownCat 0x1f, WhiteCat 0x20 | `0x0031` | **75** | `0x42E2BF` |
| PlainRunner 0x3f, LeafRunner 0x40, SnowRunner 0x41, DesertRunner 0x42 | `0x0028` | **6** | `0x4455D7` (в `combat_advanceAttackTimer`) |
| 8 видов гуманоидов (0x00–0x03, 0x07, 0x08, 0x0d, 0x0e) **без оружия** | `0x0000` | **3, 4** (чередование по `+0x70`), **6** (ресурс < 0.8), **54** (если способность 0x36 доступна) | `0x4458A0`, `0x4455D7`, `0x42E627` |

Ошибок исполнения нет (0 из 320–800 прогонов на вид). По правилу D60 п.2 совпадение у видов одной группы **не** переносит профиль: в A1 профиль создан только для Cat 0x1e; остальные виды получат профили после собственного П1 в части B. Гуманоиды-NPC в мире обычно вооружены — их набор зависит от экипировки и будет снят в A2.

## 4. Cat 0x1e — профиль `alpha_actions/creature_ai_cat_0x1e`

* Запуск: только действие **75**, при таймере больше `combat_getAttackTiming` (дистанция в этой ветке не проверяется; выбор цели и дистанция агрессии — до участка, `PARTIAL`).
* Состояние `drawModel` для 75 — **44** (таблица состояний, ИСПОЛНЕНО); длительность по `combat_getAttackTiming` — **1085 мс** (windup 296).
* Позы (оракул `drawModel`, П2): 183 кадра при 16 мс, движутся тело, голова, хвост и передние лапы (пик 8.6 вокселя, 94°), полный возврат к покою (0 / 0°).
* Provenance клипа: `EMULATED_ALPHA_CODE`; `live_check = NOT_CAPTURED` (обновляется после П3).

## 6. П3 — попытка живого захвата (2026-11-06)

Копия Alpha из `.scratch` запущена, вход в мир, разведка `pose_capture --kinds 0x1e,0x1f,0x20` после пяти отрезков ходьбы по городу Arulon (ночь, 3:36–4:10 игрового времени). Найден **Cat 0x1e, фракция `+0x60 = 5`** (дружелюбный, 79 кадров, действие всегда 0). По коду `CombatBehavior_isHostileTo` (`0x596CA0`, ПРОЧИТАНО) существо фракции 5 никогда не враждебно игроку (фракция 0), поэтому городской кот действие 75 не запускает. Враждебные коты (фракция 1, как WhiteCat 0x20 в захвате `batch1`) — вне города; до них в этой сессии не дошли. Игра работала всё время (`CUBE_ALIVE=True`).

Итог П3: **`live_check = NOT_CAPTURED`** (причина: в доступной области только дружелюбный кот). Изменение фракции в памяти игры не применялось — это вмешательство в проверяемое поведение.
