# C4 — первый основной удар (D88/D89)

**Ветка** `integration/m0-all`. **Исполнитель** Codex. **Статус C-31** `PARTIAL`.

Функция `Cube.exe 0x445020` исполнена через `native_lifecycle.select_attack`
для классов 1…4, HumanMale и пустого текущего действия. Входы — тип и подтип
предметов в `0xAA8/0xAA9` и `0x990/0x991`. Для ближнего боя классов
Warrior, Ranger и Rogue получены следующие первые действия.

| Сочетание | Action ID |
|---|---|
| Нет оружия в основной руке или Fist | 6 |
| Одноручное оружие без особой ветки | 1 |
| Одноручное оружие без особой ветки и щит в левой руке | 10 |
| Longsword | 14 |
| Dagger | 19 |
| Greatsword, Greataxe, Greatmace, Pitchfork | 57 |

`AlphaPrimaryAttack` выбирает действие, а `GameBootstrap.HeroAttack` передаёт его
в существующий `CombatSystem`. Локальная библиотека HumanMale содержит все
шесть клипов. Действия для лука/арбалета, бумеранга и магии по-прежнему
используют временный путь, пока не подключены их ввод, снаряды и попадания.
Эмуляция первого действия дала 22 для лука/арбалета, 26 для бумеранга,
30 для посоха и 38 для жезла при начальной специализации. Эти результаты
сами по себе не определяют игровой момент попадания.

Клики в окне комбо, удержание ввода и полный цикл действия остаются
следующими частями C4. Сценовая проверка P21 отложена.

Полный Unity EditMode: 616 прошли, 2 пропущены, ошибок нет.
