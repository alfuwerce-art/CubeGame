# CubeGame — REFERENCE_ATLAS: как изучать Alpha 2013, когда код не даёт ответа

**Статус:** CURATED_RESEARCH_GUIDE, это **не** автоматически утверждённое ТЗ механик.
**Дата проверки ссылок:** 2026-11-03.
**Версия:** преимущественно Alpha 2013, отдельно отмечать релиз 2019.
**Главный принцип:** самый убедительный ответ — воспроизводимый факт локальной Alpha; реконструированный псевдокод и wiki — инструменты исследования, а не гарантии истины.

## 1. Реальный исследовательский корпус (фиксировать версии)

| Источник | Зачем | Ограничения |
|---|---|---|
| Локальная `D:\Games\Cube world\Cube.exe`, ресурсы, сейвы | Фактические структуры, версия, RTTI, игровые проверки | Неофициальная частично русифицированная сборка; проверка bit-exact подлинности невозможна по имеющимся данным; read-only |
| https://github.com/qad3n/CubeWorld-Reversal | Клиент `cube/` и сервер `server/`; функции, типы, карты вызовов, индекс `attribution.tsv`, `GAP_ANALYSIS.md` | Декомпилированный C++, **не исходники**, встречаются ошибочные имена/потерянные параметры; не копировать как C# |
| https://github.com/NationalSecurityAgency/ghidra | Верификация статических гипотез на локальном бинарнике | Устанавливать/запускать по отдельному разрешению; не нужен для каждой мелочи |
| `stage/s00-alpha-g0` | Версия клиента, хеши, успешный запуск/сейвы | Провенанс неофициальный |
| `stage/s00-static-r01` | Собственная карта классов/контейнеров/координат | Много UNKNOWN; особенно генерация и камера требуют допроверки |

Фиксировать SHA коммита Reversal, когда агент клонирует или обновляет его; файл источника/адрес функции должен указывать именно на эту версию. Не скачивать и не запускать неофициальные DLL/EXE модов.

### Официальные материалы и визуальные ориентиры

- **Picroma:** https://picroma.com/ — описания классов/боёв/особенностей; текущая страница может относиться к 2019, проверять датировку.
- Ищите исходные демонстрации Wollay/Picroma, **опубликованные в 2013**, и старые руководства с таймкодами; фиксируйте URL, дату размещения, точный билд и `time_start/time_end`. Нет датировки — снижайте уверенность.
- Для сравнения внешнего вида: собственные видео/скриншоты из локальной Alpha в **локальном** evidence-каталоге (в публичном GitHub только ссылки и собственные описания). Регистрируйте **камеру/масштаб/погоду/настройки/seed**, иначе изображения несравнимы.

## 4. Алгоритм разрешения UNKNOWN

1. Явно сформулировать вопрос: например «как повышается Power на 1 уровне?», не «найди всё о силе».
2. Проверить индекс реконструированных классов/функций и соседние вызовы; разделить псевдокод и собственные выводы.
3. Проверить бинарные значения/сейвы или провести **один локальный игровой эксперимент** со сравнимыми входными условиями (два сейва до/после, соответствующие действия).
4. Искать источники в порядке: 2013 видео/гайд → датированный форум/архив → wiki с явной меткой Alpha → поздние воспоминания.
5. При конфликте: таблица `source A, source B, version, fact, confidence`. Не отдавать агенту выдуманный ответ.
6. Если остаётся критический вопрос: подготовить для ChatGPT `FEATURE_ID + что уже просмотрено + гипотезы + исходные ссылки + конкретный блокер`. Привлечь помощь архитектора, не задавать пользователю тысячу несущественных вопросов.

## 5. Пример правильного различения

- Neoseeker описывает **бесконечные уровни и модель Power, стремящуюся к пределу** для Alpha. Это **описание источника**, а точная формула — ещё предмет проверки.
- Wiki сообщает **2 очка навыка за уровень** в Alpha и замену системы на артефакты в Steam-версии. Это кандидат для теста/спецификации, не доказательство конкретной сборки.
- **CubeGame D30:** максимальный уровень не ограничен, но дерево пассивных навыков может быть полностью открыто. Это **цель нашей игры**, и она не обязана копировать все особенности прежнего дерева Alpha.

## 6. Чего не делать

- Не копировать статьи целиком, чужие ассеты/приватные видеозаписи/оригинальные бинарники в CubeGame.
- Не запускать неизвестные моды, генераторы/активаторы, не обходить лицензирование.
- Не считать название функций `FUN_<addr>` или комментарий `[AUDIT]` подтверждённым смыслом без проверки.
- Не ставить `VERIFIED_DIRECT` за wiki или за красивый текст LLM.
- Не считать потенциально ненайденную механику частью Alpha только потому, что она есть в 2019 или в невыпущенных ассетах.
