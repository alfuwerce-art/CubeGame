# S00-R02 — RESEARCH_COVERAGE: трекер подсистем A…L

**Проект:** CubeGame. **Этап:** S00-R02 (D41). **Обновлено:** 2026-11-03 (партия 1).
**Смысл:** одна таблица, где видно, что уже доказано, что частично, а что блокирует перенос. «Рассмотрено» ≠ «декомпилировано полностью»: статус ставится по достаточности для написания и проверки механики CubeGame.

## Легенда статусов

| Статус | Значение |
|---|---|
| `DONE` | структура, алгоритм и данные восстановлены до уровня, позволяющего написать и проверить спецификацию; UNKNOWN локализованы |
| `PARTIAL` | каркас и часть формул есть; критические детали отмечены и имеют план проверки |
| `SEEDED` | собраны источники и точки входа, разбор ещё не начат |
| `NOT_STARTED` | не начато |
| `DEFERRED` | осознанно исключено из этапа (сеть, неиспользуемые демо-функции, воссоздание Plasma) |

## Что уже даёт основание для Unity-работы (не требующее дальнейших изысканий)

1. **Формулы прогрессии** (`E_combat.md` E2, E4, E8, E9) — читаются однозначно, покрываются табличными тестами.
2. **Модель полей существа** (`E_combat.md` E1) — подтверждена несколькими независимыми потребителями.
3. **Кривые Alpha** (`curve_level05`, `curve_diminishing*`) — единый модуль.
4. **Форматы данных** (`data*.db`, `Save/*.db`) — схема и распределение ключей (`DATA_AND_SAVE_SCHEMAS.md`).
5. **Границы с Plasma** — что заменяется Unity и что не переносится (`UNITY_REUSE_MAP.md`).

## Что блокирует следующий шаг (жёсткие блокеры)

| Блокер | Подсистема | Чем снимается |
|---|---|---|
| Неизвестен формат «регионального растра» карты (60 160 Б) | L/C | разбор `map_*.db` + сверка с `WorldMap`/`Region` |
| Не подтверждена модель HP=power | D/E | один точечный прогон Alpha (полоса HP до/после level-up) |
| Нет полной таблицы id способностей ↔ имена | E/F | разбор `data4.db` словаря + UI-виджеты навыков |
| Нет данных о движении/камере | I | партия I + точечные прогоны |

## Правила обновления

- Статус поднимается только при наличии записанных фактов с адресами/данными и списком UNKNOWN.
- `DONE` не ставится, пока хотя бы один критический UNKNOWN влияет на способы проверки механики.
- Динамические тесты Alpha помечаются отдельно: `RUNTIME_VERIFIED` (с датой, seed, персонажем).
- Ни одна строка не получает `APPROVED_Dxx` до решения продюсера.
