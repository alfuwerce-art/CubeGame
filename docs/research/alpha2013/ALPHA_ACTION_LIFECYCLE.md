Численные проверки исполняют байты исследовательского `Cube.exe` существующим строгим эмулятором. SHA256 бинарника: `84a7a132a84d4282338e7ea45a1940d32066d64e39cbafed8f2418d5a6dc30bf`. `VERIFIED_ALPHA` ниже относится к конкретной функции, входам и наблюдению. `EMULATED_ALPHA_CODE` — происхождение новых поз/правил. Полная доступность способности требует проверки GUI, ресурсов, физики, buffs и world update: результат одной input-helper функции этого не доказывает. Все сгенерированные правила, дампы, матрицы и клипы находятся только в `.scratch/lifecycle/`.

Открытый [реестр статусов 101 ID](HUMANOID_ACTION_STATUS.csv) содержит только метаданные; все позы и native rule JSON остаются локально.

## Dynamic Parts

Исходный drawModel обнуляет slots частей до вызова draw. Отсутствующий draw в этом случае является событием видимости, не недостающей матрицей. Смена модели/девятая часть в текущих пяти действиях не обнаружена; новый необъяснённый draw site по-прежнему приводит к отказу.

| Action | State | Причина и событие в исследованном renderer-контексте |
|---|---|---|
| 22 | 21 | Weapon slot пуст до `attackTiming/2` (integer division); оружие появляется на 271 мс |
| 23 | 21 | Та же проверка; появляется на 53 мс |
| 26 | 66 | Ветка windup/attack timing обнуляет weapon slot; скрытие на 296 мс, возврат на 1579 мс. Альтернативная ветка `+0x13B4>0` может использовать дополнительный slot, в этот POC не включена |
| 71 | 41 | Между windup и windup+reload отключены head, обе кисти и стопы; скрытие 200 мс, возврат 3200 мс. Body/hair/weapon остаются |
| 72 | 41 | Те же части; скрытие 200 мс, возврат 5200 мс |

Это тайминги каталога для его сохранённых входов, не универсальные игровые длительности этих способностей. Сэмплирование включает native boundaries ±1 мс. Во время каждого события сохраняется маска `visible`; payload содержит **только матрицы видимых частей**. Скрытый ключ нельзя запросить через `KeyMatrix/KeyPose`. На скрытии удерживается последний видимый transform без применения вымышленной позы; Renderer выключен. На появлении берётся новая исходная матрица, crossfade через невидимые позы не строится. Старый статический формат по-прежнему требует все части.

## Реализация и проверяемые ограничения

`native_lifecycle.py` — адаптер к прежнему CPU, а не новый эмулятор. `lifecycle_pipeline.py` — сборка локальной библиотеки/профилей; `lifecycle_research.py` — отдельный survey. `AlphaNativeInput` применяет проверенные правила, `AlphaNativeDriver` владеет входом/временем через прежний `AlphaAnimationController`. S04 не менялся. Прежнее вращение оружия вокруг фактической точки хвата сохранено; продюсер сообщил, что визуальная проблема второй руки исправлена.

Новый сценарий: ходьба на месте → остановка → одиночный 57 → recovery при ещё активном native action → native idle → 57/67/58 при удержании → idle → class-4 test activation 79 → удержание 11 с → primary отменяет в 57 → idle → динамический 26 → idle. Смена class в адаптере не меняет внешность/геометрию гуманоида.

Поза входа каждого action-варианта бейкится из settled idle. Поэтому crossfade при прерывании — `UNITY_TRANSITION`, **не** доказанное воспроизведение всей непрерывной истории smoothing Alpha. GUI, физическое перемещение, collision/damage/resource effects и все ability start/cancel gates не портированы. Положительные результаты сценария не отменяют эти ограничения.
