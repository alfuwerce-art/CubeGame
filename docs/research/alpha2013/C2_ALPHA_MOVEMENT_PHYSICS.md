# C2 — движение героя Alpha 2013 по байтам Cube.exe (волна 1, D88)

**Дата:** 2026-11-09. **Исполнитель:** Claude Code. **Ветка:** `integration/m0-all`. **Статус:** `READY_FOR_REVIEW`, не ACCEPTED.
**Метод:** дизассемблирование `Cube.exe` (capstone) по адресам, найденным через реконструкцию `.scratch/CubeWorld-Reversal`; каждое число ниже прочитано из байтов (`DIRECT`). Псевдокод Ghidra использовался только как указатель — в нём потеряны аргументы (`arrayElem_stride4()` без индексов), поэтому прежнее исследование [I_movement](BEHAVIOR_SPECS/I_movement.md) не смогло связать скорость с позицией.

## 1. Единицы скорости — OQ-23 закрыт

| Шаг | Адрес | Что делают байты |
|---|---|---|
| dt | `0x60C83D…0x60C862` | `dt = (float)elapsed_ms · 0.001` → секунды |
| смещение | `0x61AEB4…0x61AEDB` | `d = (velocity[+0x34] + extra[+0x4C]) · dt` (`0x412280` сложение vec3, `0x451510` умножение на скаляр) |
| в позицию | `0x61B4D9…0x61B51B` | `pos_i(int64 @+0x10) += ftol(d_i · 65536)` (`0x42C580` × 65536, `0x42C9B0` add/adc) |
| блок | `0x42F040 vec3i64_toIntFloor` | координата блока = `pos / 0x10000` (используется для `world_getColumnData`) |

**Итог:** 1 единица скорости Alpha = 1 блок/с. В CubeGame 1 блок = 1 единица Unity ([WorldLayout](../../../Assets/CubeGame/Features/World/WorldLayout.cs)), значит скорости Alpha переносятся как есть, в ед. Unity/с.

| Бег (флаг действия 0x40) | `max ×= 2.0` → **12 блок/с** | `0x619DB8` (условия: не лазание у стены, не планирование в воздухе) |

Следствие: бег держит ровно 12 блок/с при любой частоте кадров (после трения следующий кадр снова упирается в кламп), остановка без ввода — экспонента с постоянной 200 мс (≈2.4 блока выбега с бега).

## 4. Прыжок — P-20 закрыт (`0x4A8C8A…0x4A8DDE`)

1. Пока пробел удерживается, таймер нажатия `+= ms`; при отпускании — 0.
2. Если таймер < **200 мс**, герой на твёрдом блоке (`contact & 1`) или `[+0x128] ≠ 0`, и `vz ≤ 0`: `vz = min(|v_xz| + 2, 10)`, таймер подкачки = **100 мс**.
3. Пока подкачка > 0, пробел нажат и `vz < 10`: `vz += 0.08 · ms` (80 блок/с²), потолок **10**.
4. Подкачка `−= ms` каждый кадр.
5. В воде (`contact & 2`) при нажатом пробеле: `vz += 0.001 · ms` до 10 — всплытие (не перенесено, пакет плавания).

Гравитация **30** блок/с² (`0x61AC2B…0x61AC43`), в планировании/«жёстком» режиме `30 · 0.1` (`0x61ABBB`).
Пример (расчёт по правилу, шаг 1 мс, пробел удерживается): с места — старт 2, подкачка до ≈7, высота ≈ **1.27** блока, в воздухе ≈0.62 с; с бега 12 блок/с — старт 10, подкачка держит 10 ещё 100 мс, высота ≈ **2.65** блока, ≈0.85 с.

## 5. Стамина `+0x1194` — поправка к прежней записи

Байты `0x619CF9…0x619D59`: стамина **не расходуется бегом по земле**. Расход `−0.0002/мс` — только при `флаг 0x10 (планирование) && не на земле && флаг 0x40`, т.е. пробел в полёте на дельтаплане; восстановление `+0.0001/мс` — во всех остальных случаях, кроме лазания у стены в воздухе (там отдельный расход `(1 − climbingPower) · 0.0005/мс`, `decomp 100183`). Прежние формулировки «спринт −0.0002/мс» (I4, P-18) — неверная привязка флага 0x40; исправлено в матрице.

## 6. Шаг 2: вода, лазание, дельтаплан (C2, 2026-11-09)

### 6.1 Навыки в физике — B-U5 закрыт

Тик физики сам вызывает кривые навыков с рангами героя (массив `+0x1138`): плавание `+0x1148` → `curve_diminishingHalf` 0x4476A0 (`0x6192AD`), лодка `+0x114C` → `x3p1` 0x43E2C0 (`0x61928C`), дельтаплан `+0x1144` → `x3p15` 0x43F770 (`0x619479`), лазание `+0x1140` → `N1` 0x43E660 (`0x6194F0`). Формулы (float, байты): Half `r<1 → 0.5`, иначе `(1 − 1/(0.1r+1))·0.5 + 0.5`; N1 `1 − 1/(0.1(r+1)+1)` без защиты; x3p15 `r<1 → 0`, иначе `(…)·3 + 1.5`; x3p1 `r<1 → 0`, иначе `(…)·3 + 1`. Те же числа, что в описаниях статов (PILOT_MOVEMENT) — теперь доказано, что они двигают физику.

### 6.2 Плавание (контакт 2)

| Правило | Значение | Адрес |
|---|---|---|
| Вода в теле | контакт 2, если любой блок типа 2 пересекает тело; верх воды = верх самого высокого такого блока | `0x61D04x…0x61D074` |
| Предел | `max × Half(ранг плавания)` → ранг 0: шаг 3, бег 6 | `0x6192A7` |
| Плавучесть | `f = (верх воды − центр тела) / (рост/2)`; `vz += dt·30·k`, `k = 0` при `f ≤ 0`, `f + 1` при `0 < f < 1`, `1` при `f ≥ 1` (в лодке всегда `f + 1`) | `0x61D0D2…0x61D184` |
| Сопротивление | вся скорость каждую мс `→ 0` с `k = 0.005` (не в лодке) | `0x61E684…0x61E6D1` |
| Направление | W/S вдоль полного взгляда камеры, с наклоном (ныряние/всплытие) | `0x4A73DE…0x4A74D2` |
| Пробел | `vz += 0.001·мс` и подкачка прыжка `+0.08·мс` до 10 | `0x4A8D4E…0x4A8DC6` |

Позиция Alpha — центр тела (`Creature_findPathToTarget` берёт блок ног как `pos + 0.5 − рост/2`). Итог: тело всплывает до половины в воде (центр на поверхности), под водой — нейтрально.

### 6.3 Лазание (флаг 1 = левый Ctrl, контакт 4 = стена)

| Правило | Значение | Адрес |
|---|---|---|
| Ввод у стены | W/S `±80·0.2 = 16` блок/с² по вертикали, A/D 16 вбок | `0x4A6EC4…0x4A6EEF`, `0x4A7280…0x4A7299` |
| Физика | без гравитации; скорость каждую мс `→ 0` с `k = 0.0025`; бег ×2 выключен | `0x61AB04…0x61AB86`, `0x619D99` |
| Стамина | `−(1 − N1(ранг))·0.0005/мс` в воздухе у стены; при `≤ 0.01` флаг снимается → падение (ранг 0: ≈2.2 с) | decomp 100177…100190 |

### 6.4 Дельтаплан (G, флаг 0x10)

| Правило | Значение | Адрес |
|---|---|---|
| Клавиша | **G** (`handleKeyPress` таблица 0x47E95C); с предметом особого слота подтипа 0 — открыть, если упал не больше 2 блоков ниже последней вершины (`+0x13BC`) и закрыт; иначе закрыть. Подтип 1 (лодка) — состояние 0x6B в воде | `0x47E83C…0x47E8E5`, `0x42C860` |
| `isGliding` | флаг 0x10, `vz < 0`, не на земле, нет оглушения/рывка | `0x444650` (в реконструкции ошибочно «physics_isLandingHard») |
| В полёте | ввод 8 вместо 80 (`0x4A6BAA`), гравитация `30·0.1 = 3` (`0x61ABBB`), предел `× x3p15(ранг)`, без бега ×2 | |
| Ранг 0 | `x3p15(0) = 0` → флаг снимается (`0x6194BA`): без ранга «Дельтаплан» не летает | |
| Пробел | флаг 0x40 = пробел при стамине > 0; при `vz < 0` гасит гравитацию `+30·dt`; стамина `−0.0002/мс` | `0x4982DF`, `0x61AD36`, `0x619D0D` |
| Вода | закрывает дельтаплан | `0x61AC63` |

Не перенесено (PARTIAL): поле ветра `0x5A6270` (шум Перлина от позиции, смещение вверх +0.5 — в реконструкции ошибочно «randomizeVec3»), крушение о стену/землю на скорости > 8 / > 40 с оглушением (`0x61AC88`, `0x61ADAB`, C4).

### 6.5 Лодка и езда (P-27)

Лодка — предмет особого слота подтипа 1 + G в воде → состояние 0x6B: предел `× x3p1(ранг лодки)` (`0x61928C`; ранг 0 → 0, без ранга не плывёт), плавучесть `f + 1`, горизонтальное сопротивление `0.1·k` (`0x61D5E8`). Перенос — когда появятся особый слот (C5) и ранги (C3). Езда — не найдена.
