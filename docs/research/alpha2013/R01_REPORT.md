## 3. Ключевые находки

1. `data1–4.db` — действительно SQLite key/value хранилища по именам ассетов: 2857 моделей `.cub`, 93 `.wav`, 104 `.png`, 2 словаря. Утверждение README Reversal подтверждено на локальной копии.
2. Формат `.cub` **не** zlib и не PNG — внутренний контейнер, не расшифрован (для пилота не нужен).
3. Сохранения: один и тот же SQLite-скелет у всех четырёх файлов; `characters.db` — zlib-блоб, `worlds.db` — структура с версией 7, именем мира и seed; `map_*.db` — растровые блобы по регионам.
4. `.plx` — объектный поток Plasma (`PlasmaGraphics`), формат закрытый, переиспользовать не планируем.
5. RTTI `Cube.exe` даёт независимый от Reversal список классов и подтверждает разделение `cube::` (игра) / `plasma::` (движок) — совпадает с границей `World/Core` ↔ `Presentation` в ADR-0001.
6. В бинаре присутствует `plasma::InvalidDemoLicenseException`: в клиенте есть демо-лицензирование. Обход не рассматривается (запрещено правилами).
7. Русская локализация не может происходить из `data4.db`: там только `dict_de.xml` и `dict_en.xml`. Источник — `UNKNOWN`, оговорка G0 о неофициальном репаке усиливается.

## 4. Блокеры и ограничения

### 4.1. TLS/schannel в сессии агента (обходится)

`git fetch`, `curl.exe` и `Invoke-WebRequest` падают с `schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS (0x8009030e)`. TCP-соединение до `github.com:443` и `unity.com:443` устанавливается (`Test-NetConnection` = True). Рабочий обход: инструменты с собственной TLS-реализацией — `git -c http.sslBackend=openssl …` и Python `urllib` (OpenSSL) — работают.

**Следствие:** все сетевые операции в этой ветке выполнялись с `-c http.sslBackend=openssl`. Системные настройки TLS/сертификатов не изменялись.

### 4.2. `push` без учётных данных

Чтение с GitHub анонимное и работает, но для `git push` нужны credentials, которых в сессии нет (`credential.helper = manager`, менеджер в неинтерактивном процессе не отвечает).

Фактический результат проверки (2026-11-02, 22:07 MSK):

```
$ GIT_TERMINAL_PROMPT=0 git -c http.sslBackend=openssl push --dry-run origin stage/s00-static-r01
fatal: could not read Username for 'https://github.com': terminal prompts disabled
```

**Решение продюсера (2026-11-02, в этой сессии):** работаем **только локальными коммитами**; `push` в GitHub из сессии агента не выполняется. Публикация веток — вручную продюсером из его собственного терминала:

```
git push -u origin stage/s00-static-r01
git push -u origin stage/s01-unity-pilot
```

**Следствие:** ветки существуют только в локальном репозитории на `C:\Users\bow\Desktop\CubeGame`; в GitHub их нет до ручного push. Это ограничение сессии (отсутствие credentials + неинтерактивный TTY), а не свойство репозитория: `fetch` по HTTPS работает анонимно.

### 4.3. Псевдокод Reversal деградирован

В телах функций потеряны параметры (видны обращения к неинициализированным `column`, `world`), поэтому точные формулы (особенно высоты и координатной иерархии) не выводятся. Всё, что не следует из констант и структуры конструкторов, помечено `UNKNOWN`; две гипотезы о вложении `Region` записаны в `GENERATION_MOVEMENT_SPEC.md` §1.1.

### 4.4. Правовые ограничения

Reversal — не исходники автора игры; права не передавались. В репозиторий не попали ни фрагменты декомпиляции, ни оригинальные ассеты; в документах только собственные формулировки, имена классов (публичные RTTI-строки) и схемы контейнеров.

## 6. Что осталось неподтверждённым

1. Точное вложение `World → Region → Chunk → Zone → ZoneTile` (гипотезы H1/H2).
2. Формула высот Alpha и механизм seed (в пилоте — `PLACEHOLDER_NOT_ALPHA`).
3. Поведение камеры и движения (скорости, дистанция, FOV, ограничения) — требует игрового теста S00-01/S00-04.
4. Внутренние форматы `.cub`, `map_*`, `world_*`, `db.dat`, `resource*.dat`.
5. Bit-exact подлинность локальной копии (нет официальных хешей) — переносится из G0 без изменений.
6. Публикация ветки в GitHub **не выполнена** по решению продюсера: только локальные коммиты, `push` делает продюсер вручную — см. §4.2 (с фактическим выводом команды).
