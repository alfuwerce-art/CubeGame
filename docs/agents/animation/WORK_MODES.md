# Four work modes (per requirement)
CREATE: author original motion on current mannequin. Inspect authorized visual reference in motion; record action, key poses, timing, contacts, silhouette/tempo and intentional exaggeration. Build poses on target, test interpolation, bake native UE clip, reload, compare and review. For Quaternius only visible playback; no data extraction, download, import, retarget or copying from site/related packs/cache. No source skeleton needed. If reference unavailable, mark NOT_RUN; use authorized alternate if sufficient.
ADAPT: only where owner permits source asset use and license/provenance verified. Identify actual clip, skeleton, rate, root policy, rest axes, mapping and contact phases. Retarget on existing rig; inspect source -> target -> final. Adapt timing, target offsets and silhouette, not realistic mocap by default. No redesign of target geometry or shared skeleton without authorization. Preserve original source file. If adapting a visual-only source use CREATE instead.
EDIT: reproduce named defect in exact active clip/runtime. Snapshot all affected asset tracks and metadata, define exact allowed keys and protected elements. Edit local frames/bones or runtime layer; compare actual exported tracks before/after, check continuity at neighboring frames and linked transitions. For fingers preserve all non-finger tracks, clip timing and root motion; for Idle preserve visible motion and stance, not just derivative maxima. A separate candidate copy for safety is not authorization to replace the original asset or alter other clips.
REVIEW: inspect current baseline/candidate and identify precise defects; no asset mutations or auto-fixes unless separately requested. Apply quality protocol. A scoped review may use gameplay SKIP only with reason. Distinguish self-review from owner approval.
Source catalog: authorized local D:\Projects\скачанные анимации read-only; Epic Game Animation Sample, Lyra, Content Examples, Third Person Template as verified references or authorized licensed assets; Quaternius/Cube World visual only. See playbook. Log actual clip and provenance, no mass downloads or unrelated imports. Do not invent source measurements.
