# SEARCH — source selection and visual direction gate
Mandatory for new/replacement animation when no exact clip is specified. Do not create original motion unless explicitly authorized. Use existing cubegame-rig-animation throughout.
## Search
Inventory all relevant available libraries, not just first result. Check actual files/clip names, original playback, action/direction, rig, pose, source version, phase, root policy, license and owner permission. Mark checked/no match/unavailable with concrete evidence; documentation or file name alone is not a visual preview. No bulk downloads. For each viable family record suitability, missing clips, and reasons. Prefer coherent family for cycles, left/right starts/stops and transitions. Quaternius and Cube World are strictly visual only; no downloading/extracting/importing/retargeting their data. No automatic CREATE if search fails; present blockers/options.
## Selection then adaptation
For replacement families, pick at least two viable candidates if available; compare on identical target rig, cameras, floor, phase and playback, including game view. Retarget only licensed, owner-permitted sources and keep original read-only. Preview candidates separately; no in-place replacement of unrelated source-named packages. Assess lightness/energy, silhouette, arm/shoulder/pelvis coordination, rhythm, weight transfer, posture and foot contact. Record timestamped differences and actual inspection evidence. If only one viable family, explain alternatives and reason.
First show Walk/Run cycles and request owner artistic direction. Do not adapt or bind starts/stops to an unapproved replacement family; preserve existing transitions. This is a meaningful art approval gate, not an approval for every small internal edit. Once owner selects family, adapt starts/stops and Walk↔Run using compatible L/R phases; test full runtime matrix. Separate selection approval from final acceptance.
