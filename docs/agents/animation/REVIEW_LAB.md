## Minimal deliverables
1. Reproducible baseline/candidate preview with same rig/mesh, lighting, floor grid, camera, clip phase, playback rate. Side-by-side or deterministic sequential capture is acceptable when side-by-side unavailable. Match reference phases, not source joint coordinates. Add front/side/rear/gameplay views and hand close-up, 1x/0.5x and step/scrub. Label asset path/revision, clip, frame/time and speed. Record actual active clip in PIE.
2. Capture at least three cycles for looping clips, full action for nonloops, transitions before/during/after and dense frames around defects. Save recordings, ordered frames, and metadata/telemetry; agent must inspect them and record actual observations (not just generate files). If unable to see motion, mark NOT_RUN and explain limitation.
3. Deterministic input scenarios for locomotion: idle hold, repeated start/run/stop (at least ten), walk->run, run->walk, mid-start release, mid-stop restart, short taps, 90/180 turns, camera orbit while holding movement, left/right Shift if relevant. Recheck after Stop->Play. Compare speed, support drift, pelvis height, root/capsule, active sequence and blend. No need for backward/strafe assets when forward facing movement is the intended mode.
4. Regression export: normalized saved/reloaded UE track maps and protected file receipt; compare keys permitted by scope, all others exact. Validate deformation on actual mesh and protected other mannequin. Capture missing tools/rights separately.
## Selection review (new/replacement families)
Use same female or male target, rest pose, camera, floor, playback speed and matched action phase to compare at least two viable candidate families when available. Compare source and target, normal and slow speed, shoulders/arms/pelvis coordination, silhouette, style, rhythm, posture, foot contacts and visible expressive motion. Record observed shortcomings at timestamps, not generic PASS. Present Walk/Run only first; wait for owner direction before modifying dependent start/stop/transition packages. Approval of cycles is not full locomotion acceptance. If only one viable candidate exists, document all alternatives and why unavailable/unsuitable.
