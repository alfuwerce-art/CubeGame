# CubeGame — оценка обвязки ИИ
Сравнивать изменения Harness только на одинаковых задачах, SHA, критериях и проверяемых результатах. Учитывать число ошибок, пропущенные требования, ручные исправления, повторные попытки, время и качество Windows Player.

Протокол: предложить изменение → безопасная локальная проверка → сравнение с базой → явное одобрение → интеграция. Нельзя считать успешный запуск скрипта доказательством работы hook в агенте. Не менять GDD, полномочия или модель по инициативе агента.

Заметки о проверенном опыте хранить отдельно от постоянных AGENTS/Memory.
