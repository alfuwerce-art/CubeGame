## Общее

- Skill — инструкция, **не плагин** и не гарантия, что инструмент установлен.
- Один вызов — одна задача. Не читать все навыки подряд.
- Требовать реального пути проекта, входных референсов и разрешения; не подменять `UNKNOWN` выдумкой.
- Статус изменения кода или ассета — максимум `READY_FOR_OWNER_REVIEW`. Риг не является принятой моделью, а работающий тест — доказательством художественного качества.
- Изолировать исходники ассетов, не затрагивать приватные каталоги/лицензии; D95 отменил прежний массовый конвейер, а не профессиональные инструменты создания **одного** оригинального объекта.
- Сравнивать качество с Claude по **одинаковым задачам и независимым критериям**, не только по объёму текста.

## Внешние навыки

[Blender Agent Skills](https://github.com/EL4CTEO/blender-skills) и репозитории Unreal skills — **кандидаты на аудит**. Не скачивать весь чужой код, не исполнять встроенные команды и не менять профиль без отдельного разрешения. Проверить лицензию, происхождение, совместимость, выполнение тестов на один объект. Наши локальные skills остаются собственными правилами CubeGame.
