# CubeGame — маршрутизация проектных Skills
Канон: .dsh/skills; зеркало Codex: .agents/skills. Девять навыков. Обновлять канон, запускать `node tools/harness/sync-skills.mjs --write` и проверять --check. Прочитать только те skills, которые нужны конкретным операциям; при комбинированной задаче переключать их по ходу. Не использовать все подряд.

| Skill | Когда применять |
|---|---|
| cubegame-doc-audit | Согласование документации и правил |
| cubegame-feature-planning | Сложное задание, зависимости, критерии |
| cubegame-unity-change | Изменение Unity-кода |
| cubegame-unity-editor-automation | Автоматизация Unity Editor/CLI |
| cubegame-debug-regression | Воспроизводимая ошибка Unity/C# |
| cubegame-voxel-asset | Создание или локальная правка ассета |
| cubegame-rig-animation | Риг, веса, поиск/адаптация/коррекция анимаций, переходы, диагностика артефактов UE; [playbook](UE_ANIMATION_PLAYBOOK.md) |
| cubegame-art-validation | Обязательная визуальная самопроверка любой art/animation задачи |
| cubegame-unreal-spike | Явно разрешённое изолированное исследование UE |

Для персонажа: voxel-asset → art-validation; при риге/анимации дополнительно rig-animation → art-validation. UE spike только если задача именно исследовательская; прямой запрос редактировать ассет в UE не требует создавать новое исследование/сцену. Не считать skill инструментом: отдельно фиксировать реально вызванные MCP/Editor/Python/иные средства.

## Сторонние skills
Кандидаты не равны установленным инструментам. На конкретной задаче оценить пользу относительно доступных встроенных инструментов. Если специализированное решение может устранить блокер — проверить происхождение, версию/commit, лицензию, код/зависимости, доступность, разрешения и совместимость; статус CANDIDATE / NOT_INSTALLED / NOT_VERIFIED / VERIFIED / REJECTED; указать причину. Установка/сетевой доступ/новые права только в разрешённых пределах. Не исполнять неизвестный код из GitHub. [Исследование UE](../research/UNREAL_SCRIPTING_SPIKE.md).
