# CubeGame — маршрутизация проектных Skills
Канон: .dsh/skills; зеркало Codex: .agents/skills. Девять навыков. Обновлять канон, запускать `node tools/harness/sync-skills.mjs --write` и проверять --check. Прочитать только те skills, которые нужны конкретным операциям; при комбинированной задаче переключать их по ходу только вне анимационного workstream; для анимаций действует исключение ниже. Не использовать все подряд.

| Skill | Когда применять |
|---|---|
| cubegame-doc-audit | Согласование документации и правил |
| cubegame-feature-planning | Сложное задание, зависимости, критерии |
| cubegame-unity-change | Изменение Unity-кода |
| cubegame-unity-editor-automation | Автоматизация Unity Editor/CLI |
| cubegame-debug-regression | Воспроизводимая ошибка Unity/C# |
| cubegame-voxel-asset | Создание или локальная правка ассета |
| cubegame-rig-animation | Риг, веса, поиск/адаптация/коррекция анимаций, переходы, диагностика артефактов UE; [playbook](UE_ANIMATION_PLAYBOOK.md), [quality protocol](animation/QUALITY_PROTOCOL.md) |
| cubegame-art-validation | Обязательная визуальная самопроверка любой art/animation задачи |
| cubegame-unreal-spike | Явно разрешённое изолированное исследование UE |

Для геометрии персонажа: voxel-asset → art-validation. Для рига/анимации: rig-animation — основной на весь workstream, art-validation — обязательная подчинённая проверка, после неё вернуться к rig-animation.

## Фиксация навыка для анимаций (обязательная)
- Запросы о RUN-02, Play Mode, просмотре, подборе, ретаргете, создании/правке движения, MCP, переходах, записи памяти и архива относятся к cubegame-rig-animation. Не переключаться на voxel-asset, unreal-spike, Unity skills, feature-planning, doc-audit, сторонний OpenAI Docs или иные навыки для их выполнения. Не читать сторонние skills ради поиска документации или архива. Использовать разрешённые инструменты UE/MCP/UI/терминал/Python/Git напрямую. Обязательные общие документы, task-gate и art-validation не означают смену основного навыка.
- Если задача действительно выходит за рамки анимации (например, изменение геометрии или системной настройки), записать checkpoint и запросить отдельное поручение; не менять scope самостоятельно. В смешанной явно порученной работе разделить задачи, а не обходить skill lock. При блокере сначала восстановить штатный инструмент по [инструкции](animation/EDITOR_RECOVERY.md), иначе BLOCKED.
- Для новой/заменяемой анимации сначала SEARCH по [каталогу и протоколу отбора](animation/SOURCE_SELECTION.md); EDIT локального дефекта не требует поиска. Не переходить к CREATE без разрешения, не переносить Quaternius.

 UE spike только если задача именно исследовательская; прямой запрос редактировать ассет в UE не требует создавать новое исследование/сцену. Не считать skill инструментом: отдельно фиксировать реально вызванные MCP/Editor/Python/иные средства.

## Сторонние skills
Кандидаты не равны установленным инструментам. На конкретной задаче оценить пользу относительно доступных встроенных инструментов. Если специализированное решение может устранить блокер — проверить происхождение, версию/commit, лицензию, код/зависимости, доступность, разрешения и совместимость; статус CANDIDATE / NOT_INSTALLED / NOT_VERIFIED / VERIFIED / REJECTED; указать причину. Установка/сетевой доступ/новые права только в разрешённых пределах. Не исполнять неизвестный код из GitHub. [Исследование UE](../research/UNREAL_SCRIPTING_SPIKE.md).
