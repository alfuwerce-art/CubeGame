# DeepSeek Harness — проектные навыки
По локальному отчёту DSH обнаруживает девять навыков из `.dsh/skills`. Обнаружение не подтверждает установку сторонних программ или работу hook.

| Skill | Назначение |
|---|---|
| cubegame-doc-audit | Согласование документации, ссылок и решений |
| cubegame-feature-planning | Задание, зависимости, критерии приёмки |
| cubegame-unity-change | Изменение игрового Unity-кода |
| cubegame-unity-editor-automation | Узкая автоматизация Unity Editor/CLI |
| cubegame-debug-regression | Воспроизведение ошибки, исправление, регрессии |
| cubegame-voxel-asset | Создание одного оригинального игрового ассета |
| cubegame-rig-animation | Риг и анимация конкретного ассета |
| cubegame-art-validation | Проверка одного визуального результата |
| cubegame-unreal-spike | Изолированное исследование Unreal по разрешению |

Использовать один релевантный skill; не запускать все подряд. Вход — конкретный TASK, выход — измеряемый результат и воспроизводимые доказательства. Статус `READY_FOR_OWNER_REVIEW` ставится до решения владельца.
