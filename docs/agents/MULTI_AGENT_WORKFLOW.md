# CubeGame — работа нескольких агентов
Codex и DeepSeek — исполнители; ChatGPT — архитектура и ревью; владелец — решения и интеграция. Один TASK, назначенный исполнитель, baseline SHA, отдельная ветка, scope, проверки и отчёт. [Общий контракт](HARNESS_TASK_TEMPLATE.md), [Harness](HARNESS_ARCHITECTURE.md), [Skills](SKILLS_INDEX.md). Одна сессия Editor на проект, не параллелить правку тех же файлов. Между агентами передавать TASK, доказательства, Git SHA и паспорта ассетов, не всю переписку.

Принятые свойства не пересматривать; проверять scope и сохранность при локальных изменениях. Не создавать побочные системы. Внутренние проверки выполняются автономно, без дробной приёмки. Перед интеграцией независимо проверить diff, evidence и совместимость. Не force-push, не удалять историю, не merge самостоятельно. Неизвестные детали не выдумывать; существенный блокер объяснить. Архив только по запросу.
