# CubeGame — работа нескольких агентов
**Исполнители:** DeepSeek Harness и Codex. **ChatGPT:** архитектура, сводка требований и независимое ревью. **Владелец:** утверждение и интеграция.

Одна задача — назначенный исполнитель, исходный SHA, отдельная ветка, допустимые пути, тесты и отчёт. Один Unity Editor на каталог; параллельное редактирование тех же файлов запрещено. Между агентами передавать короткий TASK и ссылки на Git-коммиты, а не всю переписку.

Перед интеграцией проверить diff, фактические тесты и совместимость с текущей базой. Нет force-push, удаления истории и самостоятельного merge. Неизвестные требования записать как вопросы. Архивные исследования — по запросу, не по умолчанию.
