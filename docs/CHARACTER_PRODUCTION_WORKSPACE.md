# Производственное пространство Factoria

Исходники персонажей ведутся в Factoria. Передача в CubeGame идёт по утверждённому пакету с версией, SHA-256, лицензией, форматом и фактическими результатами. Копирование DCC-исходников в игровой репозиторий не требуется.

| Каталог | Назначение |
|---|---|
| `scripts/`, `workflows/` | Воспроизводимые инструменты и графы. |
| `docs/`, `measurements/` | Согласованные спецификации и разрешённые технические метаданные. |
| `local/sources/<ASSET_ID>/` | Редактируемый источник кандидата, описание рига и файл обмена Blockbench. |
| `local/references/<ASSET_ID>/` | Частные референсы владельца и листы сравнения. |
| `local/exports/<ASSET_ID>/` | FBX/GLB, настройки импорта и временные выходы. |
| `local/reports/<ASSET_ID>/` | Проверки, данные измерений, хэши и визуальный лист. |

Используйте устойчивый идентификатор `FAMILY_VARIANT_BASE_Vn` заглавными латинскими буквами, цифрами и подчёркиваниями. Версия сохраняет предыдущий согласованный исходник. При изменении рига обновляйте карту соответствий и проверяйте привязку, сокеты и существующие клипы после повторного импорта.

Текущий пилот [HUMAN_MALE_BASE_V1](HUMAN_MALE_BASE_V1_REVIEW.md) имеет локальные исходники и отдельный проект импорта. Скрипты и эксперименты разных поколений дают материал сравнения. Качество проверяется на версии, которую передают владельцу.

Проверка документации Factoria и CubeGame: python scripts/verify_character_docs.py --cubegame <checkout>. Для Factoria отдельно запустите скрипт без аргумента. Тот же скрипт работает в GitHub Actions.
