# CubeGame — действующие решения
Применять только утверждённые положения. `UNDECIDED` — решение владельца ещё требуется. Полная хронология и исследовательская база доступны в `archive/decisions/` и Git; они не являются текущим планом.

| Тема | Утверждено |
|---|---|
| Игра | Одиночная авторская Windows-first 3D action RPG на Unity; модульный монолит ADR-0001 |
| Мир | Процедурные регионы, постоянные последствия, активная/облегчённая симуляция, независимые прохождения |
| Визуал | Детализированный voxel/pixel 3D; визуальные эталоны принимает владелец |
| Расы | Human, Orc, Goblin, Lizard, Elf, Dwarf, Undead; культурные и личностные различия |
| Фильдор | Редкие NPC первого публичного одиночного релиза; опциональная будущая играбельная раса |
| Бой | Контактные попадания, различное оружие и защита; развитие через практику |
| Магия | Одно конечное магическое дерево с шестью направлениями и сочетаниями |
| NPC | Характер, занятия, отношения, память, действия и последствия |
| Квесты | События мира, выбор и последствия; фракции, территории, торговля |
| Сохранения | Seed + значимые изменения мира и героя, сон как точка возрождения, выбор режима потери предметов |
| Контент | Девять крупных биомов и 41 микробиом — принятый каталог расширения; первый релизный объём ещё уточняется |
| Выпуск | Вертикальный срез → внутренняя Alpha → Beta → Release Candidate → одиночный релиз; заморская кампания позже |

Источники продуктовых решений: D01–D36, D59–D82, решение о сроке появления Фильдора. Старые одинаковые номера из разных серий не использовать без названия и контекста. Текущие пробелы: [OPEN_DECISIONS](OPEN_DECISIONS.md). Изменение утверждённого правила оформляется решением владельца.
