# Контракт передачи персонажей Factory → Unity (внутри CubeGame)

[Factory](../../Factory/README.md) — встроенный производственный каталог CubeGame: DCC-исходники, библиотека модулей, риги, анимационные ресурсы, экспорт и измерения. `CubeGame/` хранит игру, требования и интеграционные контракты. **Один Git-репозиторий, один источник каждой версии.** Здесь хранятся контракт, ссылки и технические результаты. Допущенный игровой экспорт передаётся отдельной согласованной поставкой с хэшем и правами использования. [Рабочая карта Factoria](https://github.com/alfuwerce-art/factoria/blob/codex/character-production-workspace/docs/CHARACTER_PRODUCTION_WORKSPACE.md) применяет этот контракт.

## Пакет одного кандидата

| Часть | Проверяемый выход |
|---|---|
| Исходник | Редактируемая геометрия, нейтральная и привязочная позы, версия DCC, источник, условия использования. |
| Риг | Имена, родители, оси, единицы, rest transforms, bind pose, карта весов и таблица соответствий Avatar. |
| Модули и сокеты | Стабильные имена и носители, локальные трансформы, область покрытия, парность. Модель без подходящего модуля осматривается отдельно. |
| Экспорт | Один хэшированный FBX с соответствующим .meta для проверки Humanoid, перечень клипов и диапазоны кадров. |
| Доказательства | Blender round-trip, импорт и оценка клипа в изолированном Unity Editor, технические числа, визуальный лист для владельца. |
| Статус | `READY_FOR_OWNER_REVIEW` после проверок. Допуск в игру и визуальное принятие фиксирует владелец. |

D94 сохраняет единый принцип модульной сборки героя и NPC: расовый манекен, профиль модулей и рецепт внешности, отдельно экипировка. Действующая [ревизия](../ACTIVE_STAGE.md) сверяет документацию и контракт. Производственное применение контракта начинается по отдельной задаче владельца. [Закрытый HUMAN_MALE_BASE_V1](../decisions/2026-11-21-human-male-base-v1.md) хранится как исторический эксперимент.

Если расходятся художественные эталоны, пропорции или требования рига, передайте владельцу имеющиеся варианты с измерениями и ссылками. По результату ревью обновите конкретную версию, а прежний источник сохраните в истории.
