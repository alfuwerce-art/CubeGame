# M0-00 — контрактный handoff для Claude (issue #9 / M0-00C)

**Статус:** `INPUT_FOR_REVIEW`, не изменение контрактов Claude и не приёмка.
**Откуда:** ветка `deepseek/m0-00-full-systems-preparation`, отчёт
[M0_00_FULL_SYSTEMS_PREPARATION_REPORT](M0_00_FULL_SYSTEMS_PREPARATION_REPORT.md).
**Что делать Claude:** учесть в M0-00C; спорные пункты — отдельным решением продюсера. DeepSeek
не менял принятые S02–S04 и не будет менять API без handoff.

## 1. `CORE-ENUM-MISMATCH` — блокирует M0-04A (найдено пилотом)

`Assets/CubeGame/Core/Items/ItemEnums.cs` против r3-доказательств
(`M0_00B_P0_MECHANICS_EVIDENCE §A.1–A.3`, проверка 34/34 PASS):

| Значение | Доказано Alpha | Сейчас в Core | Следствие |
|---:|---|---|---|
| 1 | Axe | Mace | подтип 1 считается как булава |
| 2 | Mace | Fist | сдвиг |
| 3 | Dagger | Sword | сдвиг |
| 4 | Fist | Dagger | сдвиг |
| 5 | Longsword | Longsword | совпадает |
| 6 | Bow | Reserved06 | лук не представлен |
| 7 | Crossbow | Reserved07 | арбалет не представлен |
| 8 | Boomerang | Crossbow | сдвиг |
| 9 | Arrow | Arrow | совпадает |
| 0x0e (14) | Quiver | Boomerang | колчан не представлен |
| тип 5 | Gloves | Boots (enum) | подмена перчаток/обуви |
| тип 6 | Boots | Gloves (enum) | подмена |

Пилот `PILOT_ITEMS` возвращает ровно **10** расхождений и падает, если их станет меньше/больше.
`ItemInstance` дополнительно поддерживает только 8 из 24 типов (тип 1 — расходники, 0x0b —
материалы, 0x15 — квестовые, 0x18 — лампа и др. отвергаются).

**Предложение (не выполнено):** отдельным решением M0-04A расширить контракт типов/подтипов и
добавить миграцию имён; не менять `ItemEnums.cs` «тихо», потому что на нём держатся принятые
S04-тесты и сохранения v1. Нужен явный выбор: (A) новая версия enum + миграция, (B) отдельный
Alpha-контракт в M0-04A без правки S04, (C) другое решение продюсера.

## 2. `SAVE-EQUIPMENT-GAP` — блокирует M0-01D/M0-04D

`SaveGame` v1 хранит персонажа и список предметов; 13 слотов экипировки Alpha не сохраняются.
Пилот подтверждает отсутствие полей рефлексией. Нужны: версия формата, поля слотов, миграция
старых сейвов и тест «экипировка переживает перезапуск» (GS-07/GS-13).

## 3. Единицы ресурсов способностей

Кулдаун и мана прочитаны (`Ability_get_cooldown`, `ability_getManaCost`, мана в 1/100000).
Стамина: значения 100…600 против шкалы 0…1 — нормализация не доказана. В пилоте
`AbilityRuntime` принимает `unitsPerResource` явно; в игре нельзя объявлять это число
«Alpha-балансом» без решения.

## 4. Что пилот **не** доказывает (не включать в контракты как факт)

- `OQ-01` база шанса попадания, `OQ-24` доля блока, `OQ-23` масштаб скоростей.
- Прыжок игрока: ни функции, ни константы.
- Отображение «подтип оружия → действие» — не восстановлено; пилот намеренно отказывает.
- Смерть: полный сброс состояния есть, правило штрафа/точки/таймера — нет.
- Торговля: наценки/ассортимент/ресток F-U5; покупка не реализована.
- Мир: W-18 таблица климат→объекты, W-07 уровень воды, W-11 порог стриминга, `reg/tile/land`.
- Вне-экранная симуляция NPC — требование CubeGame, не Alpha (Alpha сохраняет блобы по близости).
