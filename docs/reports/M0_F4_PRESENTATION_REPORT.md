### Привязки звука

Локальный `Cube.exe` читался в режиме read-only. Диспетчер `0x484350` принимает ID, независимый от строки SQLite. Имена проверены по таблице переходов `0x485E90` и указателям на строки WAV. Адреса ниже указывают на инструкции вызова в Alpha.

| Событие | WAV | Статус |
|---|---|---|
| Завершение миссии | `missioncomplete.wav`, `0x1E` | `ALPHA_CODE_STATIC` / `ALPHA_DECOMPILED`. Q-09, вызовы `0x48F9BE`, `0x4907D7`. Привязка к живому переходу завершения охоты F3 |
| Подбор | `pickup.wav`, `0x2D` | `ALPHA_CODE_STATIC` / `ALPHA_DECOMPILED`. Вызов `0x48CE0C` после добавления предмета. В CubeGame звучит после успешного ground pickup героем |
| Повышение уровня | `levelup2.wav`, `0x1D` | `ALPHA_CODE_STATIC` / `ALPHA_DECOMPILED`. Вызов `0x493E8F`. В CubeGame нужен `ExperienceGained.LevelsGained > 0` |
| Открытие и закрытие интерфейса, выбор в редакторе героя | `menu-open2.wav` `0x53`, `menu-close2.wav` `0x54`, `menu-select.wav` `0x55` | `ALPHA_CODE_STATIC` / `ALPHA_DECOMPILED`. Обе ветви `0x48B30D` и `0x48B337` сходятся к `0x48B33D`. Выбор вызывает `0x42B834`. Набор панелей и полей, использующих cue в UI Toolkit, — `CUBEGAME_CONTRACT` |
| Успешный крафт | `craft.wav`, `0x59` | `ALPHA_CODE_STATIC` / `ALPHA_DECOMPILED`. Вызов `0x470C9A` в ветви успеха. Привязан к рецепту Life Potion |
| Удар, блок, выпитое зелье | `hit.wav` `0x00`, `block.wav` `0x18`, `drink2.wav` `0x2C` | Сэмплы Alpha. Обобщённая привязка к подтверждённому попаданию/блоку и успешному использованию зелья — `CUBEGAME_CONTRACT`. Выбор по оружию, типу действия и точным условиям Alpha — `PARTIAL` / `UNKNOWN` |
| Смерть | HUD и уведомление о победе/поражении | Отдельный звуковой выбор по виду, полу и контексту — `UNKNOWN`. Летальное попадание использует тот же путь feedback, что и обычное попадание |

Для локального запуска `python -m tools.alpha_content.extract_sounds` помещает WAV в `.scratch/content/sounds`. `CUBEGAME_ALPHA_CONTENT` может указывать на другой локальный корень кэша с каталогом `sounds`. Атлас D6 читается из `AlphaOutput/icons` и строится через `CubeGame → Alpha Models → Build Item Icon Atlas` в Unity с графикой. При отсутствии ресурсов игра продолжает работу, а карточки предметов сохраняют текстовое описание.

## Границы F4

- `PARTIAL` для выбора боевых, событийных и пространственных звуков. `UNKNOWN` для точной озвучки смерти, большей части действий и оставшихся Alpha event mappings.
- `PARTIAL` для иконок экипировки. Проверенный селектор модели и локальный атлас покрывают те записи, у которых есть совпадение. Оригинальная легенда карты, Plasma HUD и состояния виджетов остаются `UNKNOWN`. Текстовые маркеры карты и визуальные индикаторы F4 имеют статус `PLACEHOLDER_NOT_ALPHA`.
- `CUBEGAME_CONTRACT` для retained UI и локальных карт. Региональные охоты F3 остаются `PARTIAL` и показываются в журнале отдельно по состояниям. Долги собраны в [Alpha Parity Backlog](../planning/M0_ALPHA_PARITY_BACKLOG.md).
