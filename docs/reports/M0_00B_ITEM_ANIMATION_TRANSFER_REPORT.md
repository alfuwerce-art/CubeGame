## 4. Подготовлено для интеграции (задача 6) — и что НЕ сделано

Контракт `cubegame.item_layer/1` (внутри evidence) содержит всё, что нужно слою предметов в Unity:

* `weaponClasses` / `offhandClasses` / `slotClasses`: индекс модели, имя `.cub`, слот, блок, закон
  `coeff/const/scale`, статус;
* `slots`: смещение, типы предметов, блок(и), условие (флаг/действие/кулдаун), SWAP/ATTACH;
* `actions`: 101 запись с `state`, `weapon`/`offhand` (IN_HAND/ON_BACK), `heldItem`, `petItem`,
  `weaponOnly`, `twoHandedChain`;
* `consumable`, `dual`, `twoHanded`, `dynamicParts`, `unknowns`.

**Сторона Unity не реализована** (и не должна была без M0-00D): в `AlphaRig.Anchor` нет новых правил
(`weapon_bow_in_hand`, `offhand_shield_in_hand`, …), `AlphaClip` не несёт off-hand части, контроллер
не проверяет требования действия к экипировке. Это следующий шаг M0 при отдельном разрешении; форма
данных уже готова и проверена.
