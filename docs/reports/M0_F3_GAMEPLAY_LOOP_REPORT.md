## VALIDATE → PILOT

- **Атаки существ.** C-29 (`0x4452A0`) выбирает стрелу `0x17` для оружия `(3,6)` и магическое действие `0x25` для ветви класса 3. Обработчики выпуска `0x617184` и `0x617C88` проверены в F2B. `CreatureCombatDriver` передаёт `AttackPlan` в боевой runtime для выбора, подтверждённого C-29 или гейтом оружейного действия при известном оружии. Стрела и магический снаряд из тестовых состояний ИИ попадали в героя через `CombatSystem`. S05-каталог показывает `0x25` у волка в условно эмулированном состоянии. Для волка, которого текущий CubeGame спавнит без данных о классе/оружии, этого недостаточно для доказательства выпуска. Старый контактный путь сохранён как `PLACEHOLDER_NOT_ALPHA`. Дальность агро и прицел в центр hit box — `CUBEGAME_CONTRACT`. Пилот `FullM0CreatureAiTests` 9 PASS, 0 FAIL.
- **P-01.** `IMPLEMENTED_PILOT` описывает выбор расы и его runtime, UI и сохранение. `DIRECT` для правила Alpha и ссылка на ограничения визуала F2A сохранены. После исправления P-01 генератор показал те же дефекты в других строках. Старые C1/C2/C3/C6 сопоставлены с их исходными M0-подэтапами из реестра, неоднозначные implementation-статусы нормализованы по тексту строк, два выражения с модулем записаны как `abs(v_xz)`. Генератор остался строгим. `build_transfer_registry.py --check` PASS, 176 строк, хэш `c4a909cda750c97b`.
- **Торговля.** По байтам `0x4C76E0…0x4C77F9` цена единицы равна `max(1, trunc(levelFactor × rarityFactor × 10 × typeMultiplier))`, с удвоением для перечисленных в коде подтипов оружия. Вызовы `0x47DAC6/0x47DAEF` и `0x47DC45` используют ту же цену для списания при покупке и начисления при продаже. Это `ALPHA_CODE_STATIC`. У предметов адаптера без уровня и редкости цена считается для L1/r0.
- **Крафт.** В ветви LifePotion `0x59D3D0…0x59D409` в вектор ингредиентов записываются `(0x0B, 0x16)` и `(0x0B, 0x1A)` по одной единице. Это Heartflower и Water Flask. Состав рецепта — `ALPHA_CODE_STATIC`, доступность кнопки в инвентаре и продажа ингредиентов — `CUBEGAME_CONTRACT`.
- **Услуги.** Ветвь `0x610630…0x610640` для NPC класса `0x84` увеличивает день и ставит 07:00. Соседние условия проверяют вечер/ночь с 18:00 до 06:00. Для платных изменений навыков `0x4DF880` проверяет кошелёк и вызывает `0x47F030`, где проверяются класс, флаг существа и расстояние строго меньше 4 блоков. Мост CubeGame использует свою запись городского наставника нужного класса.
