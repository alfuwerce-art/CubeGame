## CUBEGAME_CONTRACT и PARTIAL

| Пункт | Решение |
|---|---|
| Поток `rand()` | Alpha — глобальный CRT; CubeGame — свой поток на регион (`RegionSeed`), регион всегда даёт те же миссии при том же уровне героя |
| Регион прохода | регион, в котором стоит герой (Alpha выбирает его через поиск ближайшего региона) |
| Хранение | блоки миссий в `.session` (`alphaMissions`, `alphaMissionRegions`); Alpha хранит их в `world_*.db` (`mission<x>_<z>`). Старое поле `huntMissions` читается и игнорируется |
| Босс | 2 предмета экипировки, внешность и поведение `Sequential[Combat(20), RandomWalk]` из `0x5D9460` не перенесены — `PARTIAL`; убитый босс не возвращается (дельты популяции) |
| Равные веса зон | первый по порядку обхода; introsort Alpha для 64 элементов нестабилен — `PARTIAL` |

- В лагере бросок `0x5DDEE6` задаёт ориентацию костра `0x41`. Если костёр помещается, его позиция становится центром группы. Затем идут четыре пары бросков `0x5DE3FF` и `0x5DE4CD` для вида и ориентации объектов вокруг центра. Стационарная группа появляется после этих попыток.
- Прогон на пустом поле подтвердил четыре попытки поставить костёр и 16 пар бросков соседних объектов при нуле созданных объектов. Пустой список вожаков в первом варианте состава 1 пропустил пять патрулей после выбора категории. В трассе шесть выборов категории `0x5DED67` и один бросок ориентации `0x5DEDF3`.
- У стационарных гуманоидов в трассе записаны класс, специализация, оружие и сырые пары «тип, подтип» брони и украшений. Грудная броня `(4,0)` присутствует у всех проверенных стационарных гуманоидов. Материалы, параметры и визуальное применение останутся отдельной проверкой.
