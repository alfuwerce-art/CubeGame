## 3. Правила D60

1. Все клипы `EMULATED_ALPHA_CODE`, `live_check = NOT_CAPTURED` у всех 14 профилей.
2. Каждый вид получил профиль только по собственному П1 (по всем своим seed); тесты: профиль не применяется к другому виду; вид семейства без собственных доказательств остаётся `BLOCKED`.
3. Экипировка: все профили — без оружия. **Наблюдена** только у HumanFemale 0x03 (полный дамп NPC); у бегуна — заголовок захвата (класс/фракция); у остальных 12 видов экипировка NPC **не наблюдалась** — запуск доказан для состояния «без оружия», это отмечено в профиле (`equipment_observed=false`). Оружие NPC в задании → `EQUIPMENT_UNVERIFIED`.
4. Действия видов без доказанного запуска не импортируются (пакет требует профиль своего вида и все его действия; иначе FAIL).

## 5. Ограничения

* Живой захват боя не выполнен ни для одного вида (в доступной области Alpha только дружелюбные NPC).
* Экипировка NPC не наблюдалась у 12 из 14 видов.
* Выбор цели, агрессия, дистанция до участка выбора — `PARTIAL`; ветки особых видов и водных существ не входили.
* Варианты внешности: П1 проверен по всем seed охвата S05B-1, а позы запечены и проиграны на seed (0, 0).
* Технический PASS ≠ художественное одобрение; переходы — `UNITY_TRANSITION`.
