**Механизм:**

* **Область.** Список видов заново вычисляется из статической таблицы по признаку «AUTO_READY, ходьба семейства `TRANSFERRED_FROM_ALPHA`, живой захват найден локально по имени и SHA256» и сравнивается с закреплённым в D59 списком из 15 видов. При расхождении пакет отказывает (`SCOPE_DRIFT`). Виды вне области не запускаются.
* **Охват B.** Эмулятор внешности (`Cube.exe` закреплён SHA256, только чтение, без запуска Alpha) перебирает seed[2]/seed[3] и пары их представителей; жадный минимальный набор, начиная с (0, 0), покрывает каждую модель головы/волос/кистей вида. Итог — 70 seed, нижняя граница (наибольшее число вариантов слота) достигнута для каждого вида.
* **Фазы.** Фаза 1 — seed (0, 0) всех 15 видов + выборки 30/120 Гц для одного вида каждого семейства (0x00, 0x1e, 0x3f) + регрессия действий HumanMale. **Фаза 2 запускается только если всё это PASS** (иначе `PHASE2_BLOCKED`).
* **Задание.** Задание планировщика с нужным seed, **без** библиотеки действий и оружия: у HumanMale в пакете `LOCOMOTION_ONLY` с причиной `ACTION_LIBRARY_NOT_IMPORTED`; действия проверяются отдельной регрессией.
* **Вердикт прогона.** Все 7 шагов (`SELFTEST`, `TRANSFER`, `PLAYMODE`, `PARAMWALK`, `LOCOMOTION_PLAYMODE`, `ENTITY_CONTRACT`, `ENTITY_PLAYMODE`) = PASS с кодом 0, `RESULT=PASS`, код выхода 0; дополнительно `PARAMWALK` с ненулевым числом живых кадров Alpha, `controller_mode=LOCOMOTION_ONLY` и отказ действий. Пороги не менялись.
* **Возобновление и хеши.** `batch_state.json`: повторный запуск пропускает только PASS, у которого совпадают SHA256 задания, входы (статическая таблица, `Cube.exe`, захваты) и SHA256 скопированных отчётов. FAIL, подменённый отчёт или изменённый вход — прогон повторяется (проверено тестом и фактически: фаза 2 пропустила 24 записи фазы 1).
* **Один проект Unity** `.scratch/universal/unity/S05B1`; отчёты каждого прогона копируются в `.scratch/universal/batch/s05b1/runs/<прогон>/`, прежние `TransferOutput` уходят в историю раннером.

## 3. Визуальные материалы (локально, не публикуются — D54)

`.scratch/universal/batch/s05b1/visuals/<вид>.png` — 15 контактных листов из реальных кадров Unity PlayMode (ходьба → остановка → покой → после). Строка листа — один seed с подписью моделей `head/hair/hand`; у видов человеческого семейства лист одновременно является листом вариантов (4–15 строк). Просмотрены листы 0x02, 0x07, 0x40: части на местах, циклы ходьбы и покой без выбросов.

**Наблюдение для художественного просмотра:** у ряда причёсок/голов видны исходные красные и синие маркерные цвета `.cub` (маски tint). В универсальном конвейере tint волос не применяется — это известный открытый вопрос (механизм tint волос, семантика маркеров; S05A-2 использует технический T3 только для своего образца), **не регрессия пакета**. Отдельной задачей при необходимости.
