## 4. Что это даёт

- Регрессия покрывает интеграционную точку `IContentZoneSource` → `ZoneContentPlanner` → `ContentPlacement`,
  поэтому подключение провайдеров Codex не сможет молча сломать состав/детерминизм контента.
- Проверяется правило «удалённый объект не возвращается» и «постройка только на ровной площадке» —
  оба относятся к сохранению мира (дельты, владелец — интегратор).

## 5. PARTIAL / UNKNOWN

  мира и на этапе визуального осмотра.
