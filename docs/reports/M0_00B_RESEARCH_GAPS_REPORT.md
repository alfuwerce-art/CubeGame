## 0. Пять выводов, которые меняют планирование M0

1. **Генерация мира — не «перенос», а проектирование.** Перечисления биомов нет ни в одном документе
   (`biome = FUN_005a4710(rx,rz)` не расшифрована), порядок операций рельефа `PARTIAL`, уровень воды вычисляется в
   неизвестном месте, таблица «климат → объекты» (~660 строк, U6) не выгружена, реки не описаны. Сам исследовательский
   документ прямо требует **собственную** генерацию с Alpha-подобной иерархией, а не бит-в-бит
   ([`B_world.md` §B12](../research/alpha2013/BEHAVIOR_SPECS/B_world.md)). Черновик M0-00 формулирует M0-02A как
   «генерация Alpha-ландшафта … исходных биомов» — это надо переформулировать, иначе этап начнётся с ложной цели.
2. **Скорости и прыжок нельзя воспроизвести «как в Alpha».** OQ-23 остаётся `OPEN`: масштаб единиц неизвестен,
   поэтому ни одна дистанция/скорость (включая AI 80/40, радиус `2r_self+r_target`, LookAtPlayer 8, додж <2) не
   выражается в блоках/с. Констант прыжка нет **вообще** — механика не исследовалась (в `PlayerMotor` стоит
   `JumpSpeed = 7f`, это `PLACEHOLDER_NOT_ALPHA`).
3. **Правила смерти игрока нет.** `E_combat §E10` — `UNKNOWN`: штрафы, точка возрождения и таймер не восстановлены.
   Сквозной сценарий GS-06 «возрождение по правилу Alpha» в текущей формулировке невыполним: это продуктовый выбор
   продюсера, а не переносимая константа.
4. **Поведение существ вне экрана не исследовано.** В реестрах нет ни деспавна, ни активации по дистанции, ни лимита
   популяции региона (`G_H §G5` — «лимит не найден»; `C_streaming` описывает только зоны и плитки). Подэтап M0-06D
   («состояния и события NPC вне экрана») сейчас не имеет спецификации — ему нужен отдельный research-шаг, а не код.
5. **Есть системная ложная готовность в M0-00 §2.** `CombatDemo`, `EquipmentCombatDemo`, `CharacterSheetPresenter`
   **не входят ни в одну сцену** (единственный вызывающий — PlayMode-тест), `SaveGame` не содержит экипировку,
   `AlphaMath.KillExperience`/`FormHaste` и `ItemStatsCalculator.RollRarity`/`Value` вызываются **только из
   EditMode-тестов**, в `Packages/manifest.json` нет
   Input System, AI Navigation и URP. При этом M0-00 §2 называет боевые/предметные модули «ГОТОВО», а PlayMode 17/17 —
   как подтверждение работы в игре.

## 4. Механики, которых нет в реестрах вообще (найдено при аудите)

1. **Прыжок** — ни констант, ни условий (в `I_movement` только dash и гравитация).
2. **Регенерация HP игрока** — не описана ни в `D_character`, ни в `E_combat`; известны только реген фракции 5
   (10 %/с) и сон у объектов (5 %/с).
3. **Критические удары** — 0 упоминаний; в восстановленных формулах их нет (элементный прок ×2 — не крит).
4. **Поведение существ вне экрана** — деспавн, активация по дистанции, лимит популяции.
5. **«Лагеря»** как контент — в Alpha есть только типы целей invasion/gang (7…13); генератора лагерей нет.
6. **Маппинг «событие → звук»** — известен ровно один звук (`missioncomplete.wav`, id 0x1e) из 93 `.wav`.
7. **Раскладка UI** — Plasma UI заменяется Unity; ни одного каталога экранов (`VISUAL_CATALOG` — `DEFERRED`).
8. **Имена регионов** — упомянуты слоговые таблицы, но самих таблиц нет.
9. **Единицы `time`** в `world_<name>.db` (8 Б) — не установлены.
10. **Лимит стака** — найден попутно (≤49 через `quest_checkItemThreshold`), но правила стаков не специфицированы.
