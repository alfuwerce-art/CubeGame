# D86 W-18 — принадлежность адреса `0x005EFFA0` и границы переноса размещения

**Дата:** 2026-11-09. **Исполнитель:** DeepSeek Harness. **Ветка:** `deepseek/d85-visual-unity`.
**Вопрос продюсера:** в документах DeepSeek `World_placeObjectWithSpacing` связан с адресом `0x005EFFA0`, а у Claude
этот же адрес исполняется как **маска гор**. Нужно проверить принадлежность адреса и вызовы до портирования.
**Ответ (кратко):** это **одна и та же функция**, но она **не является алгоритмом размещения объектов**. Она считает
маску рельефа (perlin + smoothstep + поправки на тип колонки). Её значение использует и генератор рельефа, и W-18 как
свой аргумент `fVar6` («spacing»). Политика размещения объектов по-прежнему `UNKNOWN` → `CUBEGAME_CONTRACT`.

## 1. Что проверено и где

Тело функции (`game_misc.cpp:47652–47800`) состоит из:

1. `perlinNoise2D_cosInterp` в нескольких масштабах (`×0.01`, `×0.0025`, `×0.005`, со смещениями мира `+843/984/94/874`);
2. `GameController_getVoxelColumn8(x >> 11, z >> 11)` и поправок по типу колонки (2 = гора, 4/5 = озеро/руины,
   6/7 = каньон/долина, 10 = срез) через `vec3_distanceSquared` и `sqrt`;
3. финального `f·3 − f·2f²` (smoothstep) и **возврата значения** — это и есть маска.

Имя `World_placeObjectWithSpacing` — результат переименования по месту вызова (аргумент `fVar6` в W-18 принимали за
«spacing»), а комментарий декомпилятора «Places an object at (x,y) enforcing spacing via sqrt distance checks» относится
к вызовам внутри тела, которые на самом деле возвращают скаляры и умножаются на маску. То есть **имя описывает не то, что
делает функция**.

## 2. Совместимость двух версий

Оба документа верны и не противоречат друг другу:

* Claude исполняет `0x005EFFA0` в пути рельефа (`0x5C5E20`/`0x5E4850`) и получил **маску гор** с точностью `2.1·10⁻⁷` —
  это доказательство формулы **исполнением**.
* DeepSeek использует тот же адрес в W-18 (`0x005F56C0`) как аргумент `fVar6`; в дереве W-18 он участвует только в
  сравнениях (`0.3 < fVar6` → добавить объект `0x2f`; в подземной ветке не участвует).

Следствие для W-18: `fVar6` — **не «расстояние между объектами», а значение маски рельефа**, то есть ветка `0.3 < fVar6`
означает «на горном/каньонном рельефе добавляется объект `0x2f`», а не «объект ставится с шагом». Это уточнение смысла,
а не новая интерпретация: сама формула маски исполнена и подтверждена.

## 3. Что это меняет в коде DeepSeek (и что нет)

**Изменено (проверяемо):**

* Все комментарии и отчёты, где `0x5EFFA0` назывался «алгоритмом размещения объектов» / «placeObjectWithSpacing, не
  портирован», исправлены: это **маска рельефа**, и её порт уже существует в генераторе Claude.
* `AlphaScatterField` принимает `spacing` как значение **или** как функцию `(x,z) → fVar6` — теперь к ней можно
  подключить исполненную маску без изменения вызовов. До подключения значение остаётся документированным входом
  CubeGame, а не «значением Alpha».
* Позиции объектов в `AlphaVegetationPlanner`/`ZoneContentPlanner` помечены `CUBEGAME_CONTRACT` — это позиции
  CubeGame, а не перенесённая Alpha-политика.

**Не изменено (и не будет без новых доказательств):**

* правила «что где стоит», плотность, отталкивание объектов, порядок `rotateAndPlace` и вызывающий код, который
  превращает список id в расставленные объекты — `UNKNOWN`;
* `spacing` не подменяется случайными числами и не выдаётся за Alpha.

| Элемент | Статус |

| Подключение маски к `AlphaScatterField` в Unity | `READY_FOR_INTEGRATION` (шов готов, значение пока задаёт вызывающий) |

## 5. Что должен сделать интегратор (Claude)

После слияния достаточно передать исполненную маску в существующий шов:

```csharp
// world: уже есть исполненная маска (M0-02b/c)
var field = new AlphaScatterField(
    climateGrid,                       // IAlphaClimateGrid: Humidity/Temperature/RegionCell
    (x, z) => terrain.MountainMask(x, z));   // fVar6 = значение 0x5EFFA0 в этой точке
```

Если генератор пока не отдаёт маску по произвольной точке — оставить текущее значение и сохранить статус
`CUBEGAME_CONTRACT`; подмена «похожей» формулой запрещена (это уже было бы выдачей догадки за Alpha).
