# Roadmap CubeGame

[Актуальный GDD](GDD.md) описывает самостоятельную игру. Игровой roadmap сохраняет направление владельца. Текущий объём определяется [активной задачей](ACTIVE_STAGE.md).

| Поток | Результат | Зависимость | Статус |
|---|---|---|---|
| G0–G2, техническая база и мир | Существующий runtime и результаты отбора инженерных кандидатов для дальнейшего развития | Отдельное решение о сведении кодовых веток и совместимости | История зафиксирована по соответствующим веткам, ревизия персонажей их не объединяет |
| G3, модели и анимации | Один эталонный человек, подтверждённый Blender/FBX и техническим импортом в чистом Unity Editor | Согласование эталона владельцем | Текущая задача |
| Развитие G3 | Библиотека модулей, общий контракт сборки внешности игрока/NPC, риг и клипы, крепления экипировки | Приёмка эталона, отдельный объём | Направление D94 |
| G4–G8, игровые системы | Вертикальный срез CubeGame от создания героя до продолжения сохранённого мира | Принятый объём среза, техническая база, собственный контент | Запланировано |
| G9–G12, контент и окружение | Собственное окружение, эффекты, звук, UI и игровые точки интереса с проверкой в Player | Рабочий срез, арт-эталоны | Запланировано |
| G13–G15, качество и выпуск | Профили производительности, тесты регрессии и часть релизного контроля | Завершённый продуктовый объём | Запланировано |
| Будущие расширения | Каталог биомов и микробиомов, новые существа, сезоны | Дальнейшее решение владельца, рамки D82 | Отложено |

[Исторический развёрнутый план G0–G15](planning/ROADMAP_DRAFT.md) сохраняется как источник планирования. Исторические M0 и M1 не открывают работы по переносу Alpha.
