# Roadmap CubeGame

Действующая цель — самостоятельная игра по [GDD](GDD.md) и [D93](decisions/D93-development-pivot-own-game.md). [Активная задача](ACTIVE_STAGE.md) определяет допуск к исполнению. Таблица сохраняет порядок и объём стадий G0–G15. Наличие исторического кандидата в Git не является приёмкой или допуском.

| Стадия | Результат и состояние |
|---|---|
| G0 — Development Pivot / Baseline Freeze | Направление самостоятельной CubeGame утверждено D93. Исследования Alpha остаются источником сравнения. |
| G1 — Technical Foundation | Компиляция, сохранения, Player и набор регрессий на выбранной базе. Отбор и сведение инженерных веток проходят отдельное ревью. |
| G2 — World Foundation | Детерминированные регионы, генерация, сохранение последствий и измерение стриминга. Существующие инженерные кандидаты проверяются отдельно. |
| G3 — Character & Creature Factory | D94 закрепляет концепцию и порядок: расовый манекен → визуальные модули → общая сборка/редактор и детерминированный NPC → совместимый риг/анимация → экипировка → интеграция. Негуманоиды по потребности. HUMAN_MALE_BASE_V1 — `REVIEW_CLOSED / NOT_SELECTED`. Производство по новому поручению. |
| G4 — Core Combat | Рабочая основа боя, реакции, управление и воспроизводимые контрольные сценарии. Перспектива, отдельный допуск. |
| G5 — NPC & Living World Foundation | Жители, расписания, события, состояние поселений и последствия в одной симуляции. Перспектива, отдельный допуск. |
| G6 — RPG, Items & Economy Foundation | Прогрессия, лут, хранение, крафт, торговля и согласованная экономика. Перспектива, отдельный допуск. |
| G7 — Core Gameplay Prototype | Рабочий связанный игровой цикл на ограниченном объёме контента, включая сохранение и продолжение. |
| G8 — Vertical Slice | Одна законченная репрезентативная область с полным циклом, контрольными метриками и ревью владельца. |
| G9 — World & Visual Production | Окружение, собственный визуал, биомы и воспроизводимый контент мира. |
| G10 — Character, Creature & Animation Production | Производство согласованного набора персонажей, существ и анимаций после проверки эталонов и контрактов. |
| G11 — Content, Quests & World Systems | Первый согласованный набор мест, событий, задач и связанной прогрессии. Включить редкие NPC Фильдор в первый публичный одиночный релиз. |
| G12 — UI / UX / Audio / VFX Production | Интерфейс, звук, эффекты, настройки и проверка взаимодействий. |
| G13 — Game Alpha | Полная внутренняя проверка самостоятельной CubeGame, регрессии, стабильность и производительность. |
| G14 — Game Beta | Исправление дефектов, UX, баланс, совместимость и проверки на целевых конфигурациях. |
| G15 — Release Candidate / 1.0 | Первый публичный одиночный выпуск по согласованному составу и требованиям приёмки владельца. |

После первого публичного одиночного релиза отдельно планируются заморский континент и кампания, расширение каталога биомов и сезоны. Выбор Фильдора в редакторе относится к возможному DLC. Стартовый набор редактора в [открытых решениях](design/OPEN_DECISIONS.md). [Развёрнутая историческая дорожная карта](planning/ROADMAP_DRAFT.md) сохраняет происхождение стадий.
