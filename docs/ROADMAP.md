# Roadmap CubeGame

Требования к игре описаны в [GDD](GDD.md), ближайшая работа — в [ACTIVE_STAGE](ACTIVE_STAGE.md). Стадии с художественной или продуктовой приёмкой закрывает владелец.

## Ветки

`integration/m0-all` — действующая интеграционная ветка и цель PR. `main` — текущая default branch GitHub и ранняя историческая база. Целевое переключение на единственную `main` выполняется после приёмки проверенного интеграционного коммита и сверки GitHub HEAD. Дополнительная `develop` не требуется.
