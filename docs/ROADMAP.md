# Roadmap CubeGame

Действующая цель — собственная Unity-игра по [GDD](GDD.md) и [D93](decisions/D93-development-pivot-own-game.md). **D95 закрывает конвейер моделей**; способ производства персонажей и анимаций не утверждён. Открытие любой стадии — отдельное решение владельца.

| Стадия | Результат |
|---|---|
| G0 — Development Pivot | Самостоятельная CubeGame вместо переноса Alpha. |
| G1 — Technical Foundation | Рабочая версия Unity, сборка, сохранения и регрессионные тесты. |
| G2 — World Foundation | Процедурный мир, регионы, стриминг, сохранение последствий. |
| G3 — Characters and Character Editor | Определить и проверить первый качественный игровой персонаж, редактор и требования к NPC. **Производственный метод не утверждён**, прежний конвейер отменён. |
| G4 — Core Combat | Игровая основа боя, управление, реакции и контрольные сценарии. |
| G5 — Living World / NPC | Жители, расписания, память, события и последствия. |
| G6 — RPG, Items & Economy | Прогрессия, предметы, лут, крафт, торговля. |
| G7 — Core Gameplay Prototype | Связанный игровой цикл на ограниченном наборе контента. |
| G8 — Vertical Slice | Законченная демонстрационная область с воспроизводимым циклом. |
| G9 — World & Visual Content | Собственные биомы, материалы, освещение, окружение. |
| G10 — Characters & Animation Content | Принятые персонажи, существа и анимации, **без предрешённой технологии производства**. |
| G11 — Quests & World Content | Места, события, задания и развитие; Фильдор как редкие NPC первого релиза. |
| G12 — UI / UX / Audio / VFX | Полноценный интерфейс, звук, эффекты и настройки. |
| G13 — Game Alpha | Внутренняя функциональная, визуальная и техническая проверка. |
| G14 — Game Beta | Баланс, оптимизация, UX и совместимость. |
| G15 — Release Candidate / 1.0 | Первый публичный одиночный релиз. |

Кампания на заморском континенте, дополнительные биомы и сезоны остаются последующими вехами по игровым решениям. Подробности по редактору — в [открытых вопросах](design/OPEN_DECISIONS.md).
