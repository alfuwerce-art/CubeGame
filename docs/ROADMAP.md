# CubeGame — Unreal-first Roadmap
**Дата:** 2026-11-22. **Статус:** новая последовательность — `PROPOSED_FOR_OWNER_APPROVAL`; Unreal-пилот U0–U4 разрешён отдельно. Игровые требования GDD остаются действующими. Не считать смену релизного движка утверждённой.

## Технический шлюз: сначала готовый игровой фрагмент
| Этап | Результат | Приёмка |
|---|---|---|
| U0 — Toolchain | Unreal, C++/UBT, Python Editor, DeepSeek и MCP | Реальные версии и один успешный read-only MCP вызов; иначе `BLOCKED` |
| U1 — Скриптовая сцена | Небольшая блочная арена, материалы, свет, камера | Идемпотентный Python, лог и скриншот редактора |
| U2 — Управление | Third-person C++ герой-заглушка, камера, прыжок, коллизии | Управление в PIE/Standalone |
| U3 — Мини-игра | C++ бой, враг/HP, подбираемый предмет, простой HUD, сохранение и загрузка | Один связанный игровой сценарий, записанный на видео |
| U4 — Проверка | Автотесты, Win64 сборка, нагрузка, ошибки DeepSeek и человеческие доработки | Решение владельца: продолжить Unreal / доработать пилот / оставить Unity |

Контракт U0–U4 — [UNREAL_FIRST_PLAYABLE](experiments/UNREAL_FIRST_PLAYABLE.md).

## Предлагаемый порядок полноценной игры после U4
| Этап | Результат | Шлюз |
|---|---|---|
| G0 — Product/Architecture | GDD, принятый движок, C++ контракты, стандарты качества | Утверждены проектные решения |
| G1 — Engineering | Сборка, автоматические тесты, ввод, базовые SaveGame, модульные границы | Собирается и запускается Windows Player |
| G2 — Core loop | Управление, бой, предмет, инвентарь, смерть и продолжение | Игровой цикл без ручной подмены функций |
| G3 — World foundation | Seed, небольшой регион, стриминг, delta-сохранения | Повторяемый мир и сохранённые изменения |
| G4 — Character foundation | Первый принятый герой, риг, экипировка, минимальный редактор | Игровая камера + движущаяся модель + сохранение внешности |
| G5 — NPC simulation | Расписания, память, базовая мотивация, события вдали | Наблюдаемые последствия, стабильные ID |
| G6 — RPG/economy | Прогрессия, инвентарь, торговля, крафт | Сквозной игровой сценарий |
| G7 — Quests/factions | Задания от состояния мира, фракции и последствия | Сохранение и воспроизведение результатов |
| G8 — Vertical slice | Один качественный регион с целостным циклом, NPC, боем, UI/артом | Принят владельцем в реальной Windows-сборке |
| G9 — World/biome content | Новые регионы, растительность, материалы, вода | Визуальное ревью и профилирование |
| G10 — Character/creature content | Остальные расы, враги, анимации, экипировка | Визуальная/техническая приёмка партиями |
| G11 — Narrative/content | Поселения, данжи, события и Фильдор как NPC первого релиза | Интегрированные игровые сценарии |
| G12 — Presentation/optimization | UI, VFX, звук, настройки, оптимизация | Целевой профиль качества после измерений |
| G13 — Game Alpha | Полный объём функциональности первого выпуска | End-to-end тесты, отчёты и регрессии |
| G14 — Game Beta | Баланс, баги, производительность, UX | Приёмка функциональных и визуальных критериев |
| G15 — Release Candidate | Стабильный одиночный Windows-релиз | Решение владельца |

**Принцип:** до G8 — небольшой ограниченный объём оригинального контента, после G8 — расширение. Каталог девяти биомов / 41 микробиома утверждён как направление, но состав первого релиза остаётся `UNDECIDED`. Заморская кампания, сезоны и мультиплеер — будущие этапы. Ни одна стадия не становится `ACCEPTED` по результату автоматического теста.
