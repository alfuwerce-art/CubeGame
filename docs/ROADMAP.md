# CubeGame — Roadmap
Этап открывается и принимается владельцем. `Кандидат` не означает `ACCEPTED`.

| Этап | Результат | Подтверждённое состояние |
|---|---|---|
| G0 | Собственная концепция и документация | Направление утверждено |
| G1 | Техническая основа, компиляция, сборка, сохранения, тесты | Кандидат в GitHub, приёмка не подтверждена |
| G2 | Процедурный мир, регионы, стриминг и сохранение изменений | Кандидаты в GitHub, приёмка не подтверждена |
| G3 | Первый качественный игровой персонаж, редактор, расовые варианты | План |
| G4 | Контактный бой, управление, реакции | План |
| G5 | Живой мир и NPC | План |
| G6 | Прогрессия, предметы, экономика | План |
| G7 | Связанный игровой прототип | План |
| G8 | Законченный вертикальный срез | План |
| G9 | Авторские мир и визуальный контент | План |
| G10 | Игровые персонажи, существа и анимации | План |
| G11 | Места, события, квесты, Фильдор как NPC первого выпуска | План |
| G12 | UI/UX, звук, VFX, настройки | План |
| G13 | Внутренняя Game Alpha | План |
| G14 | Game Beta, оптимизация и баланс | План |
| G15 | Первый публичный одиночный релиз | План |

Детальная реализация может выполняться независимо в узких проверяемых задачах, если зависимости понятны; приёмка этапа требует интеграции в игру. Утверждённый расширенный каталог девяти биомов и 41 микробиома — направление дальнейшего контента, не автоматическое обязательство G15. Крупная заморская кампания, сезоны, мультиплеер, пользовательские серверы — последующие вехи. Содержание: [GDD](GDD.md), [решения](design/DECISIONS.md).
