## 1. Цель и определение «готово» для M0

**Один** локальный Unity-проект (`D:\Projects\CubeGame`, Unity 6000.3.27f2), который запускается одной кнопкой и
даёт одиночную игру, повторяющую согласованный функционал Alpha 2013: создать мир и героя → путешествовать по
генерируемому миру → встречать существ и NPC → сражаться, получать опыт и предметы → торговать/взаимодействовать →
заходить в данжи и выполнять задания → сохраниться, выйти и продолжить. Мультиплеер — вне M0. Plasma/исполняемый
файл Alpha не переносится: поведение воспроизводится собственным кодом C#; ассеты Alpha — локальные
исследовательские материалы (D54), в Git не публикуются.

**M0 закрыт**, когда сквозные golden-сценарии §6 проходят в одной сборке, матрица покрытия §3 не содержит
непомеченных `UNKNOWN`, а продюсер лично принял результат. Агенты `ACCEPTED` не выдают.

## 4. M0-00C — архитектура интеграции и правила совместимости

1. **Модульный монолит (ADR-0001):** `Core` (правила, без Unity-типов) → `Application/Features` (сценарии: мир,
   герой, бой, NPC, предметы, задания) → `Presentation` (MonoBehaviour, модели, анимации, UI). Игровое состояние
   принадлежит Core/Features; аниматор и HUD его только отображают.
2. **Команды и события:** ввод → команда (`MoveCommand`, `AttackCommand`, `InteractCommand`…) → Feature меняет
   состояние → доменное событие (`CreatureSpawned`, `ActionStarted(kind, actionId)`, `HitResolved`, `ItemPicked`,
   `QuestProgressed`) → Presentation. Анимация действия запускается **только** событием `ActionStarted` от правил.
3. **Логические ID и время:** `WorldId`, `RegionId`, `EntityId` (стабильный, из seed + индекса спавна), игровые часы
   Core; Unity-время только в Presentation.
4. **Контракт S05 в игре:** `AlphaEntityContract` (`cubegame.entity_contract/1`) остаётся единственным источником
   «что сущность может»: `controllerMode` `ACTIONS / LOCOMOTION_ONLY / STATIC_OBJECT`, допустимые клипы по
   происхождению. Реестр статусов на сущность: `ANIMATION_AVAILABLE` (есть клип), `BEHAVIOR_VERIFIED` (запуск
   доказан кодом/живьём), `GAMEPLAY_ENABLED` (включено правилом M0), `NOT_APPLICABLE`, `UNKNOWN`. Клип без
   `GAMEPLAY_ENABLED` в игре не проигрывается; библиотеку не удалять.
5. **Сохранения:** `SaveFormat.CurrentVersion` растёт с каждым изменением схемы; для каждой версии — миграция
   `vN→vN+1` и тест «старый сейв грузится». Мир = seed + версия генератора + дельты изменённых чанков; неизменённое
   генерируется заново. Запись атомарная (временный файл → замена), проверка FNV-1a64 сохраняется.
6. **Данные Alpha:** импорт из локальной `D:\Games\Cube world` (только чтение) в `.scratch`/локальный кэш
   при первом запуске редактора; в Git — только код и числовые доказательства.
