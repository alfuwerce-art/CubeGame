# Конвейер переноса анимаций Cube World Alpha → Unity (ТЗ)

**Основание:** [D53](../../decisions/D53-original-animation-extraction-priority.md), [исследование](../research/alpha2013/ANIMATION_EXTRACTION_RESEARCH.md).
**Статус:** `DRAFT` — конвейер описан и частично реализован (тайминги), полный перенос поз `BLOCKED`.
**Границы:** один гуманоид; S05B, массовая конвертация и production-проект не затрагиваются; извлечённые данные Alpha — только локально.

## 1. Цель конвейера

Превратить анимацию Alpha из «ручного угадывания» в воспроизводимый процесс:

```
состояние/способность → длительности фаз (из кода) → позы (из кода или захвата)
→ преобразование в систему Unity → клип → автоматические проверки → визуальное сравнение
```

## 2. Источники данных (в порядке приоритета)

| # | Источник | Что даёт | Статус |
|---|---|---|---|
| S1 | `combat_getAttackWindup` / `combat_getAttackTiming` / `combat_getReloadFrames` | длительности фаз по типу способности, формула `base_ms / (haste × speed)` | **реализовано** |
| S2 | `Creature_drawModel` | матрицы частей и формулы поз | `PARTIAL` — таблица состояний и каналы извлечены байтовым разбором ([ALPHA_POSE_EXTRACTION.md](../research/alpha2013/ALPHA_POSE_EXTRACTION.md)), привязка каналов к частям тела не доказана |
| S2a | `tools/alpha_models/anim/pose_table.py` | 73 состояния, 522 записи каналов, слоты с именами декомпиляции | **реализовано**, воспроизводимо |
| S3 | Захват из живой Alpha (внешнее наблюдение/память) | реальные позы | `PARTIAL` — ввод и съёмка 57 FPS работают, позы не восстановлены (позиции частей в кадре почти не смещаются) |
| S4 | `Attribute_deserialize_*_keyframes` | keyframes атрибутов (не поз) | `PARTIAL` |

## 3. Формат данных, извлечённых из S1

```json
{
  "abilityType": 3,
  "phases": { "windupMs": 100, "contactMs": 100, "recoveryMs": 100 },
  "scalers": { "haste": 1.0, "speed": 1.0 },
  "source": "combat_getAttackWindup@0x0043caa0, combat_getReloadFrames@0x00447310",
  "status": "RECONSTRUCTED_FROM_EVIDENCE"
}
```

Правила: `frames = base_ms / (haste × speed)`; при неизвестном типе способности использовать консервативные 100 мс и помечать `PARTIAL`.

## 4. Преобразование в Unity

1. `AttackPhases` (секунды) → таймлайн клипа: `windup = 0.25·T`, `strike = 0.45·T`, `contact`, `recovery` — по долям из S1.
2. Позы: если источник S2/S3 даёт углы/матрицы — перевести в `localRotation`/`localPosition` узлов; иначе клип помечается `ORIGINAL_NOT_ALPHA`.
3. Кисти: правая на `primaryGrip`, левая решается на `secondaryGrip` в world-space (реализовано в S05A-2 GRIP).
4. Клинок: проверять траекторию острия и отсутствие пересечения с головой/торсом на каждом сэмпле.

### 4.1 Контракт адаптера позы (S05A2-D58)

Адаптер (`CharacterPilotPoseAdapter` в изолированном пилоте) принимает позу **в одной из трёх форм** и не требует, чтобы источник знал про базис Unity:

| Форма | Данные | Когда используется |
|---|---|---|
| матрицы частей | 4×4 на часть в пространстве персонажа | источник отдаёт мировые/иерархические матрицы (кости Alpha) |
| локальные TRS | `localPosition` + `localRotation` (+ `localScale`) | источник уже в иерархии Unity; проверяется как эталон |
| процедурные функции | `t → TRS` на часть | собственные/технические клипы, тестовые данные |

Правила, которые адаптер обязан соблюдать:

1. **Перевод базиса — на границе, один раз.** Alpha собирает `T·Rz·Ry·Rx·S`; Unity использует порядок ZXY. Поэтому матрица собирается в порядке Alpha и умножается на замену базиса (`(x, y, z)_alpha → (x, z, y)_unity`, det = −1), а не переводится в `Quaternion.Euler` «похожими» углами.
2. **Проверки вместо тишины:** нечисловые значения (NaN/∞), вырожденный родитель (необратимая матрица), скачок больше порога — это именованные проблемы, а не молчаливый пропуск.
3. **Провенанс обязателен.** Каждая поза несёт метку (`TRANSFERRED_FROM_ALPHA` / `PARTIAL_BINDING` / `RECONSTRUCTED_FROM_EVIDENCE` / `TEST_DATA_NOT_ALPHA` / `ORIGINAL_NOT_ALPHA`); тестовые данные не могут быть помечены как Alpha-данные, и адаптер отказывает в такой метке.
4. **Не владеет чужими узлами:** адаптер пишет только в переданный набор частей.

Текущее состояние источника S2: числа извлечены (`PARTIAL`), привязка канала к части тела не доказана, поэтому клипы на этих числах помечаются `PARTIAL_BINDING`, а не `TRANSFERRED_FROM_ALPHA`.

## 5. Обязательные проверки каждого клипа

| Проверка | Требование |
|---|---|
| Контакт кистей | отклонение ≤ 0.02 на каждом сэмпле двухфазного удержания |
| Динамические коллизии | границы головы/торса пересчитываются каждый сэмпл; любое пересечение = FAIL |
| Стык цикла | `t = 1−ε → 0` по позиции и повороту (уже поймал два дефекта) |
| Скачки между фазами | шаг ≤ порога; иначе FAIL |
| Крепление оружия | смещение в системе кисти постоянно (drift ≤ 1e-3) |
| Фронтальная зона удара | замах проходит через область перед персонажем (проверка сектора) |
| PlayMode | отдельный режим именно с этим клипом, ≥ 40 кадров, exit 0 |

## 6. Статусы клипов

| Статус | Когда ставится |
|---|---|
| `TRANSFERRED_FROM_ALPHA` | позы и тайминги получены из данных Alpha (S2/S3) и проверены сравнением кадров |
| `RECONSTRUCTED_FROM_EVIDENCE` | тайминги/структура из кода Alpha, позы — авторские |
| `ORIGINAL_NOT_ALPHA` | полностью собственный клип |
| `BLOCKED` | данных нет или доступ закрыт |

## 7. Реестр анимаций (текущий гуманоид)

| Клип | Статус | Примечание |
|---|---|---|
| `technical_walk_NOT_ALPHA` | `ORIGINAL_NOT_ALPHA` | принят в S05A-1 как технический |
| `two_handed_attack` | `RECONSTRUCTED_FROM_EVIDENCE` (тайминг) + `ORIGINAL_NOT_ALPHA` (позы) | тайминги из `combat_get*` |
| idle/дыхание | `BLOCKED` | нет поз |
| одноручные удары | `BLOCKED` до S2/S3 | тайминги уже есть |
| прыжок/урон/смерть | `BLOCKED` | нет ни таймингов, ни поз |

## 8. Порядок работы партии

1. Выбрать клип и тип способности, выписать тайминги (S1).
2. Попытаться получить позы (S2 → S3).
3. Собрать клип, пометить статус.
4. Прогнать автоматические проверки (§5) и PlayMode именно с этим клипом.
5. Снять кадры ключевых фаз и сравнить с Alpha (если есть кадры).
6. Отчёт партии + обновление реестра; только затем следующая партия.

## 9. Ограничения

* Извлечённые кривые/матрицы/кадры не публикуются и не входят в релиз без прав.
* Риг Alpha не восстановлен; скиннинг (`MaterialBone`) на нашей плоской иерархии не воспроизводится.
* Живой захват требует решения проблемы фокуса окна (см. §4 исследования).
