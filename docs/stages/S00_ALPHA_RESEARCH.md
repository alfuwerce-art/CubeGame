# S00 v2 — исследование Cube World Alpha 2013 и Steam 2019

Проект: CubeGame (рабочее название).
Статус: SPEC_PREPARED — исследование на ПК ещё не выполнено.
Основание: D37, D01–D36. Исполнитель: локальный ИИ-агент.
Alpha 2013 отсутствует локально, её установка не требуется. Для прямой проверки нужна официальная Steam-версия 2019.

## Цель

Подготовить раздельные технические каталоги Alpha 2013 (архивные источники) и Steam 2019 (непосредственные наблюдения на ПК), затем утвердить целевые механики CubeGame и определить тесты для последующей реализации Unity. Не переносить особенности Steam-версии автоматически.

## Вход

Продюсер устанавливает Cube World 2019 из Steam: https://store.steampowered.com/app/1128000/Cube_World/
Агент фиксирует реальный запуск, номер сборки (если доступен), Steam AppID 1128000, ОС, SHA-256 исполняемого файла; локальные оригинальные файлы и игровые ресурсы не публикуются в GitHub. Если игры пока нет, архивное исследование Alpha не блокируется.

## S00-A — архивная Alpha (задачи)

A01: запуск, создание героя, интерфейс, настройки, управление, камера.
A02: мир, seed, карта, регионы, биомы, города и локации.
A03: классы, специализации, XP, уровни, Power, навыки.
A04: базовая боевая система, MP, уклонения, оружие, враги, боссы.
A05: инвентарь, крафт, рецепты, кастомизация оружия, Spirit Cubes.
A06: питомцы, плавание, скалолазание, лодка, дельтаплан.
A07: NPC, задания, подземелья, награды, торговля.
A08: сохранения, смерть, мультиплеер (только исследовать).
Для каждого утверждения: версия, URL/таймкод, дата источника, наблюдаемое правило, степень подтверждения: DOCUMENTED / PARTIAL / UNKNOWN / CONFLICT. Без запуска Alpha НЕ писать DIRECTLY_VERIFIED_ALPHA.

## S00-B — прямое исследование Steam 2019

B01: запуск и настройки; меню/управление/персонаж.
B02: генерация/карта, биомы, регионы, города/NPC.
B03: бой, классы, оружие, враги, питомцы и смерть.
B04: предметы, инвентарь, региональная привязка, крафт.
B05: артефакты, задания, данжи, боссы и награды.
B06: сохранение/загрузка, выход, возврат и воспроизводимые сценарии.
B07: структура ассетов, модели и возможность анализа анимаций; не обещать перенос из Alpha, пока не проверено.
B08: документировать сетевые возможности; сервер сейчас не создавать.
Указывать последовательность ввода, начальное состояние, результат, запись/скриншот, версию, ограничения. Не изученные функции оставлять UNKNOWN.

## S00-C — проектное сравнение

Сводная матрица: feature_id / источник Alpha / прямое наблюдение 2019 / целевое правило CubeGame / решение продюсера / тест Unity. Статусы APPROVED_EXISTING, APPROVED_NEW, PROPOSED, REJECTED, DEFERRED. Неутверждённое не реализовывать.

Предварительные кандидаты: XP и уровни; очки навыков; классы/специализации; экипировка без регионального обесценивания; питомцы; развитие передвижения; крафт и кастомизация; боевые основы; данжи и боссы; артефакты 2019 как дополнение. Это не автоматически утверждённые решения.

## Gate закрытия

Подтверждённые сведения Alpha отделены от 2019, есть локальные прямые тесты Steam-игры, каталог ошибок и неизвестного, матрица решений продюсера и будущих тестов Unity. Агент выставляет READY_FOR_REVIEW; архитектор и продюсер принимают S00 отдельно. Не ждать локальной Alpha, но критические неопределённости должны быть явно видны.
