# S00 v3 — прямое исследование Cube World Alpha 2013

**Проект:** CubeGame (рабочее имя, название игры не выбрано).  
**Статус:** `SPEC_PREPARED / SOURCE_PATH_REPORTED / DIRECT_VERIFICATION_PENDING`.  
**Основание:** [D38](../decisions/D38-alpha-client-available.md), D01–D36, ADR-0001.  
**Локальный кандидат:** `D:\Games\Cube world` (сообщён продюсером; существование папки/версия/запуск ещё не проверены).
**Роли:** продюсер — выбор механик; ChatGPT — архитектура/ревью; локальный агент — непосредственное исследование.

## 0. Задача и пределы

Технически описать реальную Alpha 2013 с воспроизводимыми сценариями для последующей реализации CubeGame на Unity. Утверждённая цель базовой версии — максимальная близость к Alpha, за исключением отложенного мультиплеера.

- **Основной источник:** реально запущенная и проверенная Alpha 2013.
- **Вторичные источники:** датированные видео, руководства и технические исследования; не заменяют наблюдение там, где клиент доступен.
- **2019:** необязательная отдельная дорожка, не обязательна для S00 и не доказывает поведение Alpha.
- **Не делать:** Unity-код, модификации игры, извлечение и публикацию закрытых бинарных ассетов, платный хостинг/серверы, апгрейд моделей, выдуманные исправления механик.
- Не объявлять собственный игровой тест успешным без лога фактической проверки.

## 1. S00-G0 — проверка источника (ОБЯЗАТЕЛЬНО ПЕРВОЙ)

1. Проверить существование `D:\Games\Cube world` и сделать **неразрушающую** инвентаризацию (список EXE, DLL, архивов, ресурсов, конфигов и папок).
2. Для EXE/DLL записать размер, SHA-256, метаданные версии/подписи, если доступны. Название папки не является доказательством сборки 2013 года.
3. Проверить источник файлов и результат локальной антивирусной проверки, если происхождение архива неизвестно. Не запускать неизвестные установщики, активаторы, патчеры, PowerShell-скрипты. Не изменять антивирус, систему или права доступа.
4. Только после приемлемой проверки безопасности запустить именно игру, убедиться в реальном меню/создании героя/мира, сохранении/перезапуске; записать фактическую конфигурацию.
5. Сохранить все доказательства локально вне исходной папки; не публиковать оригинальные EXE и ассеты на GitHub. Не подменять оригинальную Alpha модами.
6. Результат: `docs/research/alpha2013/ENVIRONMENT.md` и `S00_G0_REPORT.md`, статус `G0_PASS`, `G0_BLOCKED` или `G0_NEEDS_REVIEW`, плюс список обнаруженных файлов и шагов проверки.

**Пока G0 не прошёл, не присваивать статус `ALPHA_DIRECT_VERIFIED` каким-либо механикам.**

## 2. S00-01…S00-12 — игровые исследования

| ID | Область | Наблюдения и доказательства |
|---|---|---|
| S00-01 | Запуск, настройки, меню, камера, управление и UI | Доступные экраны/опции, действия, шаги и снимки |
| S00-02 | Расы, создание героя, классы и специализации | Начальные предметы, оружие, параметры, отличия |
| S00-03 | Генерация мира, seed, регионы, биомы, города, время | Повторение seed, карта, локации, объекты |
| S00-04 | Движение и навыки перемещения | Бег, плавание, скалолазание, лодка, дельтаплан, питомцы |
| S00-05 | XP, уровни, Power, дерево навыков | Проверенные изменения характеристик и правила прокачки |
| S00-06 | Бой, способности, ресурсы, враги и смерть | Последовательность атак, уклонения, AI, состояние после боя |
| S00-07 | Лут, торговля, предметы, инвентарь и крафт | Инвентарные переходы, ингредиенты, рецепты, оружие |
| S00-08 | Города, NPC, питомцы, взаимодействия | Типы NPC, профессии, функции, поведение |
| S00-09 | Квесты, данжи, замки и реальные боссы | Начало задания, прохождение, награды и повторение |
| S00-10 | Сохранения, разные миры, смерть/возрождение | Матрица что сохраняется после выхода/загрузки |
| S00-11 | Оригинальные сетевые возможности | Только описание, не разворачивать сервер |
| S00-12 | Итоговая матрица Alpha → CubeGame | Доказательства, исключения, неизвестные, тесты Unity |

Для технической части анимаций/моделей: дополнительно описывать доступные игровые форматы и предполагаемую возможность переноса, **не** утверждая совместимость с Blender/Unity до теста S05A.

## 3. Формат каждого результата

`feature_id | alpha_build | input/seed/initial_state | action | observed_result | evidence_id | evidence_type | confidence | Unity_test_case | game_design_status`.

- `evidence_type`: `ALPHA_DIRECT`, `ALPHA_2013_VIDEO`, `ALPHA_2013_DOCUMENT`, `RETROSPECTIVE`, `RECONSTRUCTION`, `STEAM_2019_ONLY`.
- `confidence`: `VERIFIED` (проверено прямо в клиенте), `PARTIAL`, `UNKNOWN`, `CONFLICT`, `BLOCKED`.
- `game_design_status`: `APPROVED_Dxx`, `PROPOSED`, `REJECTED`, `DEFERRED`.
- Все игровые числовые формулы подтверждать тестами или отмечать гипотезой. Не смешивать правила 2013 и 2019.
- Не считать оригинальные отличия Alpha автоматически ошибками, требующими исправления.

## 4. Отчёты и артефакты

После проверки G0, затем по пакетам, агент создаёт в `docs/research/alpha2013/`:
- `ENVIRONMENT.md` — среда/версия/источник;
- `S00_G0_REPORT.md` — исходная проверка;
- `FEATURE_MATRIX.md` — проверенное поведение;
- `SYSTEM_CATALOG.md` — описание механик;
- `TEST_SCENARIOS.md` — воспроизводимые кейсы;
- `OPEN_QUESTIONS.md` — незавершённые исследования;
- `S00_REPORT.md` — итог, ограничения и предложения.

Оригинальные бинарники и полные копии платной игры **не коммитить** в публичный GitHub. Для доказательств: собственные заметки, короткие допустимые снимки/видеофрагменты и ссылки на локальные материалы без приватных данных.

## 5. Приёмка

S00 закрывается только после G0 PASS, подтверждённого покрытия основных игровых циклов, матрицы известных/неизвестных механик, источников и сценариев будущего тестирования Unity, проверки архитектора и утверждения продюсера. Если отдельные системы нельзя исследовать, статус и последствия фиксируются, а продюсер решает, блокирует ли это переход.

Агент возвращает `READY_FOR_REVIEW` с коммитом/списком фактов; не ставит сам `ACCEPTED`.
