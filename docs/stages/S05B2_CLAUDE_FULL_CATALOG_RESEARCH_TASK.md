**Исполнитель:** Claude Code (исследователь, архитектор и разработчик решений), **не** DeepSeek.
**Каталог работы:** `D:\Projects\CubeGame`, технический оригинал `D:\Games\Cube world` read-only.
**Исходная ветка:** `review/d64-claude-full-research-handoff` — включает опубликованный DeepSeek `stage/s05b2-deepseek-batch` @ `f8628cc6` и нормативную цель D63. Создать свою `claude/s05b2-full-catalog-research`.
**Ограничение:** DeepSeek приостановлен, не выполнять параллельную работу в одном локальном каталоге.

## Миссия

**Создать действующий универсальный производственный способ, по которому DeepSeek сможет перенести абсолютно все доступные модели, сущности, предметы, экипировку и все существующие анимации Cube World Alpha в локальную Unity.** Не «ещё один образец», не «описание возможного метода», не «пять блокеров в отчёте». Исследование должно завершаться работающим кодом, устраняющим выявленные проблемы. Охват должен включать весь исходный каталог, в том числе ещё не обнаруженные цепочки ресурсов и анимаций.

Используй ранее доказанную основу: декомпиляция/эмуляция оригинального кода, `x86emu`, `alpha_static`, `creature_rig`, `drawModel`, `ai_trigger`, `voxel_markers`, `transfer_planner`, `batch_runner`, `action_baker`, C# Unity Runtime/Editor. **Если оригинальную анимацию нельзя посмотреть прямо в игре, вычисляй её по коду/состояниям/матрицам**, как уже получилось на humanoid/NPC, без обязательного поиска каждого существа в мире. Для других систем исследуй их реальные форматы и алгоритмы; не предполагай, что всё — `Creature_drawModel`.

## Исследовательская программа — без искусственного сокращения

1. **Полный каталог ассетов** `data1–4.db` и иных игровых источников: все доступные `.cub`, индексы, ссылки, версии/варианты; существа, NPC, боссы, животные; персонажи и создание внешности; оружие, броня, инвентарь, предметы, интерактивные пропсы; окружение и статичные модели. Найти отдельные пути загрузки, если не используют реестр `creature`.
2. **Геометрия и визуальные свойства:** все сетки, частичные модели, scale/mirror/coordinate transforms, модели аксессуаров и attachments, прозрачность/цветовые маркеры/tint, материал, порядок рисования; на неподдержанных форматах и индексах исправлять код/реестр/конвертер.
3. **Полный каталог анимационных систем:** локомоция/idle, атаки разных видов, оружие, навыки, магия, урон, блок, уклонение, прыжок, смерть, взаимодействие, поведение NPC, движения объектов/окружения — всё, что действительно существует в коде или данных Alpha. Для каждого определить управляющие источники, состояние, входные параметры, action triggers, временную функцию, части/матрицы, переходы, влияние экипировки; доказать фактическую применимость действия к виду/предмету.
4. **Триггеры без живого NPC:** исследовать AI/Server.exe/Cube.exe и способы исполнять код с реконструированным валидным состоянием. Отвязать получение доказанных действий от обязательного live capture. Если функция требует контекст, обеспечить подходящий декодер/эмулятор, а не объявлять все новые семейства бездействующими.
5. **Исключения и дефекты:** B-1/B-2/B-3/B-4 из [отчёта DeepSeek](../reports/S05B2_DEEPSEEK_BATCH_REPORT.md) — начальная очередь, **не лимит работы**. Каждый подтверждённый дефект исправлять в коде и затем проверять узким воспроизводимым случаем.
6. **Единое управление импортом:** `scan/plan/convert/animate/import` или совместимый интерфейс текущего планировщика для всех категорий; правильные `NOT_APPLICABLE` для статичных моделей; независимые status для GEOMETRY, VISUAL, RIG, EQUIPMENT, ANIMATION, TRIGGER, UNITY; metadata provenance, SHA256/cache/resume. Все категории должны иметь предусмотренный путь обработки, даже если отдельные экземпляры временно остаются `BLOCKED` с конкретным доказанным основанием.
7. **Передача DeepSeek:** готовый реализованный конвейер, в котором задача «весь каталог» запускается без отдельного исследования каждого creature и без ручной настройки десятков видов; документация запусков и восстановления после отказов, полный список реально нерешённого.

## Правила качества и эффективности

- **Никаких лишних тестов:** не создавать массовые дублирующие проверки «ради галочки», многочасовые регрессии без причин и ручные шлюзы просмотра после каждого вида. Минимальные точечные проверки новых механизмов и одна проверка сквозного Unity-результата на принципиально разные пути, плюс необходимая защита существующих исправлений D61. Не выдавать отсутствие тестов за доказательство.
- **Не ограничиваться уже исследованными семействами.** Не называть `AUTO_READY` готовым Unity-переносом. Цель — способ для всех ресурсов, включая нестандартных существ, предметы и объекты мира.
- **Не придумывать анимации.** Если в Alpha конкретного действия нет, пометить `NOT_APPLICABLE`; если оно существует, но пока не восстановлено, пометить `BLOCKED` и продолжать исследование/исправление, а не отбрасывать.
- Живые захваты необязательны, если код/формула дают воспроизводимый вывод; честно сохранять `EMULATED_ALPHA_CODE`, `RECONSTRUCTED_FROM_EVIDENCE`, `live_check=NOT_CAPTURED`; `TRANSFERRED_FROM_ALPHA` только для реального capture.
- Прототип/исследование — только локально, не распространять оригинальные или конвертированные файлы Alpha. Не изменять систему игрового S04/сохранений, `main`, чужие ветки.
- Если объективно недостаёт исходных байтов/прав или формат физически отсутствует, не изображать успешность: указать точный предел и альтернативные пути; не считать это разрешением самовольно сокращать утверждённый объём.

## Готовый результат

- Реестр ассетов: `TOTAL_SOURCE`, `DISCOVERED`, `SUPPORTED_METHOD`, `NEEDS_RESEARCH`, `BLOCKED`, `NOT_APPLICABLE`, отдельно creature/non-creature, уникальные models, kinds/variants.
- Реестр анимаций: реально существующие действия по всем системам, описание code path / trigger / pose, family, equipment и путь переноса (с источником доказательств).
- Реализованный код/адаптеры/контракты с устранёнными B-1..B-4 и всеми обнаруженными дефектами, где источник позволяет исправление.
- Небольшие репрезентативные Unity-прогоны **различных механизмов** (не сотни одинаковых проверок) для демонстрации, что инструменты действительно работают.
- `docs/reports/S05B2_CLAUDE_FULL_RESEARCH_REPORT.md`: что реализовано, что доказано, на что распространяется, нерешённое, команды DeepSeek для полного массового прогона, базовый commit, Python/Unity результаты именно проведённых тестов.
- Публикация только безопасного кода/метаданных/документации в `claude/s05b2-full-catalog-research`, `git status` чист и точный SHA. Результат `READY_FOR_REVIEW`, **не** `ACCEPTED`. DeepSeek возобновит большой пакет **после проверки и утверждения продюсером**.

**Не останавливаться после расследования первоначальных 4 блокеров. Цель — универсальный механизм для всего каталога Alpha, включая всё, что пока даже не учтено в 156 creature kinds.**
