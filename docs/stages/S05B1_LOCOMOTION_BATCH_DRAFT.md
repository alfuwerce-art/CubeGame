# S05B-1 — пакетный перенос геометрии и ходьбы/покоя для семейств с живым захватом (ЧЕРНОВИК)

Не является разрешением: до отдельного решения продюсера `S05B — NOT_AUTHORIZED`, `transfer_planner batch` отказывает, `BATCH_AUTHORIZATIONS` пуст.

## 1. Цель

Первый ограниченный пакет: проверить, что конвейер **без ручной работы над каждым существом** переносит в изолированный Unity-пилот геометрию, риг, ходьбу и покой для всех видов, у семейства которых уже есть **живой захват Alpha**. В каждом прогоне сверять результат с этим захватом. Это проверка пакетного механизма на самом надёжном подмножестве, а не производство игровых ассетов.

## 2. Состав (15 видов, 3 семейства)

Выбраны все виды, у которых в матрице ходьба = `TRANSFERRED_FROM_ALPHA+RECONSTRUCTED_FROM_EVIDENCE`. Других критериев отбора нет.

| Семейство | Категория / части | Виды | Уже в пилоте S05A-2 | Новые |
|---|---|---|---|---|
| `e66d96be5a` | BIPED_WITH_FORE_LIMBS, 7 | ElfMale 0x00, ElfFemale 0x01, HumanMale 0x02, HumanFemale 0x03, LizardmanMale 0x07, LizardmanFemale 0x08, FrogmanMale 0x0d, FrogmanFemale 0x0e | 0x02 | 7 |
| `ced63e5e96` | QUADRUPED, 7 | Cat 0x1e, BrownCat 0x1f, WhiteCat 0x20 | 0x1e, 0x20 | 1 |
| `51aeec9280` | LEGS_ONLY, 3 | PlainRunner 0x3f, LeafRunner 0x40, SnowRunner 0x41, DesertRunner 0x42 | 0x3f | 3 |

Живые захваты-эталоны (локально, `.scratch`): `s05a2/cap/session2.jsonl` (человек 0x02), `universal/cap/batch1.jsonl` (WhiteCat 0x20, PlainRunner 0x3f). Захват ищется по имени и SHA256 из клипа семейства — подмена файла даёт отказ.

**Варианты моделей** (вопрос В2). У котов и бегунов по одному варианту. У видов человеческого семейства от 4 до 15 вариантов головы/волос на слот:

| Вариант охвата | Прогонов Unity | Что доказывает |
|---|---|---|
| A. только seed (0, 0) | 15 | механизм пакета на каждом виде |
| **B. каждая модель вида хотя бы раз** (рекомендуется) | ≈ 70 (наибольшее число вариантов слота на вид, суммарно) | все головы/волосы этих видов импортируются и проходят геометрию |
| C. все сочетания seed | до 454 | избыточно: позы от модели не зависят (проверено), только время |

## 3. Что входит

1. Модели всех частей вида → Unity Mesh, проверка `GEOMETRY` (вершины = ожидание), якоря, зеркалирование.
2. Риг и `contract.json`; `ENTITY_CONTRACT_RESULT=PASS`.
3. Ходьба: клип семейства (`TRANSFERRED_FROM_ALPHA`, с пометкой вида-источника, если вид-получатель не снимался) и формула (`RECONSTRUCTED_FROM_EVIDENCE`); сверка формулы с живыми кадрами семейства (`PARAMWALK` ALPHA ≤ 1e-3 вокселя / 0.01°).
4. Покой: захваченная стойка (человеческое семейство) или формула при амплитуде 0.
5. Контроллер в режиме `LOCOMOTION_ONLY` для всех видов, **включая HumanMale** (в пакете без библиотеки действий: `ACTION_LIBRARY_NOT_IMPORTED`). PlayMode: ходьба → остановка → покой → отказ действий → ходьба, при 60 Гц; выборочно 30/120 Гц (по одному виду на семейство).
6. Реальные кадры Unity и контактный лист на каждое семейство для художественного просмотра продюсером.

## 4. Что НЕ входит

* Любые действия/атаки, в том числе для 7 видов человеческого семейства с совместимыми позами (`POSES_FAMILY_COMPATIBLE_TRIGGER_UNPROVEN`) — запуск не доказан.
* Оружие и экипировка (слой оружия остаётся у S05A-2 гуманоида).
* Виды «только формула» (136), `NEEDS_RESEARCH` (3), `BLOCKED` (2) — это S05B-2 и далее.
* Новые запуски Alpha и новые захваты.
* Интеграция в основной проект Unity / S04, production-ассеты, публикация моделей, клипов, кадров и матриц Alpha (D54). В Git — только код, задания без данных Alpha, отчёт и матрица статусов.
* Изменения формулы ходьбы, клипов S05A-2 и хвата меча.

Политика ошибок: FAIL одного вида не останавливает пакет, но итог пакета — FAIL, пока каждый вид не PASS или не переведён продюсером в исключение. Пороги не ослабляются.

## 6. Оценка ресурсов

* Unity: ≈ 3 мин на вид без действий при прогретом проекте (по пилоту), то есть ≈ 45 мин для варианта A и ≈ 3.5 ч для варианта B; плюс выборочные 30/120 Гц.
* Диск: ≈ 20 МБ на проект без тяжёлых листов; кадры ≈ 15–40 на прогон.
* Платные инструменты/сервисы не нужны.

## 7. Критерии приёмки (предлагаемые)

1. Для каждого (вид, seed) области: `RESULT=PASS` с кодом выхода 0 всех шагов (`SELFTEST`, `TRANSFER`, `PLAYMODE`, `PARAMWALK`, `LOCOMOTION_PLAYMODE`, `ENTITY_CONTRACT`, `ENTITY_PLAYMODE`) в свежей сессии.
2. `PARAMWALK` сверяет формулу с живыми кадрами своего семейства (ненулевое число кадров), без ослабления порогов.
3. Ни одного action-клипа в импортированных данных; у всех видов `LOCOMOTION_ONLY` с причиной.
4. Регрессия: Python все тесты OK; ручное задание S05A-2 `human_0x02_lifecycle.json` — PASS с прежними числами (98 действий, кадры 30/60/120 Гц).
5. Отчёт с матрицей, логами и контактными листами; в Git нет данных Alpha.
6. Художественный просмотр контактных листов — продюсером (технический PASS ≠ визуальное одобрение).

## 8. Риски

| Риск | Мера |
|---|---|

| Видовые различия, не попавшие в подпись семейства | подпись консервативна (любое различие параметров разделяет семейства); сверка с живыми кадрами семейства на каждом виде |
| Ложное ощущение «готового production» | статус результата — исследовательский пилот D54; перед релизом — собственные/лицензированные ассеты |
| Unity-проект открыт продюсером | раннер отказывает при блокировке проекта; пакет использует отдельный проект |
