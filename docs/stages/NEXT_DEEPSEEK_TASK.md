# CubeGame — следующее задание DeepSeek

**Решение D40** разрешает исследование Alpha и первый Unity-пилот параллельно. **Unity Hub/Editor и Blender отсутствуют**, по последнему фактическому отчёту агента.

1. Запусти НОВУЮ сессию `cubegame-dev` с `workspace-write / ask`, не используй `danger-full-access / never`.
2. Прочитай `AGENTS.md`, `docs/ACTIVE_STAGE.md`, [D40](../decisions/D40-static-first-unity-pilot.md), [S00-R01](S00_STATIC_R01.md), [S01-PILOT](S01_UNITY_PILOT.md), ADR-0001. Подтяни main, не перетирай `plugins/`. G0-отчёты находятся в ветке `stage/s00-alpha-g0` — сначала прочитай их оттуда.
3. Создай ветку `stage/s00-static-r01`. **Сразу приступай** к статическому анализу локальных Alpha-файлов и CubeWorld-Reversal как исследовательского справочника. Собери собственные описания форматов и генерации, ссылки/сведения, неопределённости, acceptance cases. Оригинал `D:\Games\Cube world` не изменяй.
4. Параллельно проверь Unity. При его отсутствии обозначь `BLOCKED_UNITY_INSTALL` и **попроси продюсера разрешение** установить официальный Unity Hub и Unity 6.3 LTS + URP; сообщи варианты расположения на диске (D: предпочтителен при нехватке C:). Без явного разрешения не скачивай и не устанавливай. Не меняй настройки системы/антивирус.
5. После подтверждённой установки создай отдельную ветку `stage/s01-unity-pilot` от актуального main, перенеси минимум: детерминированный voxel-регион, временный игрок, камера, движение, отладочный HUD, тесты и демонстрация. Код пишешь сам — не копируй декомпилированные C++ тела и чужие ассеты.
6. Blender **не нужен для этого пилота**; его установку и моделирование оставь на S05A. Не запускай графический этап.
7. По R01 и по пилоту отдельные отчёты и коммиты, тесты без выдуманных PASS, статус `READY_FOR_REVIEW`, без слияния в main. После двух неудачных попыток решить один блокер — остановись и отчитайся.

Текущее ограничение: полная история Alpha и точная битовая подлинность локального repack не доказаны. Не утверждай, что всё изучено или игра перенесена.
