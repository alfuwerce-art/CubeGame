## 4. Ограничение среды: TLS через schannel не работает

В этой сессии `git fetch`, `curl.exe` и `Invoke-WebRequest` падают с `schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS (0x8009030e)`, хотя TCP-порт 443 доступен. Инструменты с собственной TLS-реализацией (Python `urllib`, `git` с `http.sslBackend=openssl`) работают.

Следствия для установки:

- скачивание установщиков агентом возможно **только** через Python/OpenSSL (или через git, если бы это был репозиторий);
- если удобнее, продюсер может скачать установщики браузером — тогда агенту останется проверка хеша/подписи и запуск;
- настройки TLS, сертификаты, антивирус и системные параметры **не изменяются**.

## 5. План установки (по шагам, с указанием, кто выполняет)

| # | Шаг | Кто | Требует прав администратора |
|---|---|---|---|
| 1 | Скачать `UnityHubSetup-x64.exe` в `.unity-install\`, записать SHA-256 и версию из свойств файла | агент | нет |
| 2 | Запустить установщик Hub с целевым каталогом `D:\Unity Hub` | **продюсер** (UAC) или агент после явного разрешения на запуск установщика | **да**, UAC |
| 3 | Войти в Unity ID в Hub (Unity Personal / существующая лицензия) | **только продюсер**, пароль агенту не передаётся | нет |
| 4 | Установить Editor 6000.3.27f2 на `D:\Unity\Hub\Editor\6000.3.27f2` — либо через Hub GUI, либо тихой установкой `UnitySetup64-6000.3.27f2.exe /S /D=D:\Unity\Hub\Editor\6000.3.27f2` (тогда Hub нужно указать путь к установке) | продюсер (UAC), либо агент по разрешению | **да** |
| 5 | Проверить установку: `Unity.exe -version`, `-batchmode -quit -logFile`, отсутствие ошибок лицензии | агент | нет |
| 6 | Создать проект в корне репозитория (URP-шаблон), зафиксировать версии Editor и пакетов в отчёте | агент | нет |
| 7 | Реализовать пилот P1 и прогнать кейсы `TC-*` из `GENERATION_MOVEMENT_SPEC.md` §3 | агент | нет |

Шаги 2 и 4 требуют UAC: текущий процесс не администратор, поэтому без подтверждения продюсера установка невозможна.

## 6. Что нужно от продюсера

1. Явное разрешение на **скачивание** Hub (184 МБ) и Editor (3.9 ГБ) из официального CDN Unity.
2. Явное разрешение на **запуск установщиков** и подтверждение UAC (или готовность установить Hub вручную).
3. Уточнение по лицензии: Unity Personal под текущим Unity ID или иной вариант (агент не запрашивает и не хранит пароли).
4. Подтверждение размещения: Hub `D:\Unity Hub`, Editor `D:\Unity\Hub\Editor\6000.3.27f2` (или другой путь на D:).

До получения разрешения статус остаётся `BLOCKED_UNITY_INSTALL`; ветка `stage/s01-unity-pilot` не создаётся, Unity-проект не создаётся, C#-код пилота не пишется.
