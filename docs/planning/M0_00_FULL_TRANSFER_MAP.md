# M0-00 — карта переноса полного игрового функционала Alpha 2013 → Unity

**Статус:** `PREPARATION_PACKAGE / READY_FOR_REVIEW`. Это не ТЗ M0-00D, не приёмка S05B-2 и не
разрешение M0-01+. **Исполнитель:** DeepSeek Harness. **Ветка:**
`deepseek/m0-00-full-systems-preparation`, worktree `D:\Projects\CubeGame-deepseek` (D71).
**Входная база:** `deepseek/m0-00b-p0-mechanics` @ `0b62ccc`; результаты S02–S05 и M0-00B/P0
приняты как входные доказательства, заново не исследовались.

**Проверено в этом пакете:** 462 детерминированные проверки в изолированном стенде
(`M0_PILOTS_RESULT=PASS`), 176 строк матрицы покрытия разобраны в машинный реестр, 24 типа
предметов и 16 способностей сведены в подтверждённые таблицы. Unity Editor и Alpha **не
запускались**.

Обозначения: `DIRECT` — прочитано в коде/данных Alpha; `PARTIAL` — каркас есть, детали нет;
`UNKNOWN` — не восстановлено; `CUBEGAME_CONTRACT` — наше интеграционное решение, не факт Alpha.

## 4. Массовая подготовка (не «по одному предмету/NPC»)

1. **Подтверждённые таблицы → C#** (`tools/m0_transfer/gen_alpha_tables.py`): 24 типа предметов,
   20 подтипов оружия, 16 способностей, 11 имён регионов, 5 фракций; SHA-256 данных в
   сгенерированном файле. Изменение значения требует изменения JSON с цитатой.
2. **Матрица → реестр** (`build_transfer_registry.py`): 176 строк, домены, confidence, статус,
   M0-подэтап; `--check` запрещает устаревший реестр.
3. **Пилотный стенд** (`tools/m0_pilots/run_pilots.ps1`): компилирует реальный Core и 462
   проверки; не требует Unity Editor.
4. **Следующие автоматизируемые выгрузки (не сделаны):** таблица климат→объекты W-18, лут-таблицы
   `I-12`, `mission` 38 Б, `reg/tile/land`, цены торговли. До выгрузки — `UNKNOWN`, не заполнять
   догадками.
5. **Правило:** семейства и общие алгоритмы (все 24 типа, все 13 слотов, все 16 способностей,
   156 видов), индивидуально — только документированные исключения (RuneGiant, динамические
   части, оружейные действия NPC).
