# M0 / D88 — полный план переноса Cube World Alpha 2013 в Unity (Claude + DeepSeek)

**Дата:** 2026-11-09. **Основание:** [D88](../decisions/D88-two-agent-split-transfer-first.md), [D86](../decisions/D86-full-m0-unity-transfer-authorized.md), [план M0-00…09](M0_FULL_ALPHA_INTEGRATION.md), [матрица покрытия M0-00B](../research/alpha2013/M0_00B_ALPHA_GAMEPLAY_COVERAGE_MATRIX.md) (коды строк W/P/C/N/I/Q/AI ниже — оттуда).
**Итог:** готовая одиночная игра Alpha 2013 в одном Unity-проекте (Windows-сборка): создать мир и героя → путешествовать по процедурному миру → сражаться с существами → лут и экипировка → города, торговля, данжи, задания → сохранение, выход, загрузка — и продолжить ту же игру. Мультиплеер не входит.
**Статус документа:** рабочий план, утверждён продюсером как поручение «составь полностью план работы». Не ACCEPTED результата.

## 0. Правила для обоих

1. **Этапы (D88):** этап 1 — перенос (перед коммитом компиляция без ошибок; правило с числами Alpha — тест вместе с кодом); этап 2 — полные проверки и исправления; этап 3 — визуальный осмотр срезов продюсером.
2. **Доказательность:** каждое число — `DIRECT`/`EMULATED_ALPHA_CODE` (исполнение байтов `Cube.exe`/`Server.exe` эмулятором x86 `tools/alpha_models/universal/x86emu.py`) или явный `PLACEHOLDER_NOT_ALPHA`/`UNKNOWN`. Неизвестное не выдумывать. Живой запуск клиента Alpha — только с разрешения продюсера.
3. **Граница:** DeepSeek поставляет данные, поведение и вид через `Features/Contracts`; HP, урон, предметы, деньги, задания и сейв применяет только Claude (Core S02–S04). Изменение контракта — запись `API` в журнале до кода.
4. **Git:** Claude — `integration/m0-all` (интегратор, `D:\Projects\CubeGame`); DeepSeek — `deepseek/m0-content` (`D:\Projects\CubeGame-deepseek`). Связь — `D:\Projects\CubeGame\docs\agents\AGENT_COORDINATION.txt`.
5. **Совместимые исправления** (имена, расхождения без изменения чисел и сейвов) — выполнять сразу, сообщать после. Изменения игровых чисел, формата сейва и утверждённых механик — сначала продюсеру.

## 6. Этап 2 — проверки (после волны 5)

1. Полные EditMode/PlayMode обоих наборов, регрессия S02–S04 и S05.
2. Сквозные сценарии M0-09A: новый мир → создание героя → путешествие с выгрузкой зон → бой с разными существами → лут/экипировка → город/торговец → данж/босс/сундук → задание → сейв/выход/загрузка → продолжение.
3. Устойчивость: изменение чанка и восстановление, состояние NPC вне экрана, разные классы и способности, длительная игра (FPS/память), повреждённый сейв.
4. Сверка с Alpha по матрице: для каждой строки — `ALPHA_PARITY_PASS` / `PLACEHOLDER` / `BLOCKED` с причиной.

## 7. Этап 3 — визуальный осмотр (один раз, продюсером)

Сцена и набор кадров/видео: создание героя (все расы/полы), ходьба/бег/плавание/лазание/планер/лодка, бой каждым классом и способностями, 10–15 разных существ (атаки, смерть), боссы, экипировка на герое (все слоты), город с NPC и торговцем, данж с сундуком, биомы, вода и пещеры, день/ночь, интерфейс (инвентарь, навыки, карта, журнал). К каждому срезу — что сверять с Alpha.
