# CubeGame — концепция
Самостоятельная Windows-first 3D action RPG. Существующий Unity-проект сохранён; сейчас Unreal проходит игровой C++-first пилот до окончательного выбора движка.

Игрок создаёт героя, исследует большой процедурный мир и взаимодействует с его обитателями. Боевые столкновения, поиск ресурсов и экипировки, развитие навыков, торговля, поселения, фракции и задания имеют последствия, сохраняемые между сеансами. Мир активно моделирует область игрока и упрощённо — удалённые события.

Стиль — авторский детализированный voxel/pixel 3D: читаемые кубические формы, геометрия, текстуры, атмосферное освещение, вода, растительность, выразительные модели и анимации. UI удобен для длительной игры.
