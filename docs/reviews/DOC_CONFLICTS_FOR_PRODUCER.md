# CubeGame — противоречия и вопросы продюсеру

**Дата:** 2026-11-10. **Статус:** Q1–Q3 RESOLVED (D91), Фильдор release-scope RESOLVED (D92); редакционная проверка продолжается.

## Предыдущие решения, не требующие повторного вопроса
- **D65 → D66**: одно магическое дерево, физические боевые навыки через практику; старые формулировки о физическом дереве superseded.
- **D13 → D74**: большинство обычных заданий исходят из симуляции мира, допускаются авторские эксперименты; утверждённая добровольная сюжетная ось D60 сохраняется.
- **D79 → D82**: 9 биомов / 41 микробиом утверждены как каталог; новые расширения и сезоны запланированы после основной игры, но оригинальные биомы Alpha не откладываются.
- **D81/D82 ↔ S06**: в S06 погодная система и архитектурный задел под сезоны, а сама сезонная смена — отдельное обновление.
- **M0 D90**: рабочая основа Alpha без ложного обещания 100% паритета; все хвосты фиксируются в M0_ALPHA_PARITY_BACKLOG.

## Принятые ответы — D91, 2026-11-10

- **Q1 = batch:** продюсер принимает эталон семейства и каждую производственную партию; проверка технической валидности каждого Asset ID обязательна, а художественные исключения выносятся отдельно. Продюсер не обязан вручную утверждать каждую модель. Это подтверждает действующий процесс D67 и уточняет D35.
- **Q2 = single:** первый публичный выпуск — самостоятельная полноценная одиночная версия. Сетевой режим, пользовательские серверы и расширенный моддинг не блокируют её выпуск и планируются отдельно после неё.
- **Q3 = later:** заморский континент и четырёхактная кампания — отдельная крупная веха развития игры **после первого публичного одиночного выпуска**. D60 остаётся утверждённым сюжетным каркасом; Q3 меняет производственный срок, не отменяет кампанию. Срок Фильдор был отдельным OPEN, теперь **D92: редкие NPC Фильдор обязательно входят в первый одиночный релиз**, без выбора расы игроком до будущего DLC.

**Источник:** [D91 — решение продюсера](../decisions/D91-document-consolidation-release-batches.md).

## Дополнительный ответ продюсера — D92

**Фильдор = первый публичный одиночный релиз.** Утверждена доступность редких NPC, без обязательного открытия заморского континента или кампании D60 в первом релизе; выбор расы в редакторе остаётся возможностью будущего DLC. [D92](../decisions/D92-fildor-first-solo-release.md).

## Редакторские ошибки, а не новые игровые вопросы
- ГДД из отдельной ветки содержит устаревшие статусы этапов S05A-2/S05B.
- Индекс planning README 2026-11-02 утверждает, что разработка ещё не началась.
- В GDD есть ошибочная нумерация разделов.
- M1 и S06: APPROVED CONCEPT / FUTURE STAGE / NOT_AUTHORIZED, а не ACTIVE.

## Правило
Ответы сначала в датированный CHANGE_REQUEST / новый Dxx, затем синхронизация GDD + Roadmap + регламентов; ни одно решение не редактировать задним числом без следа.
