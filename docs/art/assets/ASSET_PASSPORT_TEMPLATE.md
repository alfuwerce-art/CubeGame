# Паспорт ассета — заполняется из реально проверенной модели
- Asset ID / фактический путь / редактируемый источник / экспорт (если нужен)
- Git SHA, хеш источника и файлов, engine/project/version; состояние восстановления
- Статус: CANDIDATE / OWNER_APPROVED_FOR_SAVE / ACCEPTED; точная цитата/ссылка на решение владельца, область решения
- Референсы: ID, ракурс, разрешение использования, provenance; приватные материалы локально
- Размеры и единицы, пропорции, силуэт, плоскости, локальные формы, материалы, границы модулей, pivots
- Защищённые элементы: конкретная версия/геометрический регион/метод сравнения; skeleton и dependencies
- Геометрия/rig: topology, число треугольников, joints/weights, clips, known defects
- Проверки: ожидаемое/фактическое/evidence/status; кадры фронт/бок/3-4/спина/игровая камера, видео движений
- Совместимость одежды/волос/оружия, LOD и производительность (только проверенное)
- Открытые вопросы и следующая разрешённая задача
Незаполненное = NOT_VERIFIED. Не копировать числа из старого отчёта как фактические измерения.
