# CubeGame — приёмка игровых ассетов
Самопроверка исполнителя перед READY_FOR_OWNER_REVIEW. Технический и визуальный результат независимы. Не объявлять ACCEPTED без решения владельца.

| Проверка | Доказательство |
|---|---|
| Scope | diff, protected file/region сравнение, отсутствие изменений зависимостей вне разрешения |
| Визуал | одинаковые реальные кадры референс/до/после: силуэт, локальные плоскости, пропорции, пиксельность, лицо, палитра, материалы и игровая камера |
| Геометрия | редактируемый источник, масштаб/pivot, нормали, пересечения/дубли/нежелательные внутренние грани; число треугольников и причина изменения, не произвольный лимит |
| Риг | фактическая иерархия, pivots, веса, rest pose, проверка shared dependencies |
| Движение | запись полного цикла нужного клипа в редакторе/игре, кадры экстремальных поз, контакты стоп/оружия, пересечения, локальные растяжения и их причина |
| Модульность | пробное крепление одежды/оружия/волос если в scope, движение без слияния и артефактов; иначе NOT_RUN |
| Производительность | измерения в согласованной сцене/железе, LOD/группа NPC если в scope; не утверждать пригодность по числу полигонов |
| Воспроизводимость | исходник, экспорт если нужен, SHA, точный проект/версия, команды/логи, права на референсы |
| Среда | UE-пилот: фактически открытый UE и заданный сценарий; Unity-интеграция: импорт и Windows Player. Не создавать лишние сцены/экспорты вне запроса |

Отчёт по каждому критерию: PASS/FAIL/SKIP/BLOCKED/NOT_RUN + evidence. При обязательном критерии FAIL/NOT_RUN — PARTIAL/BLOCKED, не READY. Отсутствие референса/паспорта или недоступная runtime-проверка — явное ограничение. Визуальный PASS агента — только результат самопроверки, не приёмка. Принятый элемент сохраняется в паспорте с точной формулировкой решения и проверенной версией.
