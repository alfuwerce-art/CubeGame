# CubeGame — актуальное художественное направление (карта для ревью)

**Статус:** `REVIEW_CANDIDATE`, сводка **ранее обсуждённых** требований. Визуальные ассеты, образцы и технические параметры не становятся `ART_APPROVED` от появления этого файла. Игровые цели определяет [GDD](../GDD.md). Исторический подробный [Art Direction](https://github.com/alfuwerce-art/CubeGame/blob/docs/gdd-first-draft-20261106/docs/art/ART_DIRECTION_DRAFT.md) имеет собственные решения и может содержать Alpha-first / закрытые Factory правила; использовать как источник ревью, **не** как действующее разрешение прежнего конвейера.

## Художественное обещание

Оригинальная **детализированная voxel/pixel 3D**-игра: читаемая блочная геометрия и пропорции персонажей, выразительные силуэты, собственный UI, плотная природная среда, атмосферный свет и тени, качественная вода и материалы. Не подменять стиль фотореализмом, гладкими мультяшными формами или точным клоном чужих ассетов.

## Что требуется проверять

| Объект | Арт-критерий | Доказательства |
|---|---|---|
| Гуманоид | блочный силуэт, читаемые кисти/стопы/лицо и расовые признаки; без случайного «аниме» | фронт, бок, 3/4, спина; камера игры |
| Модуль внешности | одна система масштаба/пивотов; лицо/волосы/экипировка не разрушены при сборке | сравнение без предметов и с экипировкой |
| Оружие | форма считывается в движении, не сливается с рукой | хват, атака, смена |
| Существо | собственная форма, надёжная коллизия/анимация, не клон humanoid | несколько ракурсов и игровые клипы |
| Биом | характерная растительность/земля/свет/существа, без выдачи времени года за новый биом | игровой ракурс, дневной/ночной, плотность |
| Вода и погода | соответствие блочному миру, тени, блики/поверхность, читабельность боя | в движении, разные настройки |
| UI/VFX | собственная композиция, читаемость и удобство | экран игры + сценарий |

## Защита стиля и источников

- Приватная папка `D:\Projects\референсы для CudeGame` — **не трогать, не публиковать и не переносить автоматически**.
- Новые изображения, созданные в обсуждениях биомов, — **кандидаты**, не принятый стандарт без регистрации/проверки владельцем.
- Для эталона: ID, источник, разрешение использования, статус (`REFERENCE` / `OWNER_APPROVED` / `REJECTED`), версия, дата, ожидаемые черты, запрещённые отклонения.
- Визуальная проверка **одного работающего образца** предшествует любому повторяемому workflow. **Не** восстанавливать Factoria, Style Lock, Tripo/ComfyUI автоматизацию или массовое производство по D95.

## Условия принятия

`MODEL_EXISTS` ≠ `MODEL_GAME_READY`: нужен редактируемый файл + экспорт, отсутствие деформаций/разрывов, игровой ракурс, импортер, права, нагрузка и решение владельца. Для рига/анимации — отдельная проверка действия в игровой сцене. Подходы [voxel asset](../../.dsh/skills/cubegame-voxel-asset/SKILL.md), [rig](../../.dsh/skills/cubegame-rig-animation/SKILL.md), [art validation](../../.dsh/skills/cubegame-art-validation/SKILL.md).
