# CubeGame — стандарт формы персонажа
Рабочие ограничения, извлечённые из требований владельца в UE-сессии 22–24.11. Не новый GDD, не утверждение пропорций всех рас. Паспорт принятой модели и явно указанный референс конкретной задачи определяют детали; при конфликте с сохранённым эталоном не угадывать.

| Область | Целевая форма / запрет |
|---|---|
| Общий силуэт | Детализированная voxel/pixel анатомия, геометрия разных масштабов; не гладкая органика и не грубые коробки |
| Голова | Основные грани плоские; локальные ступенчатые скругления углов и челюсти; не округлять всю поверхность и не сужать лицевую грань |
| Уши | Читаемая раковина по референсу, а не случайное углубление/выступ |
| Руки | Блочная анатомия плеча и предплечья без случайных выпуклостей; плоская ладонь и отдельные читаемые пальцы |
| Мужской торс | Грудь и неглубокий пресс встроены в форму; удаление одной ступени не означает стирание рельефа |
| Женский торс | Отдельный референс для груди, талии, пресса и таза; не переносить форму мужского торса и не добавлять чрезмерные выступы |
| Ноги | Воксельная форма всей ноги; колено встроено в силуэт, без ободков и накладных кубиков; компактные стопы по эталону |
| Поверхности | Плоские читаемые грани, локальные ступени; не уничтожать характер граней глобальным bevel/smoothing |
| Модульность | Лицо, волосы, одежда, оружие и расовые детали остаются раздельными там, где требуется редактором; совместимость проверять, не предполагать |

Не выдумывать точные размеры/проценты, бюджет треугольников, количество костей для всех рас. Измерять исходный принятый ассет: высота, размеры головы/плеч/таза/конечностей, границы модулей, pivots, mesh/skeleton версии. Фиксировать реальные значения в паспорте. Никакой массовой генерации до выбора метода владельцем. [Reference protocol](REFERENCE_PROTOCOL.md), [Acceptance](ASSET_ACCEPTANCE.md).

При утверждении размеров и совместимости экипировки обязательно применять [временное правило утверждения эталонов](TEMP_CREATURE_REFERENCE_RULE.md); принятие отдельного элемента не равно принятию полного эталона.
