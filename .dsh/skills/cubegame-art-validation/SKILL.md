# Visual QA of one object or coherent small group

1. Read [Art Direction](../../../docs/art/ART_DIRECTION.md), approved brief and exact reference status. Don't approve a visual just because it was generated in chat.
2. Check characteristic voxel/pixel silhouette and geometry, readable proportions, source material/legal origins, colour/style consistency, water/shadow/render when applicable.
3. Compare multiple camera angles under actual target lighting. For animations require recording and collision/contact notes, not static beauty renders.
4. Distinguish `REFERENCE`, `CANDIDATE`, `OWNER_APPROVED`, `REJECTED`, `NEEDS_REWORK`; only owner can choose final artistic status.
5. Provide succinct discrepancy report **per observable feature**: expected, actual, evidence, severity, focused repair; do not invent acceptance.
6. If only uploaded screenshots exist, evaluate what is actually visible; mark inaccessible scene settings, mesh geometry or rig `UNKNOWN`.

Exit: links to reference and produced frames, objective checks, owner review queue. No modifications without scope approval; no batch factory.
