# Voxel asset
Read Art Direction, CHARACTER_STYLE_STANDARD for characters, REFERENCE_PROTOCOL and asset passport/brief. Verify actual source and editor, units, pivot, permissions and dependencies. Define changed region and protected regions; capture baseline images and region measurements/hashes. Analyze silhouette, planes, steps and volumes in matching views before choosing modeling approach. Edit authorized source/copy, not a replacement; keep modular parts and shared skeleton unchanged unless requested. Check geometry, materials, dependency dirty state and compare actual same-camera results with reference AND original. Use art-validation before handing off; use rig-animation only if relevant. After two failed corrections of same defect diagnose and change method or BLOCKED. Export/import only if requested/needed by target engine. Deliver source, actual images, scope checks, license, evidence, honest status; owner approves art.
