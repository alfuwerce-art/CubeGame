# Исторический архив CubeGame
Архив — неизменяемая справочная база. Файлы здесь не являются активными заданиями, игровыми эталонами, согласованными ассетами или кодом для автоматического запуска.

- `alpha/` — исследования, отчёты, старые технические задания, инструменты и полный снимок Unity-базы (`unity-baseline/`) на момент смены документации.
- `decisions/` — старые решения и этапы.
- `agent-instructions/` — ранние инструкции исполнителей.
- `factoria/` — все 470 отслеживаемых файлов исходного PR #17, с историей исходных Git-коммитов.

Агент использует `archive/` только по отдельному исследовательскому запросу и никогда не читает его как действующий план. Снимок Unity сохранён без дублирования Git-блобов; старые runtime-системы в живом Unity-проекте следует заменять только с проверкой зависимостей и компиляции.
