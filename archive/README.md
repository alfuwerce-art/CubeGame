# Исторический архив CubeGame
Материалы здесь сохранены как источники и история разработки; они **не являются** текущими заданиями, разрешениями, утверждёнными игровыми ассетами или кодом для автоматического исполнения.

- `alpha/` — исследовательская база, отчёты, старые задания и инструменты прототипов.
- `decisions/` — исторические решения и последовательность этапов.
- `agent-instructions/` — прошлые инструкции исполнителей и настройка инструментов.
- `factoria/` — полный импорт отслеживаемого содержимого второго репозитория (470 файлов в исходном PR #17), сохранены исходные Git-объекты и история через родительский коммит.

Файлы архива не загружаются автоматически при старте задач. Любое использование отдельных результатов требует проверки происхождения и соответствия актуальному GDD.
