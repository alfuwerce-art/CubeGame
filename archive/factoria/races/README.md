# Исторические карточки производственных экспериментов

Карточки в этом каталоге фиксируют входы, рабочие имена и результаты прошлых экспериментов Factoria. Утверждённую продуктовую расовую основу и открытые вопросы редактора определяет [реестр решений CubeGame](https://github.com/alfuwerce-art/CubeGame/blob/codex/character-production-contracts/docs/design/DECISIONS.md).

Рабочие ID `FILDOR_ENDERMAN`, `DRAGONKIN` и `SKELETON` сохраняются для воспроизводимости опытов. В каноне D80 имя Фильдор утверждено, первые публичные одиночные встречи закреплены для редких NPC. D63 исключает Frogman из дизайна CubeGame. Связь Dragonkin с Lizard, роль Skeleton по отношению к Undead и стартовый набор редактора требуют продуктового решения. [Текущая производственная память](../docs/PRODUCTION_MEMORY.md).
