# Factory — инструкции для производства персонажей

**Единственный активный Git-репозиторий — CubeGame.** Factoria производит модели и ассеты теперь **внутри `CubeGame/Factory/`**, отдельную Factoria не изменять.

CubeGame владеет игровым дизайном, архитектурой, контролем интеграции и контрактом ассетов. Перед началом читать `../PROJECT_MEMORY.md`, `../docs/ACTIVE_STAGE.md`, `../AGENTS.md`, [локальную память](docs/PRODUCTION_MEMORY.md), [производственные правила](docs/CHARACTER_PRODUCTION_WORKSPACE.md).

- Текущий этап `REPOSITORY_UNIFICATION`: аудит, синхронизация путей и проверок; не создавать модели, манекены, риги, генераторы или игровые системы.
- `HUMAN_MALE_BASE_V1` — `REVIEW_CLOSED / NOT_SELECTED`; архивный, не использовать как обязательный эталон.
- Новый производственный объём и художественный эталон утверждает только владелец.
- Производственные исходники, конфиденциальные референсы и закрытые Alpha-ассеты не публиковать без проверки прав. Локальные D: материалы остаются на месте.
- Не удалять ценные данные, исходный репозиторий и branches; нет force-push/merge без разрешения.
- Будущие DCC/Blender/Unity проверки выполнять только по отдельному ТЗ; фиксировать хэши, версии и воспроизводимые результаты.
- Статус исполнителя не выше `READY_FOR_OWNER_REVIEW`.
