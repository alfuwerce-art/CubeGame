# DESIGN-01 · Ревью архитектуры Factoria

**18 ноября 2026 · READY_FOR_OWNER_ARCHITECTURE_REVIEW**

Предложение — **Hybrid с 3D-шаблоном по умолчанию**. Контроль посадки, размеров, ракурсов и скелета принадлежит Blender. ComfyUI генерирует художественный дизайн по эталону и техническим картам. Одежда имеет независимый меш. Палитры переиспользуют геометрию. Путь image-to-3D зарезервирован для сложных отдельных форм и потребует отдельной проверки.

| Вопрос | Решение и статус |
|---|---|
| 1. Как закрыть стиль? | `PROPOSED` — закреплённый SDXL/VoxelXL, общий художественный словарь, Blender-свет и материалы, разреженные ключевые рёбра. `TESTED` — V3 рецепт на двух визуальных кандидатах. Стиль восьми генераторов и проход лимитов не подтверждены. [Style Lock](STYLE_LOCK_DESIGN.md) |
| 2. Где истинные размеры? | `PROPOSED` — pack из утверждённого 3D с joint/socket matrices, метрами, slot masks и камерой. `TESTED` — прототип male 1.8 м, с проектной глубиной. Female V3 утверждён визуально, женского 3D-baseline ещё нет. [Geometry Reference](GEOMETRY_REFERENCE_DESIGN.md) |
| 3. Как совпадут ракурсы? | `PROPOSED` — FRONT/BACK/LEFT/RIGHT как рендеры одного mesh revision. Самостоятельные кадры ComfyUI остаются вариантами концепта. [Камеры](GEOMETRY_REFERENCE_DESIGN.md) |
| 4. Как получить модульную одежду? | `PROPOSED` — worn inpainting в зоне shell, UV рисунок поверх отдельного garment mesh, изолированный экспорт по тому же мешу. [Генераторы и tunic](GENERATOR_WORKFLOWS.md) |
| 5. Где совместимость со скелетом? | `TESTED` — male rig 20 костей, жёсткие веса в 7 состояниях, GLB round-trip. `PROPOSED` — binding по slot policy, проверка seams/weights/poses на каждом модуле. [Валидация](VALIDATION_DESIGN.md) |
| 6. Как избежать слияния с телом? | `PROPOSED` — edit/allowed/keepout и независимый matte, проверка raw до клипа, модели тела и одежды отдельно, occlusion таблицей, проверка повторной установки после GLB. [Контракты](ASSET_DATA_CONTRACTS.md) |

[Сравнение](TECHNOLOGY_COMPARISON.md) |

Сравнить style/fit, отдельный export/reimport, позы, минуты ручной коррекции, cold/warm ресурсы. [Пилот](IMPLEMENTATION_ROADMAP.md#минимальный-сравнительный-эксперимент) |
| 11. Что первым? | `PROPOSED` — после решения владельца по архитектуре и male rig, GEOMETRY-01 создаёт pack только для утверждённого baseline. Ранняя структурная валидация идёт до первой генерации. [План](IMPLEMENTATION_ROADMAP.md) |

Аудит подтвердил хэш эталона, frozen и двух V3 графов, наличие локальных результатов и версии установленных инструментов. В исторических замерах пик RSS был 13 674–13 717 MiB. **12 из 15** кадров превысили +2048 MiB VRAM, включая выбранные Male/Female TORSO. При +2000 MiB — 13 из 15. Способ измерения и бюджет требуют утверждения перед пилотом. Штатные ноды, схемы JSON и графы доказывают наличие и структуру. Посадка новых объектов, визуальный результат генераторов и промышленная готовность остаются `NOT_VERIFIED`.

Проверка комплекта: 10 Markdown-документов, 4 пары JSON Schema/пример, положительные и отрицательные структурные проверки на используемом подмножестве схем, согласованность ID и матриц камер. Внутренние ссылки разрешаются локально. Это проверка проектных документов.

Основное описание в [архитектуре](ARCHITECTURE.md). Реализация и ресурсные прогоны остаются за пределами DESIGN-01.
