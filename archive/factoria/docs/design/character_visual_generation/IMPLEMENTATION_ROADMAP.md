# План реализации на утверждение

После DESIGN-01 сначала решение по мужскому ригу, затем Geometry Pack. Минимум валидации нужен до первого inference, поэтому VALIDATION-01 делится на преселекцию и полноценный 3D fit. Место GEN-03 после GEN-02 проверяет два разных класса привязки: skinned/segment fit и rigid grip. SCALE-01 бывает лишь после воспроизводимого вертикального среза.

## Минимальный сравнительный эксперимент

После утверждения мужского baseline и рамок бюджета — один оригинальный `MEDIEVAL_TUNIC` на Human Male V3, один фронтальный crop, одинаковые style assets и seed. Сначала получить B: простая клетчатая/пиксельная палитра на shell без sampling, полный fit и четыре проекции. Затем C: один допустимый masked img2img с той же оболочкой и немногочисленными швами, рисунок перенести в UV. Измерить приемлемость силуэта и визуала, репроекцию, 3D clearance, независимость частей, количество минут ручной правки, RAM/VRAM и время. Контроль A при отдельном разрешении — один основной концепт и один боковой в той же камере, сравнить против 3D-проекций по landmarks и ручному fit; Tripo и новые веса для проверки гипотезы не нужны. Сравнение запланировано после решения владельца, в DESIGN-01 описан протокол.

Предлагаемый результат пилота: guardrails проходят на обоих повторениях 3D, одни и те же мелкие размеры и позы, один меш без baked body, C добавляет утверждённый рисунок без дополнительной ручной геометрической подгонки и укладывается в оба лимита. Если C не даёт измеримой пользы, B остаётся основой конкретного слота. GEN-01 может проверить UI-цепочку раньше на hair; tunic лучше всего различает архитектуры под сборку персонажа.
