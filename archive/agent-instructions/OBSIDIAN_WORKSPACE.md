# Obsidian и Markdown — необязательный интерфейс документации CubeGame

Первый транскрипт рекомендует **Obsidian** как удобную программу для локальных Markdown-страниц, ссылок `[[...]]` и референсов. Это **не** новый источник истины и не обязательная установка.

- Открывать как vault существующую папку `D:\Projects\CubeGame\docs` или корень проекта, **не копируя документы в отдельную базу**.
- Хранить критические ссылки в переносимом Markdown `[название](относительный-путь.md)` для совместимости с GitHub и агентами.
- Скриншоты и изображения автоматически не добавлять в публичный репозиторий. Приватные эталоны и оригинальные референсы остаются на прежних защищённых путях. Папку `D:\Projects\референсы для CudeGame` не менять.
- Не использовать Obsidian Sync, сторонние плагины или облачную синхронизацию без отдельного решения.
- `docs/CONCEPT.md` — корневая страница; от неё ссылки на GDD, Art Direction, Quality Attributes, Roadmap, ADR, Decisions и Harness.
- Отдельный «meta-repository» из видео **не создаётся**: D95 выбрал один CubeGame. Проектные skills и решения остаются под Git в CubeGame.
