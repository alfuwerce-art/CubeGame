# CubeGame — единые правила для агентов

## Источник истины
**Единственный активный репозиторий — CubeGame.** Сначала читать `PROJECT_MEMORY.md`, `docs/ACTIVE_STAGE.md`, `docs/GDD.md`, `docs/ROADMAP.md`, `docs/design/DECISIONS.md` и ТЗ назначенного этапа. Для производства дополнительно читать `Factory/AGENTS.md` и `Factory/docs/PRODUCTION_MEMORY.md`.

CubeGame владеет игрой, архитектурой и продуктовыми решениями. Factoria производит ассеты **внутри `CubeGame/Factory/`**. Отдельный исторический репозиторий Factoria — источник восстановления, не место для новой работы.

## Текущий допуск
`REPOSITORY_UNIFICATION`: проверка Git-переноса, документов, ссылок и CI. Игровой код, Unity-сцены, манекены, риги, NPC, ComfyUI и генераторы не разрабатывать. `HUMAN_MALE_BASE_V1` имеет статус `REVIEW_CLOSED / NOT_SELECTED`, не является эталоном.

## Роли
Владелец утверждает продуктовые решения, визуал, этапы, merge и судьбу архивов. ChatGPT ведёт техническое ревью. Codex и DeepSeek Harness исполняют только порученные задачи. Не менять решения самостоятельно.

## Git и данные
Перед работой: `git status`, текущая ветка, удалённый SHA, изменения и происхождение файлов. Работать в отдельной ветке, не выполнять merge, force push, удаление веток и ценных файлов без разрешения. История Factoria присоединена через `git subtree` без squash. Отдельную Factoria и резервные копии сохранить. Игнорируемые и неотслеживаемые локальные файлы на D: не переносятся автоматически.

## Проверки
В этой задаче только Git, документы и CI. Реальный импорт модели в Unity проверяется отдельно. Отчёт включает ссылку на PR, SHA, проверенные результаты и ограничения. `READY_FOR_OWNER_REVIEW` не равно `ACCEPTED`.
