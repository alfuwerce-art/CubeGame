# CubeGame

Самостоятельная 3D action RPG на Unity с процедурным воксельным миром, свободным исследованием, живыми поселениями и последствиями решений игрока. CubeGame — рабочее название.

- [GDD](docs/GDD.md) описывает игру и утверждённые направления.
- [Roadmap](docs/ROADMAP.md) задаёт этапы и условия готовности.
- [Текущий этап](docs/ACTIVE_STAGE.md) показывает состояние разработки и ближайший проверяемый результат.
- [Engineering](docs/ENGINEERING.md) содержит локальный запуск, сборку и проверки.
- [AGENTS.md](AGENTS.md) и [PROJECT_MEMORY.md](PROJECT_MEMORY.md) дают правила и контекст для агентных задач.
- [Инструменты персонажей](tools/character-assets/README.md) содержат исходники прототипов и команды проверки.

Откройте корень проекта в Unity версии из [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt). Штатные сцены перечислены в [EditorBuildSettings.asset](ProjectSettings/EditorBuildSettings.asset).
