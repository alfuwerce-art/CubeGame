# CubeGame

Единый репозиторий самостоятельной Unity 3D action RPG и её производственного контура.

- [GDD](docs/GDD.md), [Roadmap G0–G15](docs/ROADMAP.md), [решения](docs/design/DECISIONS.md) — продуктовые требования.
- [Текущий этап](docs/ACTIVE_STAGE.md), [межчатовая память](PROJECT_MEMORY.md), [инструкции](AGENTS.md).
- [Factory](Factory/README.md) — модели, манекены, риги, ComfyUI, скрипты, результаты экспериментов.
- [Контракт ассетов](docs/architecture/CHARACTER_ASSET_HANDOFF.md) — внутренняя передача Factory → Unity.
- [Отчёт объединения](docs/reports/FACTORY_REPOSITORY_UNIFICATION.md).

Отдельный [Factoria](https://github.com/alfuwerce-art/factoria) сохраняется как исторический Git-источник и резервная копия, не как активное место разработки. Новые изменения вносить в `CubeGame/Factory/`.

Не делать merge до ревью владельца. Старый `HUMAN_MALE_BASE_V1` не выбран.
