# CubeGame

Рабочее название проекта; финальное название игры не утверждено.

CubeGame — самостоятельная 3D action RPG с кубическим voxel-миром: процедурная генерация, живые NPC и города, бой, RPG-прогрессия, собственный визуал. Разработка ведётся с 2026-11-02; с 2026-11-17 проект разрабатывается как собственная игра (см. ниже).
