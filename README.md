# CubeGame

Самостоятельная 3D action RPG на Unity с процедурными регионами, воксельным окружением и развивающимся миром.

- [GDD](docs/GDD.md), [Roadmap](docs/ROADMAP.md) и [решения](docs/design/DECISIONS.md) описывают игру и план.
- [Активная задача](docs/ACTIVE_STAGE.md) и [память](PROJECT_MEMORY.md) показывают текущее состояние.
- [Контракт передачи персонажей](docs/architecture/CHARACTER_ASSET_HANDOFF.md) связывает производство в [Factoria](https://github.com/alfuwerce-art/factoria) с будущей интеграцией в игру.
