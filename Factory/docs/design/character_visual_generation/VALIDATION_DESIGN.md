# Проверка изображения и 3D

Состояния прогонов разделены: `IMAGE_REJECTED`, `IMAGE_CANDIDATE`, `FIT_PENDING`, `FIT_FAILED`, `READY_FOR_OWNER_REVIEW`. Оценки и причины хранятся по стадиям. Полное прохождение 2D автоматических правил позволяет показать кандидата владельцу. Слот и rig подтверждаются 3D-отчётом.

| Класс | Проверка и метрика | Отказ / действие |
|---|---|---|
| Детерминированный | SHA-256, тип/размер PNG, RGBA и семантика alpha, аффинная регистрация view/camera revision, список обязательных файлов, совместимые версии | `INPUT_MISMATCH`; исправить вход, повторно сэмплировать бессмысленно |
| Детерминированный | Сверить координаты опор и bbox с целевым; проверить поля кадра и допуски px по конкретному слоту. Измерить area outside allowed, coverage required, проникновение в keepout, число компонент заданной площади | `SCALE_OUT_OF_RANGE`, `CROPPED`, `MASK_OVERFLOW`, `COMPONENT_MISMATCH`; сравнить raw/preview и качество обнаруженной маски |
| Детерминированный | Пиксели protected zone после композитинга побитово совпадают с carrier; контур против expected silhouette (IoU + ошибки в критических зонах), симметрия относительно зарегистрированной оси только если профиль требует | `PROTECTED_PIXELS_CHANGED`, `SILHOUETTE_DRIFT`, `SYMMETRY_DRIFT`; допускается профильная асимметрия |
| Смешанный | На независимых кадрах проверить порядок видимых/скрытых landmarks, принадлежность сторон, общие высоты и ширины на сопоставимых сечениях, теги деталей и число видимых частей | `VIEW_INCONSISTENT`; остаточная неопределённость при окклюзии. Для Blender перепроецировать общий mesh и сопоставить матрицы и bbox, включая back и стороны |
| Эвристический | Один предмет, правильный ракурс (без перспективы), нет текста, шума, фона, странных швов и слияния с телом; ступенчатые формы и объём читаются рядом с V3, в целевом масштабе и thumbnail | `ART_REVIEW`, `EXTRA_OBJECT`, `STYLE_DRIFT`, `VIEW_UNCERTAIN`. Субъективные правила используют фиксированные примеры владельца и рубрику по признакам |
| 3D | Метрические размеры, толщина и объём, clearance, меш замкнут там, где нужен, нет degenerate/невалидных граней, корректные normals/UV/материалы, отдельные object IDs | `TOPOLOGY_FAILED`, `FIT_FAILED`, `MESH_FUSED`; вернуть на исправление геометрического рецепта |
| 3D | Правильная иерархия костей и имена, матрицы grip/socket; rigid vertex weights 1.0 либо нормализованные skinned weights, швы и покрытие, mesh↔body и mesh↔mesh в rest, idle/walk/attack и по интервалам проблемных суставов. Проверить GLB round-trip на тех же именах, transform, UV и весах | `RIG_FAILED`, `POSE_COLLISION`, `SEAM_GAP`, `ROUNDTRIP_FAILED`; анализировать разрешённые контакты по slot policy |

Allowed mask, edit mask, expected matte и фактически извлечённый контур — разные артефакты. Заполнение expected matte в RGBA доказывает формат клипа и защищённость carrier, но не совпадение raw-контура. Приходящая из Blender ID/alpha — достоверна для исходной геометрии. В COMFY-STYLE-12 сегментация кандидата по градиенту на сером фоне не сработала. Для raw пилота использовать контролируемый фон, проверяемую сегментацию или ручную разметку малой контрольной группы. При низком доверии записывать `MASK_UNVERIFIED` и отдавать кадр на ревью. Ложный пропуск измерять на размеченных примерах. У частей может быть несколько ожидаемых компонент, например глаза, перчатки, открытые швы и ремни; правила на уровне категории и слота.

Пороговые значения изображения утверждаются на примерах positive/negative. Технический первый порог пилота — ошибка репроекции контрольной точки ≤ 1 px для экспортированной камеры, ноль изменённых защищённых пикселей после composite и ноль нарушений запретных 3D-зон вне явного допуска. Для 3D использовать OBB SAT только для блочных деталей как в MANNEQUIN-RIG-01; сложным мешам требуется проверка пересечений по треугольникам/знаку и проверка проникновения вложенных оболочек. Тестовые 5 мм и 25 мм из рига применимы только к прежним парам и тестам. Критерии fit одежды и веса утверждаются отдельно по сегментам. Все пороги имеют единицы и версию.

## Повтор

Первая попытка и максимум два назначаемых повтора на вид/профиль в пилоте. Контракт, камера, размерные зоны и seed остаются общими при диагностике одного параметра. `MASK_OVERFLOW` с надёжной маской и неизменной камерой → снизить denoise. Смещение ключевого шва → разредить/локализовать plate, менять только этот вход. Плоская форма → при сравнении убрать переусиленные рёбра или отдельно проверить Depth. Недостоверная сегментация → ручная разметка, без генерации. Превышение ресурса → остановить выбранный режим и передать в ресурсный тест. Перегенерация seed допустима как отдельная проба с теми же входами, когда причина — случайный дефект. Кандидаты ранжируются сначала по жёстким проверкам, затем по художественной рубрике. Сохраняются причины, метрики, parent attempt и единственный изменённый параметр. При исчерпании лимита или конфликте проверок — вид и факт передаются на ручное ревью.

Автоматические отрицательные случаи: неверный SHA, маска с обратной полярностью, смещённый camera target, crop, второй предмет, отсутствующий рукав, перепутанный LEFT/RIGHT, ложный успех от жёсткой обрезки, синтетическое проникновение в 3D, веса на чужой кости и потеря material ID при GLB round-trip.
