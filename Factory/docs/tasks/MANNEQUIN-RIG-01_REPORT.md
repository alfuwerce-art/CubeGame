рига**, а не финальный персонаж, не одежда, не Tripo и не производственный набор анимаций.

## 5. Skinning

- 18 объектов, у каждого **ровно одна** вершинная группа, вес **1.0**, имя группы = имя кости.
- Armature-модификатор на каждом объекте, объект — child армейчур-объекта.
- Проверка «жёсткости»: деформированные вершины сравнены с аналитическим преобразованием кости
  (`pose.matrix @ rest.matrix⁻¹`) в 7 состояниях → максимальное отклонение **1.9·10⁻⁷ м** (float-шум).
  Органической деформации нет.

| Проверка | Результат |
|---|---|
| Список частей / костей / иерархия | 18 / 20 / совпадает с профилем |
| Геометрия | 696 вершин, 754 полигона, 0 NaN, 0 вырожденных, габарит 1.4821×0.600×1.8000, подошва z=0.0000 |
| Жёсткий skinning | 1 группа на часть, все веса 1.0; отклонение от аналитики ≤ 1.9·10⁻⁷ м |

| Суставы | 15 смежных пар закрыты (зазор ≤ 25 мм) во всех позах; зазоры/вставки измерены |
| Вставки по проекту | таз↔бедро 178 мм, плечо↔грудь 99–110 мм, локоть/колено/шея 2–50 мм — не растут при анимации (≤ 30 мм к rest) |
| Земля | min z = **0.0000** в каждой позе (ступни не проваливаются и не висят) |
| Семантика поз | **13/13** проверок (см. §7) |
| Экспорт GLB | round-trip: 18 частей, 20 костей, 3 действия, все веса ровно 1.0 |
| Рендеры | 14 файлов, 10.6–25.3 с каждый (Cycles CPU, 64 сэмпла + OIDN, 800×1200) |

Как считается: пересечения — oriented-box SAT по всем парам блоков (с учётом позы кости);
«нулевое пересечение» проверяется с допуском 5 мм; пары, которые по проекту вставлены друг в друга
(скрытая часть бедра внутри таза, плечо в груди) учтены отдельно и выводятся как измеренная величина.

**Осознанные ограничения прототипа:** блоки стыкуются «вставкой» — скрытая часть бедра уходит внутрь
таза, плечо внутрь груди. Это не ошибка рига, а способ держать шов закрытым при вращении; в отчёте
это измерено, а не замаскировано.

## 7. Тесты поз / анимации

Три действия в `.blend`, позы заданы вращениями в armature-space, высота таза подгоняется
**замером**: на каждом ключе вычисляется самая низкая вершина ступней и таз смещается так, чтобы
она легла на z = 0 (смещения 0.2–3.1 см записаны в `build_report.json`).

| Действие | Ключи | Что проверено |
|---|---|---|
| `idle` | 1, 7, 13, 19, 25 | руки ниже плеч, кисти у корпуса, ступни на земле, корпус вертикален |
| `walk` | 1, 5, 9, 13, 17 | контакт: левая стопа впереди правой, руки в противофазе, опора на земле; проход: стопы рядом, маховая стопа поднята |
| `attack` | 1, 5, 9, 13, 15 | замах: правая кисть за корпусом (y > +0.25); удар: кисть впереди (y < −0.25); амплитуда ≥ 0.60 м; выпад ≥ 0.15 м |

Все 13 семантических проверок пройдены. Пересечений ≥ 5 мм нет ни в одной позе, силуэт остаётся
блочным: каждая часть жёсткая (см. §5), поэтому «размазывания» геометрии быть не может; смещения
частей ограничены длиной цепочки костей и проверены по позам.

Рендеры (в `outputs/prototypes/mannequin_v3_rig/run1/renders/`):

- `tpose_front.png`, `tpose_side.png`, `tpose_three_quarter.png` — ракурсы модели;
- `pose_idle.png` / `_front`, `pose_walk_contact.png` / `_front`, `pose_walk_pass.png` / `_front`,
  `pose_attack_windup.png` / `_front`, `pose_attack_strike.png` / `_front`;
- `tpose_front_silhouette.png` — альфа-силуэт для числового сравнения.

## 9. Что доказано, что нет

**Доказано запуском:**

- блочная модель воспроизводит утверждённые пропорции V3 с расхождением ≤ 1.4 % высоты;
- 20-костный скелет и жёсткий skinning дают ровно жёсткое преобразование частей (1.9·10⁻⁷ м);
- в idle / walk / attack нет пересечений блоков ≥ 5 мм, суставы закрыты, ступни стоят на земле;
- позы семантически корректны (направление шага, противофаза рук, замах/удар, выпад);
- GLB с ригом и тремя действиями читается обратно без потери весов (все 1.0);
- `.blend` открывается повторно, действия на месте.

**Не доказано / ограничения:**

- глубина блоков — проектное решение, а не измерение эталона (у эталона только фронтальный рендер);
- **Unity-импорт не проверялся** (это отдельный шаг с отдельным разрешением, Unity в этой задаче не
  запускался);
- риг без IK, без control-костей и без facial-костей; `spine_01` — короткий шов-джойнт, это осознанно;
- позы — тестовые, не финальные анимации; переходы/interpolation не вылизывались, root motion нет;
- вставки блоков (таз/плечо) скрыты внутри соседа; при экстремальных углах (проверенные позы — до
  ~50° в плече, ~30° в бедре) они не выходят наружу, но больший диапазон не проверялся;
- женский манекен, одежда, Tripo и production-анимации по ТЗ не начинали.
